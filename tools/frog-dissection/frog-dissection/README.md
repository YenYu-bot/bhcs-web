# 青蛙虛擬解剖實驗室 — 使用與維護說明

## 怎麼開

解壓縮後直接用瀏覽器（Chrome、Edge、Safari、Firefox 皆可）開 `index.html`，不需要伺服器，也可以整個資料夾丟到學校網站或 Google Drive 分享。手機、平板也能操作（拖曳用手指）。

```
frog-dissection/
├─ index.html                    ← 整個程式（課程腳本、題庫、引擎都在這一個檔案）
├─ img/                          ← 47 張圖片，檔名對應 index.html 裡的 IMG 表
└─ 圖片製作清單與Prompt_v2安全版.md ← 要重做圖片時用
```

## 學生會看到的流程

主選單 → 選課 → 學習目標 → 課程互動（旁白引導、點熱區、選工具、劃開、釘針、拖骨頭、彈出詳細圖）→ 本課小測 → 結果。第 8 項「總測驗」從各課題庫隨機抽 15 題。進度（各課小測成績）存在瀏覽器的 localStorage，同一台電腦、同一個瀏覽器才看得到。

七課內容：① 初步觀察（24 步，最完整）② 循環 ③ 呼吸 ④ 消化 ⑤ 泌尿生殖 ⑥ 神經 ⑦ 骨骼拼圖。

## 教師常用的修改（都在 `index.html` 最上面）

| 想改什麼 | 找哪一段 | 說明 |
|---|---|---|
| 換圖片 | `IMG` | 檔名對上直接覆蓋 `img/` 裡的檔案即可；改檔名或副檔名就改 `src` |
| 熱區位置 | `HOT` | 進課程按鍵盤 `D` 開校正模式，點畫面會顯示座標（0–1000 × 0–1333） |
| 切割線 | `CUTS` | 座標點連成的折線 |
| 大頭針位置 | `PIN_TARGETS` | 四個座標：左前、右前、左後、右後 |
| 照片沒畫針時 | `SHOW_PINS_AFTER` | 改成 `true`，程式會自己把針畫上去 |
| 課程旁白與步驟 | `LESSONS` | 每一步是一個物件，`type` 決定互動方式（見下表） |
| 題目 | `QUIZ` | 每課一個陣列；題型 tf／mc／multi／fill／hotspot |
| 總測驗題數 | `FINAL_COUNT` | 預設 15 |
| 工具列 | `TOOLS` | 名稱與圖示 |

步驟類型：

| type | 學生要做什麼 | 必填欄位 |
|---|---|---|
| `say` | 讀旁白按下一步 | `text` |
| `click` | 點指定熱區 | `target`（HOT 的 key）、`ok`（答對後的說明）；可加 `requireTool` |
| `tool` | 選指定工具 | `tool`（TOOLS 的 key） |
| `cut` | 選好工具後沿虛線拖曳 | `tool`、`paths`（CUTS 的 key 陣列）、`nextLayer` |
| `pin` | 把針拖到目標 | `targets`、`nextLayer` |
| `flip` / `layer` | 按下一步換底圖 | `layer` |
| `detail` | 看彈出圖 | `img` 或 `imgs`、`title`、`text` |
| `drag` | 拖東西到目標框 | `items`（每項有 `img,name,x,y,w,h`） |

任何步驟都可加 `layer:'...'` 指定進入該步時顯示的底圖。

## 圖片現況與可再改善的地方

- 主層 9 張、骨頭 9 張、蝌蚪 6 張、縮圖 8 張、詳細觀察圖 11 張，全部到位。
- `detail-*` 那 10 張是從一張拼圖裁出來的，解析度約 500px，放大會略糊，且有英文標籤（部分拼字錯）。想更精緻時，用 `圖片製作清單與Prompt_v2安全版.md` C 段的 prompt 一張一張重生成（每張開新對話，加上 `no text, no labels`），覆蓋同名檔即可。
- `frog-brain-open.jpg` 的腦畫得偏大、位置偏後，建議重生成；換圖後按 `D` 調整 `CUTS.skullCut`。
- 所有圖皆為 AI 生成，上線前請生物老師確認器官位置與名稱。

## 已知限制

- 沒有語音旁白（原 Froguts 有）。要加的話，可在每一步加 `audio:'sound/xx.mp3'` 欄位並在 `renderStep()` 播放。
- 成績不會上傳，只存在學生自己的瀏覽器。要收成績可在 `finishQuiz()` 裡加上送到 Google 表單或後端的程式。
- 切割判定需要拖曳覆蓋路徑 60% 以上；觸控板太快滑過去會提示「沿著虛線完整劃過」，再劃一次即可。
