## 內容
`polyops` 多項式四則，依舊的 `tools/math/g8-polynomial-operations.html` 的十三個單元重做：合併同類項、多項式加法、多項式減法、多層括號化簡、單項式乘法、多項式乘單項式、兩多項式相乘、多項式乘法進階、單項式除法、多項式除以單項式、多項式長除法、代入 A、B、C 運算、四則混合運算。
舊工具每個單元只有一種句型，這裡每個單元五種問法，基礎取第 1～3 種、進階第 2～4 種、挑戰第 3～5 種，例如加入化簡後寫次數與常數項／代入求值、反求括號內的多項式、「某多項式減去 B 得 C」、三層括號與大括號、(axᵐ)³、三個一次式相乘、(ax＋b)²(cx＋d)、連除、由商與餘式反求被除式、整除求 k、AB−C、含除法的混合運算。除法題先定商與餘式再造被除式，答案寫「商：…；餘式：…」。數型：整數、分數、小數。加減、除法類不印前綴，其餘印「原式＝」。
