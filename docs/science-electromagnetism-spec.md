# 電磁鐵、馬達與發電機實驗室

比較電流產生磁場、線圈受到轉矩，以及轉動線圈產生感應電壓三種方向不同的關係。

年段：國中（依各校版本調整）。建議20–25分鐘。

## 學習目標

- 比較匝數與電流對磁場的影響
- 判斷線圈角度與轉矩
- 用磁通量變化解釋發電

## 模型

空心長螺線管 B=μ₀NI/ℓ（ℓ=0.20m）；τ=NBIA sinθ；ε=NBAω sinθ，ω=2π rpm/60，A=0.01m²。

## 簡化限制

電磁鐵採長螺線管近似；不計漏磁、鐵芯、電阻、發熱與反電動勢。馬達頁顯示當下轉矩而非自行推算轉速；發電機的轉速由外力維持。θ由固定向右基準軸量起；外加磁場B為有號分量，B<0代表向左，B=0時沒有磁場方向。轉矩正向取本圖順時針。正負只是固定繞線及法線約定，不是所有實際馬達的絕對方向。各模式只使用標示適用的控制。

## 引導任務

- ① 電流反向：比較+1A與−1A；匝數不變時磁場方向與大小怎麼變？
- ② 線圈轉矩：保持磁場為正，比較法線相對向右基準軸角度0°、90°、180°。
- ③ 停止轉動：從靜止到60rpm；再把磁場反向，比較感應電壓。
