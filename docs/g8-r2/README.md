## 正確性
驗算走另一個關係：對應角題驗三角和 180°；列式題把 x 代回兩式；等腰與中垂線的畢氏題驗 a²＋b²＝c²；角平分線面積題驗「兩個小三角形面積和＝總面積」；中垂線 △PBC 與 BC−PB 題加了三角不等式限制，不會出現不存在的三角形。
人工核對：底 16 高 15 → 周長 50；AB＝AC＝17、BC＝30 對摺 → BD 15、AD 8；AB＝24、PA＝20、QA＝13 → PQ＝11；面積 18、BC 4、PN 2 → AB 14；∠B＝(4x＋14)°、∠F＝(3x＋23)°、∠D＝(3x＋13)° → x＝13、∠A＝52°。
