# 浮力與密度實驗室規格

## 第一版學習範圍

- 由質量與體積計算物體平均密度，並與液體密度比較，預測漂浮、懸浮或下沉。
- 同時比較重量、浮力與容器底部支持力，避免把「沉底後靜止」誤認為浮力等於重量。
- 使用阿基米德原理 `Fb = ρ液 g V排`，連結排開體積與浮力。
- 說明漂浮平衡時 `V排 / V物 = ρ物 / ρ液`，物體露出液面的比例會隨液體密度改變。
- 由彈簧秤空氣中與液體中的讀值差求浮力，並用溢出液體驗證排開體積。

## 核心模型

- 重力加速度固定 `g = 9.8 N/kg`。
- 物體密度：`ρ物 = m / V物`，其中質量用 `g`、體積用 `cm³`，結果為 `g/cm³`。
- 阿基米德原理：`Fb = ρ液 g V排`。程式換算時，`ρ液 × V排` 得到排開液體質量（g），再除以 1000 換算成 kg。
- 重量：`W = (m / 1000)g`。

### 平衡狀態

| 條件 | 最終狀態 | 排開體積 | 最終受力 |
|---|---|---|---|
| `ρ物 < ρ液` | 漂浮 | `m / ρ液` | `Fb = W` |
| `ρ物 = ρ液` | 懸浮 | `V物` | `Fb = W` |
| `ρ物 > ρ液` | 下沉並停在槽底 | `V物` | `Fb + N = W` |

下沉物體尚未接觸槽底時，合力為 `W − Fb` 向下；停在槽底後，槽底支持力 `N = W − Fb`，所以物體雖然靜止，仍不能說浮力等於重量。

## 排水法與彈簧秤

- 固體完全浸沒且由彈簧秤懸掛時：`T = W − Fb`。
- 彈簧秤讀值差：`W − T = Fb`。
- 完全浸沒的剛性物體排開體積等於物體體積。
- 第一版量測區只提供密度大於所選液體的固體，避免需要向下壓住物體卻仍用只能拉伸的彈簧秤表示。

## 液體與量測物

液體採教學近似值：酒精 `0.79 g/cm³`、食用油 `0.92 g/cm³`（常見植物油 20°C 相對密度約 0.91–0.93，依油種與溫度略有差異）、水 `1.00 g/cm³`、濃鹽水 `1.20 g/cm³`、甘油 `1.26 g/cm³`。

排水量測物：玻璃 `2.50 g/cm³`、鋁 `2.70 g/cm³`、鐵 `7.80 g/cm³`；量測體積固定 `50 cm³`。

## 模型限制與安全

- 假設液體靜止、密度均勻，物體為不吸水、不溶解、體積固定的單一整體。
- 忽略表面張力、液體阻力、氣泡、繩重、彈簧秤本身浮力及容器壁效應。
- 動畫只表示移動方向；最終數值依靜力平衡計算，不以動畫速度代表真實加速度。
- 酒精等液體只作密度比較，不提供真實混合或操作步驟；實作時應由教師選用安全材料。

## 驗收案例

1. `80 g、100 cm³` 物體放入水：`ρ物 = 0.80 g/cm³`，漂浮，排水 `80 cm³`，浸入 `80%`，`W = Fb = 0.784 N`。
2. `100 g、100 cm³` 物體放入水：懸浮，完全浸沒，`W = Fb = 0.980 N`。
3. `150 g、100 cm³` 物體放入水：下沉，`W = 1.470 N`、`Fb = 0.980 N`、槽底支持力 `0.490 N`。
4. `80 g、100 cm³` 物體放入食用油（0.92）：物體密度較小，漂浮，浸入比例約 87%。懸浮情境改由任務二（100 g、100 cm³ 放入水）呈現。
5. 同一 `80 g、100 cm³` 物體放入濃鹽水：漂浮，排水約 `66.67 cm³`，浸入約 `66.67%`。
6. 鋁塊 `135 g、50 cm³` 完全浸入水：`W = 1.323 N`、`Fb = 0.490 N`、彈簧秤讀值 `0.833 N`。
7. 任一漂浮案例的排開液體質量必須等於物體質量；下沉案例不可把槽底支持力省略。
