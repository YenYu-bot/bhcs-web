## 來源與分工
- 題型與寫法取自百宏國一下講義 2-1 直角坐標、2-2 二元一次方程式的圖形。講義沒有「對稱點」，不出；講義不使用「斜率」一詞，本檔也不用。
- 直線方程式照講義兩種寫法都用：`ax＋by＝c`（顯示時化成最簡整數係數、x 係數為正）與 `y＝ax＋b`；由兩點求直線照講義重點 5，令 `y＝ax＋b`。
- 已讀 ChatGPT 提供的三個舊檔：`g7-function` 只有 f(x) 代入求值、沒有圖形；`g7-simultaneous-equations` 只有解聯立。`lineeq` 的「兩直線交點」以圖形與係數為主，不重做解聯立的計算練習。`g7-inequality` 與 `numberline` 的交集見 r1 說明。

## 正確性（verify 走不同路徑）
- 象限：直接判符號，符號推理題另用多組數值代入重判；「不通過的象限」用截距正負判斷，再以取 800 個點實際落點驗算。
- 外包法面積：出題用坐標外積，驗算用「外包長方形減三個直角三角形」，兩者不同時不出題。
- 兩點求直線：驗兩點都滿足方程式、並以兩點差商比對係數；三點共線用交叉相乘驗；參數式代三個 t 值驗。
- 交點、已知交點求係數：代回兩條方程式；正整數解組數用雙重迴圈列舉重數。

人工核對：|x＋5|＋|2x−y−3|＝0 → (−5, −13) 第三象限；B(5,0)、C(2,6)、面積 21 → A(12,0)；邊長 7 正方形 A(−2,3) → B(−2,−4)、C(5,−4)、D(5,3)；M(1,1) 中點、A(−2,−7) → B(4,9)；過 (4,2)、(2,3) → y＝−1/2x＋4；(t 參數) (−2t, t＋4) → y＝−1/2x＋4；ax＋by＋1＝0 過 (−5,−9)、(−4,−7) → 2x−y＋1＝0；y＝−4/3x−4 截距 (−3,0)、(0,−4) 面積 6；過 A(−5,1) 作 y 軸平行線交 −x＋3y＝11 → B(−5,2)、AB＝1。全對。
