# P4：sincosarea 題型多樣性

## 改了什麼

- 保留 `sincosarea` 的既有 unit、數字尺度、整數模式與原本題型。
- `ambiguous` 新增兩種實質輸出：只判定 SSA 為無解／唯一解／兩解；改求所有可能的 `∠C`。原本「三角形個數＋`∠B`」仍保留。
- `cosineangle` 保留原本「求 cosA 並判斷角型」，新增三邊符號表示求角、線段表示求角；挑戰層再新增由三邊求最大角。
- 特殊角只使用 60°、90°、120°，邊長仍是 1–10 倍的小整數三角形；沒有加入反三角函數近似值。
- 新增 `sincosarea-diversity.mjs`，逐題經 `safeQuestion()`、`verify()`、內容上限，並鎖定每種新結構至少 3 題、SSA 0／1／2 解、角度 60°／90°／120°及 5 題舊結構逐字保留。
