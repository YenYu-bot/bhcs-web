# G11 P4：`vectorcauchy` 的柯西最值

日期：2026-09-23。僅修改 `tools/math/g11-drills.html` 的 `cauchy` 單元和本主題難度說明。

## 題型與驗證

原本只有二元線性式最大值。現在基礎加二元最小值及絕對值最大值；進階加三元最大／最小值；挑戰加由最大／最小值反求正係數。係數取整數畢氏二元組或三元組，約束半徑平方取整數平方。

出題用係數向量長度乘以半徑；`verify()` 則讀回顯示答案，代回獨立建構的等號取到點，確認平方約束及線性式值。反求係數另把答案平方後代入係數長度恆等式，檢查 `b>0`。
