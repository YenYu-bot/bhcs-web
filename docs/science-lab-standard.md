# 百宏自然互動教材共用規格

## 目標

每一個互動教材都要讓學生完成一個完整的科學探究循環，而不是只看動畫：

1. 預測：操作前先選擇或寫下預期結果。
2. 操作：至少有兩個可改變的變因，並能重新開始。
3. 觀察：畫面變化與數值必須同時呈現。
4. 記錄：能把本次條件和結果加入紀錄表。
5. 解釋：揭示規則、模型限制與常見迷思。
6. 檢核：至少三題即時回饋題，錯誤時指出該回去觀察什麼。

## 共用介面

- 頁首：教材名稱、適用年級、基礎／進階模式。
- 左側或上方：任務分頁與目前步驟。
- 中央：主要互動畫面，圖像與數據同步更新。
- 右側或下方：變因控制、預測、結果與說明。
- 頁尾：實驗紀錄、學習檢核、教師提示、相關資源。
- 所有拖曳操作都必須另有按鈕、下拉選單或鍵盤操作方式。

## 科學與教材標準

- 每個數值都要能追溯到公式或明確規則。
- 模型若有簡化，必須直接告知學生；不能把近似模型說成真實世界的完整情況。
- 不以動畫速度代替量值。動畫可幫助理解，但讀值仍以標示數值為準。
- 「觀察到的現象」「由模型推論的解釋」與「真實實驗的限制」分開呈現。
- 危險操作使用模擬警示，不鼓勵學生在真實環境重做。

## 技術與無障礙標準

- 單一 HTML 或明確的同資料夾資產，不依賴外部框架。
- 390px 手機寬度不可出現整頁橫向捲動。
- 所有控制項都有可見標籤；狀態變化使用 `aria-live` 宣告。
- 可用鍵盤完成核心任務；焦點樣式清楚。
- 遵守 `prefers-reduced-motion`，關閉非必要動畫。
- 顏色不是唯一判讀方式，狀態同時使用文字或圖示。
- 儲存進度時只使用瀏覽器本機儲存，不收集學生個資。

## 上線驗收

- 科學規則測試：典型值、邊界值、錯誤操作各至少一例。
- 互動測試：每個控制都能更新圖像、數值與紀錄。
- 內容測試：標題、年級、單位、名詞與答案一致。
- 技術測試：HTML 結構、JavaScript 語法、內部連結、canonical、手機版。
- 教學測試：不讀說明的學生也能在一分鐘內完成第一次操作。
