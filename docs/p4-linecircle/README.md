# P4-3　g10 `linecircle`（直線與圓） 題型補強（2026-09-23，Claude）

累積包：`tools/math/g10-drills.html` 含 absolute、inequalities、linecircle、quadratic 四個 topic 的改動。本 topic 只改 `lineCircleConfig()`，unit id、名稱、modes 不變，基礎級保留原題型。

## 每個 unit 新增了什麼

| unit | 基礎（原有） | 進階新增 | 挑戰新增 |
|---|---|---|---|
| 圓方程式 | 一般式→標準式 | 標準式→一般式；求圓心與半徑 | 判斷圓／點／無圖形；以 AB 為直徑的圓 |
| 位置關係 | 點與圓 | 直線與圓（相交／相切／相離，先算圓心到直線距離） | 求 c 使直線相切（兩解）；交點個數 |
| 最近最遠 | 圓外點 | 圓內點（r−d、r＋d） | 圓上點到直線的最短最長距離 |
| 切線 | 過圓上點的切線方程式 | 圓外點的切線長 √(d²−r²) | 同進階，配合其他單元 |
| 弦長 | 由 r、d 求弦長；由弦長反求 d | 給直線方程式與圓，先算距離再求弦長 | 由 d 與弦長反求 r |

## 正確性
直線一律取 3x＋4y 或 5x＋12y 型（法向量長 5、13），圓心到直線的距離才是整數；切線長與弦長用畢氏三元組構造。`verify()` 直接以「|ah＋bk＋c|/w」重算距離，與出題時的構造式無關；切線長另檢查 d²−r²＝ℓ²。
