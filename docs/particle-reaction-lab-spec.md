# 粒子與化學反應實驗室規格

## 第一版學習範圍

- 從粒子圖分辨反應物、生成物與未反應的剩餘粒子。
- 以係數比例決定一次完整反應需要的粒子數。
- 判斷限量反應物，計算反應次數、生成物數量及剩餘量。
- 逐元素比較反應前後的原子數，驗證原子重新排列但不會憑空增加或消失。
- 分辨「配平係數」與「分子內右下角數字」的意義。

## 收錄反應

1. 水的生成：`2H₂ + O₂ → 2H₂O`
2. 氨的生成：`N₂ + 3H₂ → 2NH₃`
3. 甲烷完全燃燒：`CH₄ + 2O₂ → CO₂ + 2H₂O`

## 模型與簡化

- 畫面中的一個圖示代表一個分子；係數表示參與反應的分子數比例。
- 反應依已配平方程式，以完整整數組進行：`反應組數 = floor(min(nA/a, nB/b))`。
- 限量反應物以實際比例 `nA/a` 與 `nB/b` 比較，不只比較整數商；比例相等時顯示「恰好完全反應」。
- 第一版假設反應能完全進行，不模擬活化能、反應速率、可逆平衡、溫度、壓力與副反應。
- 進階模式使用標準相對原子質量 H 1.008、C 12.01、N 14.01、O 16.00，顯示畫面粒子的相對總質量（u）；這不是實驗室可直接秤量的巨觀克數。
- 燃燒與氣體反應只能作為模擬，不提供真實操作步驟。

## 驗收案例

1. `4H₂ + 2O₂`：反應 2 組，生成 `4H₂O`，無剩餘，H、O 原子數前後相同。
2. `7H₂ + 2O₂`：O₂ 為限量反應物，生成 `4H₂O`，剩餘 `3H₂`。
3. `2H₂ + 3O₂`：H₂ 為限量反應物，生成 `2H₂O`，剩餘 `2O₂`。
4. `2N₂ + 6H₂`：恰好反應 2 組，生成 `4NH₃`。
5. `2CH₄ + 5O₂`：CH₄ 為限量反應物，生成 `2CO₂ + 4H₂O`，剩餘 `1O₂`。
6. 任一反應物不足一個完整反應組時，產物為 0，且不能出現半個分子。
