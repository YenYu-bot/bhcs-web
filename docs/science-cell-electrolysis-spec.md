# 電池與電解實驗室

比較鋅銅電池與三種電解裝置：哪一極變輕或變重、產生什麼氣體、電子在導線上往哪走、溶液裡的離子怎麼移動。

年段：國中（依各校版本調整）。建議20–25分鐘。

## 學習目標

- 說明鋅銅電池中鋅極（負極）變輕、銅極（正極）變重與電子流向
- 說出電解水時兩極的氣體與體積比
- 比較用碳棒與銅棒電解硫酸銅時溶液顏色的差別

## 模型

通過的電子莫耳數＝電流×時間÷96500（進階）。鋅銅電池：鋅極 Zn → Zn²⁺＋2e⁻（負極、變輕），銅極 Cu²⁺＋2e⁻ → Cu（正極、變重）。電解水：負極產生氫氣、正極產生氧氣，體積比 2：1。電解硫酸銅：負極析出銅；碳棒時正極產生氧氣、溶液變淡，銅棒時正極的銅溶解、溶液顏色不變。

## 簡化限制

理想情況：電流全部用在電極反應，不計副反應與電阻發熱。電子的莫耳數與質量計算屬進階內容，基本觀察只看變輕變重、氣體與顏色。鋅銅電池以鹽橋連接兩杯溶液；電解時「正極、負極」指接電源的正、負極。

## 引導任務

- ① 鋅銅電池：哪一極變輕、哪一極變重？導線上的電子往哪裡走？
- ② 電解水：兩極各產生什麼氣體？體積比是多少？
- ③ 碳棒與銅棒：記下溶液顏色的變化，再改成銅棒電解硫酸銅：顏色變化為什麼不同？
