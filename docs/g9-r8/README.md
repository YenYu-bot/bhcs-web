## 內容
依舊工具 `tools/math/g9b-2-1-quartiles.html` 的四個單元重做。四分位數沿用原頁規則：位置 n×k／4 不是整數時取下一個整數位置；是整數 m 時取第 m 與第 m＋1 筆的平均。每個單元五種問法，基礎取第 1～3 種、進階第 2～4 種、挑戰第 3～5 種：
- `median` 中位數的應用：未排序資料求中位數、淘汰人數比例、中位數以下（含）與以上（含）的比例、由中位數反求 x、加入一筆資料後的新中位數。
- `raw` 未分組資料的四分位數：已排序、未排序資料求 Q₁～Q₃、Q₁～Q₃ 是第幾筆、16～24 筆求 Q₁ 與 Q₃、由 Q₁ 或 Q₃ 反求 x。
- `table` 次數與累積次數分配表：次數表、填累積次數並求中位數、累積次數表、缺一個次數、甲乙兩組合併。
- `group` 分組資料的四分位數所在組：直方圖求 Q₁～Q₃ 所在組、所在組與組中點、由累積次數、缺一組次數、由累積相對次數。
數型：整數資料、小數資料（小數只用於 median、raw；table、group 為整數，勾「小數資料」時引擎自動略過並提示）。表格用內嵌樣式，未新增 CSS。
直方圖單元：各組次數同時寫在題幹，SVG 只是輔助；第 m 與 m＋1 筆落在不同組時不出題。舊工具④改成這種形式，依上次確認列 A 類。
舊工具的線上作答評分、計時、匯出 HTML 不在引擎範圍，沒有移植。舊工具②題幹寫「資料已由小到大排列如下」卻沒有列出資料，引擎已改正（舊檔不動）。
