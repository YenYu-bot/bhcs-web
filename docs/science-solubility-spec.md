# 溶解度與濃度實驗室

用明確標示的教學溶解度曲線，分辨已溶解質量、未溶固體與溶液濃度。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 正確使用每100g水的溶解度
- 分辨飽和、未飽和與剩餘固體
- 計算質量百分濃度並比較冷卻析出

## 模型

模型A：S=20+0.5T；模型B：S=35+0.025T（g/100g水）。容量=S×水量/100；已溶解=min(加入量,容量)；濃度=已溶解/(水+已溶解)×100%。

## 簡化限制

A、B是虛構的線性教學溶質，絕非硝酸鉀或食鹽的實測曲線。假設立即達平衡、不蒸發、不形成過飽和；只適用所示0–80°C範圍。真實溶解度需查該物質的實測資料。

## 引導任務

- ① 飽和與剩餘固體：先預測剩餘固體，再只增加水量。
- ② 加熱與冷卻：記錄60°C的已溶解量，再降到20°C。兩筆相差多少？
- ③ 濃度不是加入量除以水量：比較加入溶質與真正溶解的質量，算濃度時分母是哪一個？
