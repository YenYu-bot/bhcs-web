## 內容（B 類：引擎只做計算）
依舊工具 `tools/math/g9b-2-1-boxplot.html` 重做計算部分。舊工具①「並繪製盒狀圖」與②④純看圖讀值的題型留在舊頁。引擎題目裡的盒狀圖只是輔助，五個數一律寫在題幹。四分位數規則同 quartile。每個單元五種問法，基礎取第 1～3 種、進階第 2～4 種、挑戰第 3～5 種：
- `fivenum` 五數綜合、全距與四分位距：已排序、未排序資料求五數綜合、求全距與四分位距、16～24 筆資料全部一起求、由四分位距反求 x。數型：整數資料、小數資料。
- `compare` 兩組資料的比較：兩組的全距與四分位距、哪一組較分散、百分比判讀（約有百分之幾大於／小於某個五數）、兩組統計量的差、由全距與四分位距反求缺少的五數。
- `table` 次數分配表的全距與四分位距：次數表求全距與四分位距、求五數綜合、累積次數表、缺一個次數、甲乙兩組比較四分位距。
- `read` 由五數綜合判讀：全距與四分位距、中間 50% 與百分比、由全距與四分位距反求最大值與 Q₁、由總筆數估計介於兩數之間的筆數、極端值改變後的全距與四分位距。
compare、table、read 只有整數資料；勾「小數資料」時引擎自動略過並提示。表格用內嵌樣式，未新增 CSS；盒狀圖只用既有四種顏色。
