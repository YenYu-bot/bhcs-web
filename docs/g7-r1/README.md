## 題型
- **numberline**：數線 SVG 刻度依數值自動取 1、1/2、1/4、1/5、1/10 或 1/分母；「標出點」的教用答案直接畫紅點數線。挑戰級：多數排序、介於兩數之間、已知距離求點（兩解）、哪一點較近、a＜｜x｜≦b、｜x｜＜k 且 x＞m、巢狀絕對值、｜a｜＝p、｜b｜＝q 且 a＞b 求 a＋b。
- **statistics**：資料 5–15 筆，先定平均再湊資料，平均數必為整數或有限小數。數型勾選改為「平均數為整數／平均數可為小數」，沒有分數模式；`freq`、`mode` 只提供整數。四分位數與盒狀圖屬國三，不出。長條圖、折線圖為 SVG。

## 正確性（verify 走不同路徑）
距離題用兩種順序相減取絕對值互驗；個數題用 −60～60 列舉重數，與公式 2⌈k⌉−1、2⌊k⌋＋1 比對；讀數線由刻度位置反推；平均數用「總和÷筆數」與「逐筆與平均的差總和為 0」互驗；中位數以排序後取中間、次數表題另以累計次數找位置；反求題一律代回。
