# 神經與反應時間實驗室

比較膝跳反射、碰到燙的東西縮手、看到球後接住三種反應的神經路徑，找出哪些經過大腦判斷；再用接尺實驗算出自己的反應時間。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 依序說出反應的路徑：受器→感覺神經→中樞→運動神經→動器
- 區分反射（中樞在脊髓）與經大腦判斷的反應
- 由接尺實驗的落下距離求反應時間

## 模型

反應路徑：受器→感覺神經→中樞（脊髓或大腦）→運動神經→動器。接尺實驗：尺自由落下 d 公分所需時間 t＝√(2d／g)，d 換成公尺，g＝9.8 m/s²。

## 簡化限制

神經路徑為課本層級的簡化示意，不畫神經元與突觸細節；接球的路徑省略小腦等其他腦區。接尺實驗假設尺由靜止自由落下、不計空氣阻力，只量「看到放手到抓住」的時間，不是神經傳導的純時間。

## 引導任務

- ① 膝跳反射：依編號走一遍路徑：有經過大腦嗎？中樞在哪裡？
- ② 碰到燙的東西：縮手之後才覺得痛，為什麼？找出圖上較晚才到大腦的那條虛線。
- ③ 接尺實驗：和同學做接尺實驗，把尺落下的距離輸入：反應時間是多少？重複三次取平均，再和接球的路徑比較。
