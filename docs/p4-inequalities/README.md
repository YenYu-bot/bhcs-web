# P4-2　g10 `inequalities`（不等式）題型補強（2026-09-23，Claude）

累積包：`tools/math/g10-drills.html` 同時含 P4-1（absolute）與本次（inequalities）改動，覆蓋即可。改動只在 `inequalitiesConfig()`；五個 unit 的 id、名稱、modes 不變，基礎級保留原有題型。

## 每個 unit 新增了什麼

| unit | 基礎（原有） | 進階新增 | 挑戰新增 |
|---|---|---|---|
| 一次不等式 | ax+b op c，四種符號 | 兩邊都有 x；連鎖不等式 c₁ op ax+b op c₂（含負係數要反轉） | 不等式組（含無解）；最大／最小整數解 |
| 二次不等式 | 首項係數 1、兩相異根 | 首項係數 2、3、−1、−2；重根（答「x＝r」「所有實數」「無解」） | Δ＜0（所有實數／無解）；由解集反求 b、c |
| 恆正恆負 | 恆正與恆負都出；平方項係數 a∈{±1,±2,±3}，隨機問恆正或恆負，方向不合時答「不存在（開口向上／下）」 | 同左；另求首項係數 a 的範圍（恆正 a＞b²/4c；恆負 c＜0、a＜−b²/4\|c\|） | k 同時在一次項與常數項（Δ 是 k 的二次式）；「方程式無實根」的等價問法並判斷特定 k 的根數 |
| 高次 | 三相異根、≥ | 四種符號；含偶重根 (x−a)(x−b)² | 首項係數 −1；四次（四相異根） |
| 分式 | ＞、＜ | ≥、≤（分子零點取等號、分母排除） | 分子兩因式（三個臨界點）；右邊為 k（2、3、−1），需移項通分 |

## 正確性：答案與驗算走不同路徑

所有解集合由「零點＋各區間試值」建構；`verify()` 不看建構過程，改在每個端點、端點±½、端點±3 與 ±1000 取樣，逐點檢查「原式在該點是否成立」與「該點是否在答案集合內」必須一致；分式另檢查分母零點不在集合內、右式為 k 的題另代回確認移項後的零點正確。單一整數解與不等式組另有各自的獨立檢查。

原版：恆正恆負三個難度結構數皆 1、高次永遠 ≥、分式只有 ＞＜、二次永遠首項係數 1。真瀏覽器：三難度 × 學用／教用各 10 題，驗證完成、無溢出、無 JS error；教用版答案（含分數、∪、x≠）我逐題手算核對過截圖上的 10 題。

恆正恆負依使用者指示重做：三個難度都同時出恆正與恆負，且平方項係數不一定為正，學生必須先判斷開口方向；約一半的題目方向不合，正確答案是「不存在」。

## 每種新結構的樣本

### advanced／一次不等式

- 解不等式 −x − 1 ≥ −4。　→　x ≤ 3
- 解不等式 5x − 9 ＜ 6x − 2。　→　x ＞ −7
- 解不等式 −6x ＋ 1 ＞ 7。　→　x ＜ −1
- 解不等式 −x ＋ 5 ≤ 12。　→　x ≥ −7
- 解不等式 0 ≤ 4x ＋ 8 ≤ 24。　→　[−2，4]
- 解不等式 −11 ≤ 3x − 8 ＜ −2。　→　[−1，2)

### advanced／二次不等式

- 解不等式 −2x2−8x＋24 ≤ 0。　→　(−∞，−6]∪[2，∞)
- 解不等式 x2−13x＋30 ＜ 0。　→　(3，10)
- 解不等式 −x2−2x−1 ≥ 0。　→　x＝−1
- 解不等式 x2−9x＋14 ≥ 0。　→　(−∞，2]∪[7，∞)
- 解不等式 2x2−18 ＞ 0。　→　(−∞，−3)∪(3，∞)
- 解不等式 −x2＋2x−1 ≤ 0。　→　所有實數

### advanced／恆正與恆負條件

- 求實數 k 的範圍，使 −x2＋kx − 9 對所有實數 x 恆正。　→　不存在（開口向下，不可能恆正）
- 求實數 a 的範圍，使 ax2＋8x − 2 對所有實數 x 恆負。　→　a ＜ −8
- 求實數 k 的範圍，使 −2x2＋kx − 32 對所有實數 x 恆負。　→　−16＜k＜16
- 求實數 a 的範圍，使 ax2＋8x ＋ 5 對所有實數 x 恆正。　→　a ＞ 165
- 求實數 k 的範圍，使 x2＋kx ＋ 64 對所有實數 x 恆負。　→　不存在（開口向上，不可能恆負）
- 求實數 k 的範圍，使 3x2＋kx ＋ 243 對所有實數 x 恆正。　→　−54＜k＜54

### advanced／高次多項式不等式

- 解不等式 （x＋3）（x＋2）2 ≥ 0。　→　[−3，∞)
- 解不等式 x3−14x2＋29x＋44 ≥ 0。　→　[−1，4]∪[11，∞)
- 解不等式 x3−4x2−17x＋60 ＞ 0。　→　(−4，3)∪(5，∞)
- 解不等式 （x＋9）（x＋8）2 ＜ 0。　→　(−∞，−9)
- 解不等式 x3−14x2−7x＋440 ≤ 0。　→　(−∞，−5]∪[8，11]
- 解不等式 x3＋20x2＋109x＋90 ＜ 0。　→　(−∞，−10)∪(−9，−1)

### advanced／分式不等式

- 解不等式 （x＋7）（x＋3） ＞ 0。　→　(−∞，−7)∪(−3，∞)（x≠−3）
- 解不等式 （x−9）（x＋5） ＞ 0。　→　(−∞，−5)∪(9，∞)（x≠−5）
- 解不等式 （x＋9）（x−1） ≤ 0。　→　[−9，1)（x≠1）
- 解不等式 （x＋5）（x＋9） ＜ 0。　→　(−9，−5)（x≠−9）
- 解不等式 （x＋2）（x−2） ＞ 0。　→　(−∞，−2)∪(2，∞)（x≠2）
- 解不等式 （x＋1）（x−3） ≥ 0。　→　(−∞，−1]∪(3，∞)（x≠3）

### challenge／一次不等式

- 求不等式 2x − 1 ＞ 8 的最小整數解。　→　x＝5
- 解不等式組 x ＋ 2 ≥ −3 且 2x − 2 ≤ −14。　→　無解
- 求不等式 5x ＋ 7 ≤ 6 的最大整數解。　→　x＝−1
- 求不等式 5x − 2 ≥ −3 的最小整數解。　→　x＝0
- 解不等式組 2x − 4 ＜ −24 且 x − 2 ＞ −10。　→　無解
