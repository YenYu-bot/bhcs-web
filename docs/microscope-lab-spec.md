# 虛擬顯微鏡規格

## 第一版學習範圍

- 計算總放大倍率：`目鏡倍率 × 物鏡倍率`。
- 比較 4×、10×、40× 物鏡的視野大小、可見細胞數與亮度差異。
- 使用粗動與微動調節輪完成對焦，理解高倍觀察應使用微調。
- 移動載玻片並觀察視野影像往相反方向移動。
- 比較洋蔥表皮、口腔上皮與水蘊草葉片細胞的細胞壁、細胞膜、細胞核與葉綠體。
- 使用視野直徑與比例尺建立大小概念。

## 光學與操作模型

- 目鏡固定為 `10×`；物鏡提供 `4×`、`10×`、`40×`，總倍率分別為 `40×`、`100×`、`400×`。
- 目鏡視野數採 `18 mm`，標本面的視野直徑為 `18 ÷ 物鏡倍率`：
  - 4× 物鏡：`4.5 mm`
  - 10× 物鏡：`1.8 mm`
  - 40× 物鏡：`0.45 mm`
- 複式顯微鏡成像方向與標本上下、左右相反；載玻片向右移，視野影像向左移。
- 調焦以教學化清晰度模型呈現，不模擬真實鏡片的數值孔徑、景深、球面像差與色差。
- 40× 高倍物鏡停用粗動調節，避免讓學生形成高倍時大幅升降鏡筒或載物臺的危險習慣。
- 高倍率視野略為變暗，但使用者可調整照明；亮度不代表染色深淺。

## 標本內容

### 洋蔥鱗葉表皮

- 長方形排列、細胞壁清楚、可見細胞核與大型液泡區域。
- 地下鱗葉表皮通常沒有葉綠體；不可把「植物細胞一定有葉綠體」畫成通則。

### 口腔上皮

- 扁平不規則、可見細胞膜與細胞核，沒有細胞壁與葉綠體。
- 模型不呈現細菌與染色操作。

### 水蘊草葉片

- 長方形細胞壁與多個葉綠體；葉綠體常沿細胞周邊分布。
- 第一版不模擬細胞質流動速率。

## 驗收案例

1. 10× 目鏡配 4×、10×、40× 物鏡，總倍率依序為 40×、100×、400×。
2. 視野直徑依序為 4.5 mm、1.8 mm、0.45 mm，物鏡倍率提高 10 倍時視野直徑縮為 1/10。
3. 載玻片 X 向右增加時，畫面內容必須向左移；Y 向上增加時，畫面內容向下移。
4. 粗調與微調皆為零時最清楚；離焦越遠，清晰度不可提高。
5. 40× 物鏡時粗動調節控制必須停用，微調仍可操作。
6. 洋蔥表皮不畫葉綠體；口腔上皮不畫細胞壁；水蘊草必須呈現葉綠體。
