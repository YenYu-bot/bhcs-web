# P2 數學答案修正：受影響單元與期間

這份公告只列「題目本身或教用版答案可能錯誤」的單元，不包含只改驗證器的 `sincosarea/ambiguous`、`loggraphs/inverse`。

## spaceinner / pointdistance（點到直線距離）

- 受影響內容：方向向量為 `(1,0,1)` 的部分題目，生成偏移不垂直於直線，教用版把偏移長度誤當最短距離。
- 受影響期間起點：該單元首次對外可用起；目前可取得的提交／部署證據不足以可靠還原首次上線日期，因此不填猜測日期。
- 受影響期間終點：2026-09-22 PR #26 合併前產生的版本。
- 教學處置：上述期間產生的 `spaceinner/pointdistance` 教用版答案不可直接採信；請以投影法或外積距離公式重算。學用版題目本身仍可作答，但原配套答案可能錯。

## line3d / pointprojection（點到直線的正射影）

- 狀態：已確認同類構造錯誤，修正 PR 尚未合併。
- 受影響期間：該單元首次對外可用起至後續修正 PR 合併前；首次上線日期同樣尚無可靠證據。
- 教學處置：既有教用版垂足答案不可直接採信；須同時檢查垂足在直線上，且 `PQ` 與方向向量內積為 0。
