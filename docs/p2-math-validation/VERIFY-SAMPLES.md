## 判定摘要

| unit | 判定 | 是否會改候選題面／數值 |
|---|---|---|
| deviationsum | 生成漏掉內容上限過濾 | 超限候選改為 null；保留有效題面與原範圍 |
| ambiguous | 驗證方式 | 否 |
| inverse | 驗證方式 | 否 |
| spaceinner / pointdistance | 生成構造錯誤、答案可錯 | 會改個別座標組合 |
| spacecross / height | 生成退化構造 | 會排除或重建退化向量 |
| line3d / pointprojection | 生成構造錯誤、答案可錯 | 會改個別座標組合 |
