# commonlog / definition：固定題庫宣告前後五題

本 PR 只新增依 mode 生效的 `bankSize`，`gen()` 一行都不改。固定種子的原始 HTML 題面、答案與 `sig` 前後逐字相同。

| 呼叫／難度 | 題面 | 答案 | 前後 |
|---|---|---:|---|
| 1 / basic | 求 log₇7。 | 1 | 逐字相同 |
| 2 / advanced | 求 log₂2。 | 1 | 逐字相同 |
| 3 / challenge | 求 log₇343。 | 3 | 逐字相同 |
| 4 / basic | 求 log₂2。 | 1 | 逐字相同 |
| 5 / advanced | 求 log₁₀1000。 | 3 | 逐字相同 |

分數模式的容量由 `5 個底數 × 6 個指數（−1..4）=30` 得到，三難度各 5,000 次生成都完整覆蓋 30 個 sig。整數模式不套用這個容量，避免把 45 種整數題錯標為 30。
