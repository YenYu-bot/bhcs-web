# line3d / pointprojection：修正前後五題與獨立驗算

五題都固定相同亂數種子；直線、預選參數、六種方向與自由整數範圍不變。原構造在 `d=(1,0,1)` 時可能讓 `PQ` 不垂直，因此修正後更換題目中的 `P`，使同一個線上點 `Q` 真正成為垂足。

| 種子 | 修正前題面 → 原答案 | 修正後題面 → 答案 |
|---:|---|---|
| 2 | P=(−12,−4,−3)，L：(−1,−5,4)＋t(1,0,1) → (−8,−5,−3) | P=(−7,−9,−4)，同一直線 → (−8,−5,−3) |
| 8 | P=(−2,−2,10)，L：(−8,−3,8)＋t(1,0,1) → (−6,−3,10) | P=(−5,1,9)，同一直線 → (−6,−3,10) |
| 11 | P=(−4,−2,−1)，L：(−4,−3,−7)＋t(1,0,1) → (2,−3,−1) | P=(3,−9,−2)，同一直線 → (2,−3,−1) |
| 14 | P=(−8,−1,−12)，L：(1,−2,−5)＋t(1,0,1) → (−6,−2,−12) | P=(−5,−4,−13)，同一直線 → (−6,−2,−12) |
| 17 | P=(5,0,−6)，L：(5,−1,−3)＋t(1,0,1) → (2,−1,−6) | P=(3,2,−7)，同一直線 → (2,−1,−6) |

## 方法一：直接代回兩個幾何條件

| 種子 | `Q−A` | 線上參數 t | `P−Q` | `(P−Q)·d` |
|---:|---|---:|---|---:|
| 2 | (−7,0,−7) | −7 | (1,−4,−1) | 0 |
| 8 | (2,0,2) | 2 | (1,4,−1) | 0 |
| 11 | (6,0,6) | 6 | (1,−6,−1) | 0 |
| 14 | (−7,0,−7) | −7 | (1,−2,−1) | 0 |
| 17 | (−3,0,−3) | −3 | (1,3,−1) | 0 |

`Q−A=td` 證明 Q 在直線上，內積為 0 證明 PQ 垂直方向向量。

## 方法二：重新計算正射影

另由題面獨立計算 `t=((P−A)·d)/(d·d)`，五題依序得到 `−7、2、6、−7、−3`；代回 `A+td`，分別得到表中的五個答案 Q。這個計算不使用生成器保存的原始 t 或偏移向量。

自動回歸對三難度共 600 題逐題執行這兩種方法，不只驗這五題。
