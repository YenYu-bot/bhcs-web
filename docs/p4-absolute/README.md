# P4-1　g10 `absolute`（絕對值與區間）題型補強（2026-09-23，Claude）

基底：main after PR #41。改動只有 `tools/math/g10-drills.html` 的 `absoluteValueIntervalsConfig()`；六個 unit 的 id、名稱、modes 與 `presets` 結構不變，原有題型全部保留（基礎級就是原本的樣子），新增的結構依難度分層。engine 其他部分未動。

## 每個 unit 新增了什麼

| unit | 基礎（原有） | 進階新增 | 挑戰新增 |
|---|---|---|---|
| 絕對值方程式 | \|ax+b\|=c、\|x−h\|=c | c=0 只有一解；c<0 無解；\|x−a\|=\|x−b\| | \|x−h\|=kx+d（k=2,3），兩解都合或一解需捨去，答案寫出捨去理由 |
| 絕對值不等式 | \|x−h\| op r，四種符號 | 係數 2–5 需先除；r≤0 邊界（無解／唯一解／所有實數） | a<\|x−h\|<b 複合區間，四種端點組合 |
| 由區間反求 | 開區間→\|x−a\|<b | 閉區間→≤；外側兩段→\|x−a\|>b、≥b | 反求 \|kx−a\|<b（k=2,3,4）；由文字敘述「與 h 距離大於／小於 r」寫出不等式與範圍 |
| 整數解計數 | \|x−h\| op r | 含係數 | ≥／> 型答「無限多個」；a<\|x−h\|≤b 兩段合計 |
| 雙絕對值 | 距離和最小值 | \|x−a\|−\|x−b\| 的最大最小值與達成條件 | 解 \|x−a\|+\|x−b\|≤k（k>\|a−b\|） |
| 測量誤差 | 求絕對與相對誤差 | 由相對誤差 % 求絕對誤差與兩個測量值；由測量值與絕對誤差反求真值 | 給相對誤差上限，用絕對值不等式寫出測量值範圍 |

## 正確性與獨立驗算

- 右式含 x：先選定候選解再反推 k、d，`verify()` 把每個宣稱的解代回 `|x−h|` 與 `kx+d` 兩邊比對並要求右式 ≥ 0，同時確認被捨去的候選右式確實為負。k 排除 1（否則 \|x−h\|=x−h 會退化成恆等式，這是開發中實測抓到的錯誤）。
- 整數解計數：出題用「端點取整」公式，`verify()` 改用逐一枚舉整數重數。
- 距離和不等式：`verify()` 把兩個端點代回距離和，須恰等於 k。
- 其餘沿用原本的中心／半徑互驗。全部走引擎的 `safeQuestion()`＋`contentGuard()`＋`answerWithinLimits()`，未改任何守門。

## 每種新結構的樣本（機器抽取，答案為引擎輸出）

### advanced／絕對值方程式

- 解方程式 |x − 8|＝12。　→　x＝−4 或 20
- 解方程式 |2x ＋ 8|＝−3。　→　無解（絕對值不可能是負數）
- 解方程式 |8x − 8|＝−2。　→　無解（絕對值不可能是負數）
- 解方程式 |x − 6|＝|x − 10|。　→　x＝8（到 6 與 10 等距離的點）
- 解方程式 |x ＋ 2|＝|x − 7|。　→　x＝52（到 −2 與 7 等距離的點）
- 解方程式 |x ＋ 5|＝−7。　→　無解（絕對值不可能是負數）

### advanced／絕對值不等式

- 解不等式 |x ＋ 5| ≤ 0。　→　x＝−5
- 解不等式 |x − 8| ＞ −5。　→　所有實數
- 解不等式 |2x − 14| ＜ 8。　→　(3，11)
- 解不等式 |x ＋ 4| ≥ 2。　→　(−∞，−6]∪[−2，∞)
- 解不等式 |x ＋ 1| ＜ 2。　→　(−3，1)
- 解不等式 |x − 3| ＜ 0。　→　無解

### advanced／由區間反求絕對值式

- 將區間 (−9，13) 改寫成 |x−a| ＜ b，求（a，b）。　→　（2，11）
- 將區間 [−14，8] 改寫成 |x−a| ≤ b，求（a，b）。　→　（−3，11）
- 將區間 [−3，−1] 改寫成 |x−a| ≤ b，求（a，b）。　→　（−2，1）
- 將區間 (2，16) 改寫成 |x−a| ＜ b，求（a，b）。　→　（9，7）
- 將「x ≤ −20 或 x ≥ 2」改寫成 |x−a| ≥ b，求（a，b）。　→　（−9，11）
- 將區間 (−11，−1) 改寫成 |x−a| ＜ b，求（a，b）。　→　（−6，5）

### advanced／區間內整數解計數

- 不等式 |x − 8| ＜ 8 有幾個整數解？　→　15 個

- 不等式 |x ＋ 2| ＜ 4 有幾個整數解？　→　7 個

- 不等式 |4x − 48| ＜ 1 有幾個整數解？　→　1 個
- 不等式 |2x ＋ 20| ＜ 11 有幾個整數解？　→　11 個

### advanced／雙絕對值距離與極值

- 求 |x ＋ 10|−|x ＋ 2| 的最大值與最小值。　→　最大值 8（x≥−2 時），最小值 −8（x≤−10 時）
- 求 |x − 11|−|x ＋ 9| 的最大值與最小值。　→　最大值 20（x≥11 時），最小值 −20（x≤−9 時）
- 求 |x − 1|＋|x ＋ 4| 的最小值及達成範圍。　→　最小值 5；[−4，1]
- 求 |x ＋ 9|＋|x ＋ 10| 的最小值及達成範圍。　→　最小值 1；[−10，−9]
- 求 |x − 12|−|x − 11| 的最大值與最小值。　→　最大值 1（x≥12 時），最小值 −1（x≤11 時）
- 求 |x ＋ 4|−|x − 11| 的最大值與最小值。　→　最大值 15（x≥11 時），最小值 −15（x≤−4 時）

### advanced／測量誤差與百分比

- 真值為 12，某次測量的相對誤差為 25%，求絕對誤差，並寫出兩個可能的測量值。　→　絕對誤差 3；測量值 9 或 15
- 真值為 7，測得 2，求絕對誤差與相對誤差百分比。　→　絕對誤差 5；相對誤差 5007%
- 測得 17，已知絕對誤差為 8，真值可能是多少？（寫出所有可能）　→　9 或 25
- 真值為 11，要求相對誤差不超過 2%，測量值 m 的範圍為何？（用絕對值不等式表示並解出）　→　|m−11|≤1150；[53950，56150]
