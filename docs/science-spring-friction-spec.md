# 彈簧與靜摩擦實驗室

掛上砝碼看彈簧伸長多少，找出虎克定律；再用水平拉力拉木塊，看靜摩擦力怎麼跟著拉力變大，直到木塊開始滑動。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 用 F＝kx 說明彈簧伸長量與外力成正比，並知道彈性限度
- 說明靜摩擦力會隨外力改變，直到最大靜摩擦
- 比較最大靜摩擦與動摩擦的大小

## 模型

彈簧：F＝kx（在彈性限度內），伸長量 x＝mg／k。木塊：正向力 N＝mg；最大靜摩擦 fs＝μs N。拉力小於 fs 時，靜摩擦力＝拉力、木塊不動；超過 fs 後改為動摩擦力 fk＝μk N，加速度 a＝(拉力－fk)／m。g＝9.8 m/s²。

## 簡化限制

接觸面的摩擦係數是教學值（光滑木板 μs 0.3、μk 0.2；粗糙木板 0.6、0.4；橡膠墊 0.9、0.7），不是實測值。拉力水平、木塊在水平面上，不計空氣阻力。彈簧超過彈性限度時仍顯示 F＝kx 的計算值，但虎克定律已不適用，真實彈簧可能永久變形。臨界點（拉力恰等於最大靜摩擦）可用任務③直接設定。

## 引導任務

- ① 質量加倍：記下伸長量，再只把吊掛質量改成 1 kg：伸長量變成幾倍？
- ② 拉了卻沒動：拉力 2 N 時木塊不動；改成 5 N 也不動。兩次的摩擦力一樣大嗎？
- ③ 剛好要滑動：這是最大靜摩擦的臨界點。把拉力加到 6 N：摩擦力變大還是變小？
