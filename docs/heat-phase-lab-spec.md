# 熱與物態實驗室規格

## 第一版學習範圍

- 讀出純水在一大氣壓下的加熱／冷卻曲線，分辨固態、液態、氣態與兩個共存區。
- 解釋相變期間持續吸熱或放熱，但溫度維持在熔點或沸點附近的原因。
- 使用 `Q = mcΔT` 計算單一物態內的顯熱，使用 `Q = mL` 表示相變潛熱。
- 比較質量與加熱功率對完成相同溫度歷程所需時間的影響。
- 從粒子間距、排列與運動方式連結巨觀物態，並分辨傳導、對流與輻射。

## 純水熱量模型

第一版固定模擬純水、壓力 `1 atm`，溫度範圍 `−20°C` 至 `120°C`。

| 階段 | 溫度／物態 | 模型常數 | 每克所需熱量 |
|---|---|---:|---:|
| 冰升溫 | −20 → 0°C | `c冰 = 2.10 J/(g·°C)` | `42 J/g` |
| 熔化 | 0°C | `Lf = 334 J/g` | `334 J/g` |
| 水升溫 | 0 → 100°C | `c水 = 4.18 J/(g·°C)` | `418 J/g` |
| 汽化 | 100°C | `Lv = 2260 J/g` | `2260 J/g` |
| 水蒸氣升溫 | 100 → 120°C | `c氣 = 2.00 J/(g·°C)` | `40 J/g` |

- 完整加熱每克需要 `3094 J/g`。
- 加熱時累積熱量 `Q = Pt`；理想完成時間 `t = m × 3094 ÷ P`。
- 冷卻採相同熱量區段反向進行，代表系統向外界放出熱量。
- 曲線在相變區保持 `0°C` 或 `100°C`；輸入／移出的能量改變物態比例，而非平均動能。

## 模型限制與安全

- 假設純水、固定一大氣壓、加熱功率恆定，忽略容器熱容量、蒸發散失、環境熱損失、過熱與過冷。
- 粒子圖是概念模型，粒子大小、數量、距離與速度不按真實比例。
- 真實沸點會隨氣壓與溶質改變；本模型的 `0°C`、`100°C` 不可套用到所有環境或物質。
- 真實加熱涉及高溫、蒸氣與玻璃破裂風險；頁面只提供模擬，不引導學生自行加熱密閉容器。

## 熱傳模型

- 傳導：能量經相鄰粒子碰撞與振動傳遞，物質整體不必移動。
- 對流：流體因溫度與密度差產生整體循環流動。
- 輻射：能量以電磁波傳遞，不需要介質。
- 熱傳示意只比較機制，不以動畫速度表示真實熱流率。

## 驗收案例

1. `100 g、250 W` 從 `−20°C` 加熱到 `120°C`：總熱量 `309.4 kJ`，理想時間 `1237.6 s`。
2. 累積 `4.2 kJ`（100 g）時到達 `0°C`；再吸收 `33.4 kJ` 完成熔化。
3. 累積 `79.4 kJ`（100 g）時到達 `100°C`；汽化完成需再吸收 `226.0 kJ`。
4. 熔化與汽化區即使熱量持續增加，顯示溫度分別維持 `0°C` 與 `100°C`。
5. 相同質量下功率加倍，完整歷程時間減半；相同功率下質量加倍，時間加倍。
6. 冷卻模式依相反順序通過凝結與凝固，溫度平台與加熱模式相同。
7. 進度為 `0%` 或 `100%` 時，模型不得超出 `−20°C` 至 `120°C`。
