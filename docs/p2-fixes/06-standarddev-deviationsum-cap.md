# P2 修正 06：標準差離均差平方和上限

`withinLimits()` 規定卷面數字不得超過 10,000；`deviationsum` 原本只在 `verify()` 檢查 `ans<=10000`，使超限候選產出後才被拒絕。本修正依決定在 `gen()` 算出 `ans=n×sd²` 後補 `if(ans>10000)return null`。

`verify()`、`withinLimits()`、n≤60、sd≤15、題型與輸出模板全部保留；只是讓超限候選依引擎設計交回 `safeQuestion()` 重試。
