前六項修正後完整 52 主題／1,740 組／348,000 次 gen：1,171 通過、569 失敗（原 1,148／592）。候選驗證失敗 398→17，例外 980→175；第七項為題面符號錯誤，原 P2 的 verify 不會辨識，另以实际印出字串驗證。

本批真實 Chromium 螢幕與列印畫面檢查由獨立 workflow 執行，結果與人工目視待填。列印畫面是 Chromium print media 的學用／教用畫面，不等同實體列印或 Safari 驗收。
