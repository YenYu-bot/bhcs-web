# P2 修正 05：指數函數同底方程安全驗證

根因：`expfunctions/equation` 已由 `mx+n=p` 構造出正確解，但舊 `verify()` 又用 `p` 的分子作為冪次，分別計算兩個完全相同的巨大精確冪。這個重複檢查與題目答案無關，且會在 advanced／challenge 的合法候選超過安全整數。

修正保留原本的指數等式核對，並直接檢查底數 `a>0`、`a≠1`；不再建構冗餘巨大冪。底數池、`x`／`m`／`n` 範圍、題型與輸出模板不變。
