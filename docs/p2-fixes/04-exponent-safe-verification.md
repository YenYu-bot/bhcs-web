# P2 修正 04：高一指數安全驗證

根因：`exponent/fractional`、`laws`、`algebra` 已先算出題目與正確答案，但舊 `verify()` 會再把等式兩側展開成遠大於題面所需的精確整數／分數；`laws` 在答案只需保留冪式時也會先計算巨大冪。中間值超過 JavaScript 安全整數後，精確分數引擎依設計丟出「無效分數」。

修正只改計算路徑：直接驗證既有根值、指數加減乘關係及化簡後係數；只有答案要顯示數值且 |指數|≤6 時才計算冪值。底數池、指數範圍、題型輪替與輸出模板不變。

## 修正前後固定種子樣本

下列 5 組涵蓋三個 unit；題面與答案逐字相同。

| unit／難度 | 修正前題面 → 答案 | 修正後題面 → 答案 | 比對 |
|---|---|---|---|
| fractional / basic | (1000)^(1/3)＝？ → 10 | (1000)^(1/3)＝？ → 10 | 逐字相同 |
| fractional / challenge | (324)^(5/2)＝？ → 1889568 | (324)^(5/2)＝？ → 1889568 | 逐字相同 |
| laws / challenge | ((3/5)^3)^5 ÷ (3/5)^6＝？ → (3/5)^9 | ((3/5)^3)^5 ÷ (3/5)^6＝？ → (3/5)^9 | 逐字相同 |
| laws / advanced | ((13/12)^3)^3 ÷ (13/12)^0＝？ → (13/12)^9 | ((13/12)^3)^3 ÷ (13/12)^0＝？ → (13/12)^9 | 逐字相同 |
| algebra / challenge | ((6/5)xy³)^4 ÷ (6/5)x²y⁶＝？ → (216/125)x²y⁶ | ((6/5)xy³)^4 ÷ (6/5)x²y⁶＝？ → (216/125)x²y⁶ | 逐字相同 |

`node scripts/math-regressions/exponent-safe-verification.mjs` 逐組檢查三難度與所有允許 mode；每題仍執行正式 `verify()`，並從 `sig` 獨立重算顯示答案或精確比對代數單項式。未修改 UI 或列印樣式。
