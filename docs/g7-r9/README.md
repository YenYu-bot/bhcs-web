## 內容
`inequality` 一元一次不等式，由舊的 `tools/math/g7-inequality.html` 移植：有理數、一次式、運算式項目、解集合與交集、解題步驟、數線 SVG 與十個單元（基本型、括號型、分數型、小數型、合併形式、畫數線、讀數線、解不等式並圖示、絕對值不等式、綜合練習）照舊，只換成引擎的難度／數型介面；聯立的大括號與絕對值符號改用內嵌樣式。
差異：需要在數線上作答的題（畫數線、解並圖示、絕對值）題幹下方附一條空白數線（學用、教用都有），教用版答案另含解的數線；「讀數線」的題幹加了文字（端點數值或圖例說明），挑戰級另有「判斷端點是否在範圍內」的問法，讓題型結構不只靠圖。數型：整數、分數、小數。作答列不印前綴。numberline 的「滿足絕對值條件的整數」是數線主題的用法，與本 topic 不重疊。
