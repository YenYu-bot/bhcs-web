## 圓周率設定的做法
交接包要求「圓周率取 3.14／取 3／以 π 表示」。沒有另做控制項，而是讓本 topic 覆寫「數的類型」三個勾選框的標籤：整數→「圓周率取 3」、小數→「圓周率取 3.14」、分數→「以 π 表示」（答案寫成 25π、9π＋12）。老師勾哪幾種，卷面就混哪幾種，和其他 topic 的操作方式一致。

## 單元與難度

| unit | 基礎 | 進階 | 挑戰 |
|---|---|---|---|
| 圓周長 | 由半徑、由直徑求周長；圓周的一半 | 由周長反求半徑；半徑可為 x.5 | 由周長反求直徑 |
| 圓面積 | 由半徑、由直徑求面積；直徑→半徑與面積 | 由面積反求半徑 | 半徑 2、3 倍時面積幾倍 |
| 半圓與扇形 | 半圓、四分之一圓的面積或周長（含直邊） | 弧長與周長分開問 | 四分之三圓；周長與面積合問 |
| 複合圖形 | 正方形內接圓、環形、兩半圓拼成圓 | 跑道形（長方形兩端接半圓）周長與面積 | 正方形內以頂點為圓心的四分之一圓陰影 |

值以（π 的係數，常數項）兩個有理數表示，輸出時依模式合成，所以「9π＋12」和「取 3.14 時 40.26＋12＝52.26」是同一份資料。每題附示意圖（直徑／半徑用紅色虛線；扇形依 ½、¼、¾ 畫）。

## 正確性
- `verify()`：周長題用直徑路徑重算、面積題用直徑的一半重算、反求題把答案代回、扇形檢查 π 係數與常數項分別等於弧長與直邊、環形用 (R＋r)(R−r) 重算、跑道形分別檢查四個成分。
- 取 3 模式下四分之一圓面積 3r²/4 會出分數，已把半徑調成偶數。開發中抓到：反求題在「以 π 表示」模式下呼叫了數值換算（π 為 null）→ 例外，已改為直接比對 π 係數。
