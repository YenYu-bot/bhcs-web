# 力與運動實驗室規格

## 第一版學習範圍

- 由受力箭頭判斷合力的大小與方向。
- 在無摩擦情況驗證 `F_net = ma`：同質量時合力越大，加速度越大；同合力時質量越大，加速度越小。
- 分辨位置、速度與加速度，不把「正在移動」誤認為「一定有合力」。
- 在進階模式比較靜摩擦力門檻與動摩擦力，理解施力不一定會讓物體開始移動。
- 同步閱讀小車動畫、受力圖、位置—時間圖與速度—時間圖。

## 模型與簡化

- 一維水平運動；小車視為質點，不計空氣阻力與車輪轉動慣量。
- 重力加速度固定為 `g = 9.8 m/s²`。
- 垂直方向上支持力與重量互相平衡：`N = mg`。
- 無摩擦面：`f = 0`。
- 光滑面：`μs = 0.15`、`μk = 0.10`。
- 粗糙面：`μs = 0.35`、`μk = 0.25`。
- 靜止時若 `|F_app| ≤ μsN`，靜摩擦力會抵銷施力，小車保持靜止。
- 開始滑動後，動摩擦力大小為 `μkN`，方向與當下速度相反。
- 數值模擬以小時間步進行；速度穿越零點時重新判定靜摩擦，避免物體在小速度附近不合理振盪。
- 每次觀察 3 秒；小車抵達 `x = ±15 m` 時停止模擬，代表離開觀察軌道，不代表撞牆。

## 模式

### 基礎模式

- 初速固定為 0。
- 只使用無摩擦面與向右施力。
- 改變施力與質量，聚焦牛頓第二運動定律。

### 進階模式

- 可選無摩擦、光滑、粗糙表面。
- 可向左或向右施力，並設定初速度。
- 顯示靜摩擦上限、動摩擦力、合力與完整計算式。

## 驗收案例

1. `m = 2 kg`、`F = 6 N`、無摩擦：`a = 3 m/s²`。
2. `m = 4 kg`、`F = 6 N`、無摩擦：`a = 1.5 m/s²`。
3. `m = 2 kg`、`F = 0 N`、`v₀ = 2 m/s`、無摩擦：維持等速，`a = 0`。
4. `m = 2 kg`、粗糙面、靜止、`F = 5 N`：最大靜摩擦力 `6.86 N`，小車不動。
5. `m = 2 kg`、粗糙面、靜止、`F = 8 N`：動摩擦力 `4.9 N`，初始加速度 `1.55 m/s²`。
6. 所有條件下垂直合力為 0；重量與支持力數值相同、方向相反。
