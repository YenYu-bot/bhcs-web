## 單元與難度

| unit | 基礎 | 進階 | 挑戰 |
|---|---|---|---|
| 長方形與正方形 | 長方形面積／周長、正方形面積 | 加正方形周長、周長與面積合問 | 由面積反求寬、由周長反求面積；含分數 |
| 平行四邊形 | 面積、反求高、周長與面積（給斜邊） | 加「給斜邊當干擾」（答案註明斜邊不是高） | 干擾、周長、同一圖形另一組底反求高 |
| 三角形 | 面積、直角三角形、反求高 | 加鈍角三角形（高畫在底的延長線上） | 鈍角、反求高、同一三角形另一邊上的高 |
| 梯形 | 面積、反求高、中線長 | 同左 | 反求高、反求下底、中線 |
| 複合圖形 | L 形、外框、切角（整數） | 同左（小數） | 外框、切角、兩長方形疊放 |

每題（複合圖形除外）附程式產生的 SVG 示意圖：高用紅色虛線加直角記號，鈍角三角形的高落在底的延長線外並補畫延長虛線；圖右下角標「示意圖」。圖上的數字用純文字（分數寫成 3 1/5），不放 HTML。

## 正確性

- 面積用 R 計算；`verify()`：長方形以乘法交換律與重複加法互驗；平行四邊形／三角形／梯形反求題把答案代回公式；複合圖形 L 形用「補成大長方形扣缺角」與「切成兩塊相加」兩條路徑互驗，外框同樣兩種算法，切角把切掉的三角形加回去必須等於原長方形。
- 整數模式三角形與梯形保證面積為整數（底×高調成偶數）。反求高的題在小數模式限制答案至多兩位小數；開發中抓到「2.26875 cm」這種五位小數的答案，已排除。
