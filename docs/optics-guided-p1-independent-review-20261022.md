## 1. 現況判定

**可保留、無需重建**：
1. 模型：薄透鏡 `v=fu/(u−f)`、`m=−v/u`、焦點 `u=f` 回傳 `null` 而非 Infinity、桌外實像不可被判為可聚焦、有效清晰度分級均有專門模型與測試。
2. 三輪：f=10 cm；第一次 u=30→v=15、m=−0.5；第二次 u=15→v=30、m=−2；第三次 u=5→v=−10、m=+2、在右側屏幕找不到實像。
3. 實驗證據：兩次記錄使用實際 `observedScreenPosition`，而非把 15/30 寫死；屏幕清楚只是解鎖記錄，按 CTA 才保存。
4. 控制變因：第二次保留第一輪屏幕位置，只改動物距，再讓學生重新找到清晰的位置。
5. 無障礙／儲存：鍵盤 1cm、Shift+0.5cm、PageUp/PageDown 5cm；螢幕 390/1280；錄入、Notebook A/B/C、三題挑戰、離線本機進度與恢復均已有測試。
6. 科學名詞按教學階段延後至 Concept，舊版 `tools/science/optics.html` 保留自由探索，不取代。

**工程已驗證與未驗證須區分**：`main` 的正式 CI（run `39767926943`）包含 optics 的 input/view/flow Chromium 測試並成功。這些測試以程式送出精確位置、鍵盤或模擬觸控，仍不能證明學生能徒手穩定找到焦點，也沒有五位初次操作者的匿名學習成果紀錄。

## 3. 嚴格保留的物理與體驗契約

- `f=10` 固定，Guided 不要求拖動透鏡；不得在引導關卡新增參數 slider 或直接選串、並...（與光學無關）。
- Trial 1：u=30、s 初始 20、Lv3；`v=15`、倒立縮小、sharp 後 CTA 記錄真實 `s`。
- Trial 2：u=15、`v=30`、倒立放大，原屏幕先失焦；只有`u`改變。比較卡必須尊重桌機 `14.5/15/15.5` 等合法觀察值。
- Trial 3：u=5、理論虛像 `v=-10`，只有完成三個不同停留觀察區才能宣告找不到清楚屏幕實像。移過 `u=10` 及 bench overflow 不顯示 NaN，不冒充虛像。**三區進度是操作證據，不等於證明物理全體可能性**；Concept 才說明模型和原因。
- Focus u=10 不顯示無窮的有限像距，bench 外 real 不會 sharp；模型所有計算不在 UI、CSS 重算。
- 光線圖與完整公式只在找到、比較證據後逐步揭露；虛像不等於「沒有光」，且不等於屏幕移得不夠遠。
- 不使用外部 CDN、不儲存學生身分、既有 1280／390／keyboard／screen reader／reduced motion gate 保留。
- 現有公開 `tools/science/optics.html`、`lenses.html`、`convex-lens-imaging.html` 保留原 URL；Pilot #1 在真人驗收及另行公開許可前維持 `noindex`。
