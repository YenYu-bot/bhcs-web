### M21 的規格
依交接包的要求，每題列成 ax²＋bx＋c＝0 後兩根中**恰有一個合理**，另一根因情境被捨去：負數或 0、非整數、超出題目範圍、或違反題目給的上下限。重根算唯一解。教用版的答案寫出設的未知數、化簡後的方程式、兩根、捨去的根與理由，最後寫答案。
講義裡有兩個合理解的題型（例如吊飾定價、旅行團收費），題目會自動加上限制條件（「定價不得低於 ○ 元」「每人收費不得超過 ○ 元」），讓答案只剩一個。
交接包初稿列的「增長率」不在講義 4-3 裡，所以沒有做。

## 正確性（verify 走另一條路）
- quadapps：兩根都代回方程式檢查；合理的根代回**題目敘述的原始關係**（例如「(底)×(高)÷2＝面積」「(x−b)×(x＋a)＝賣掉個數」，不是代回整理後的方程式）；捨去的根則檢查它確實違反題目條件。所以整理方程式時如果算錯，這一步就會攔下來。
- triineq：
  - 範圍題不是直接相信公式，而是在端點本身和端點內外各取值，用三角不等式逐一代回，確認只有範圍內的值成立。
  - 整數邊長用另一種方式重新列舉：所有排列都列出來再去掉重複。
  - 兩圓交點數用半弦長平方的正負來判斷。
  - 大邊對大角與外角題用餘弦定理或正弦值實際算出角度或邊長來比較。
  - 樞紐定理題用餘弦定理實際算第三邊或夾角；中線題則在坐標平面上把三角形真的畫出來，再量 ∠AMB 與 ∠AMC。

人工核對（全部代回確認過）：
1. 四邊形 AB＝16、BC＝11、CD＝6、DA＝20，對角線 AC → 14＜x＜26，共 11 個整數
2. 相異三邊 x、x＋8、40 → 16＜x＜32
3. x＋8、2x−2、x−3 為等腰三角形三邊 → x＝10（三邊 18、18、7）
4. ∠A 外角 131°、∠C 外角 74° → 最長 AB、最短 CA
5. AB＝AC，∠B＝(3x＋19)°，BC＜AB → 41/3＜x＜71/3
6. 客廳長比寬多 2、四周留 1 公尺、未鋪地毯面積＝地毯面積 → 寬 6、長 8
7. 君君 3 年後的年齡＝3 年前年齡的平方 → 6 歲（x＝1 捨去，3 年前是 −2 歲）
8. 布告欄 33×24 公寸分成 1 列 3 行，專欄區總面積 638 → 木條寬 1 公寸（77/4 捨去）
9. 以 612 元買水果、6 公斤腐爛、每公斤加 4 元賣出、賺 18 元 → 每公斤 17 元、共 36 公斤
