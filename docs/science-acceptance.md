# 自然教材現場驗收工作單

## 狀態界線

自動化驗證只能確認模型計算、DOM 流程、連結與已測瀏覽器行為；不能代表所有實體裝置相容，也不能代表學生已理解。以下未回填項目保持「待現場驗收」。

## 裝置矩陣（每項記錄型號、系統／瀏覽器版本、日期、結果）

| 裝置 | 必测行為 | 狀態 |
|---|---|---|
| Android 手機 | 直向390px附近、橫向、滑桿、返回、重新整理 | 待現場驗收 |
| iPhone Safari | 觸控、紀錄保存、私密模式、列印預覽 | 待現場驗收 |
| iPad／平板 | 直橫向切換、文字放大200%、觸控 | 待現場驗收 |
| 教室觸控電視 | 遠距可讀、觸控命中、連續操作20分鐘 | 待現場驗收 |
| 桌面鍵盤 | Tab順序、空白鍵、方向鍵、Enter、可見焦點 | 可自動測部分；實機待確認 |

每頁：無預測時不能揭露結果；修改任一條件後不得保存舊結果；重設清空本輪結果但保留既有紀錄；紀錄表可水平捲動且整頁不能橫向溢出；列印A4不裁切文字；減少動畫模式不自動播放。

## 教師試用（每主題至少1次）

- 年級／單元、教師、日期（只在校內填寫，不輸入網站分析）。
- 不口頭提示，學生能否在1分鐘內完成首次預測和操作？
- 能否只改一個變因並存下两筆可比較的紀錄？
- 能否用數據解釋結果，而非只背結論？
- 3題檢核最常錯哪一題？模型限制是否被誤認為真實定律？
- 記錄卡點、重現步驟、裝置、嚴重性；不要上傳學生姓名或影像。

## 第二批統一驗收案例

1. 每模型：典型值、零值／奇異點、極端控制值。
2. 每頁：無預測、錯誤預測、正確預測、改變條件、任務切換、重設、多筆紀錄、重新整理、全部答對／全部未答。
3. 儲存被封鎖、儲存資料格式損毀時仍可正常操作。
4. 每個新入口、canonical、schema、sitemap 均能映射到實際檔案。
5. 分析只送固定事件名與教材ID，不送自由文字、學生身份或答案。

## 匿名事件

`science_open`、`science_start`、`science_record`、`science_task_complete`、`science_quiz_complete`、`science_print`、`science_tool_open`、`science_course`、`science_consult`。

僅在既有GA可用且未設置 `bhcs_noga`／`?noga=1`、DNT或GPC時送出。無GA／離線時不影響教材。工作單與教師回饋不會送至GA。網站端事件測試不等於GA後台已驗收，正式後台DebugView仍需管理者核對。
