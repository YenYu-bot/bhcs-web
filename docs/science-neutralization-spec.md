# 酸鹼中和實驗室

用氫氧化鈉滴定鹽酸，觀察 pH 怎麼隨滴入的體積改變、在當量點附近怎麼突然跳升，以及過量的是哪一種離子。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 由 H⁺ 與 OH⁻ 的莫耳數判斷溶液是酸性、中性或鹼性
- 找出當量點的體積，觀察當量點附近 pH 的急遽變化
- 說明酚酞在滴定中的顏色變化

## 模型

H⁺ 的莫耳數＝鹽酸濃度×體積；OH⁻ 的莫耳數＝氫氧化鈉濃度×滴入體積。H⁺ 過量：pH＝－log[H⁺]；恰好相等：pH＝7；OH⁻ 過量：pH＝14＋log[OH⁻]；濃度以混合後的總體積計算。當量點體積＝鹽酸莫耳數÷氫氧化鈉濃度。

## 簡化限制

25°C，強酸強鹼完全解離，不計水的解離（當量點附近 pH 變化因此特別陡）。相對導電度以溶液中離子總濃度表示，忽略各種離子移動快慢的差異。弱酸、弱鹼不在本頁範圍。

## 引導任務

- ① 前段：從 0 mL 每次加 5 mL 到 20 mL，pH 變化大嗎？
- ② 當量點附近：從 24 mL 慢慢加到 26 mL，pH 怎麼變？酚酞什麼時候變色？
- ③ 繼續滴：當量點之後繼續滴，溶液裡多出來的是什麼離子？
