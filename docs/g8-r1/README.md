## topic `angles`（M16，百宏國二下講義 3-1）
| unit | 基礎 | 進階 | 挑戰 |
|---|---|---|---|
| pairs 對頂角、補角與餘角 | 求補角、求餘角、兩直線相交（附圖） | 同時求餘角補角、互補兩角的比 | 補角是餘角的 k 倍、三線共點 |
| triangle 三角形的內角與外角 | 求第三角（附圖）、外角（附圖）、直角三角形 | 三內角比並判斷形狀、由外角求內角（附圖） | 等腰三角形頂角底角、兩內角平分線交角、五角星形尖角和 |
| polygon 多邊形的內角和與外角和 | n 邊形內角和、外角和、四邊形第四角（附圖） | 由內角和求邊數、缺一角的 n 邊形 | 內角和比外角和多、內角和是外角和的 k 倍、缺一外角 |
| regular 正多邊形 | 內角與外角、內角和、看圖求內角 | 由外角或內角求邊數 | 內角是外角的 k 倍、內角比外角大 d°、鋪地磚 |
| equation 列方程式求角度 | 三內角含 x、互補含 x、外角定理含 x | 四邊形含 x | 等腰三角形含 x、係數不同的外角定理、外角比例求 x |

角度一律整數度，只提供整數模式。

## 正確性
每題的驗算走另一個關係（例：外角題驗「外角＋第三內角＝180°」，邊數題驗「(n−2)×180＝內角和」，鋪地磚驗「360 能否被內角整除」與 3、4、6 的已知結果一致）。人工核對：∠A＝71°、∠B＝44° → 外角 115°；四邊形 74°、86°、129° → 71°；正 12 邊形內角 150°；∠B＝27°、外角 120° → ∠A＝93°；∠1＝53° → ∠2＝127°、∠3＝53°。
