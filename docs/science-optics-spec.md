# 光學與透鏡成像實驗室

調整凸凹透鏡與物距，從兩條光線和像距讀值判斷實像、虛像與焦點奇異情況。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 辨認實像與虛像的不同
- 比較物距、像距與放大率
- 說明物體在焦點時為何無法在有限距離成像

## 模型

1/f = 1/u + 1/v；m = −v/u。凸透鏡 f>0，凹透鏡 f<0；實物 u>0。

## 簡化限制

理想薄透鏡、近軸光線；不計色差、球差及鏡片厚度。光線圖會等比例縮放以納入像的位置；焦點附近的極遠像可能讓物體顯得很小。虛線為反向延長線，不是真正反向行進的光。

## 引導任務

- ① 物體在兩倍焦距外：固定焦距10cm，比較物距30和40cm。像的位置與大小怎麼變？
- ② 物體移到焦點內：先猜像的方向與是否能投影，再和物距10cm比較。
- ③ 換成凹透鏡：保持物距，換成凹透鏡，觀察光線或反向延長線在哪裡相交。
