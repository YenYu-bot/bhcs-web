# 靜電與感應起電實驗室

把帶電棒靠近放在絕緣座上的金屬球，比較只靠近、接地、兩種移開順序與接觸起電的結果；圖上只畫電子怎麼移動。

年段：國中（依各校版本調整）。建議10–15分鐘。

## 學習目標

- 說明帶電棒靠近時金屬球兩端的電性（極化）
- 比較感應起電的兩種移開順序為什麼結果不同
- 區分感應起電與接觸起電最後的電性

## 模型

同性相斥、異性相吸。金屬中能移動的是電子：帶負電＝電子比質子多，帶正電＝電子比質子少。感應起電：帶電棒靠近並接地，電子經接地線移動；先斷接地再移開棒，導體帶與棒相反的電。接觸起電：電子在棒與導體之間直接轉移，導體帶與棒相同的電。

## 簡化限制

定性模型：圖中正、負號只表示電荷分布的方向與相對多寡，不是實際數量；只畫電子移動，正電荷（原子核）位置固定不動。金屬球放在絕緣座上，空氣乾燥、不漏電。帶電棒的電性依常見的摩擦組合：塑膠棒摩擦毛皮帶負電、玻璃棒摩擦絲綢帶正電。

## 引導任務

- ① 只靠近：帶負電的棒只靠近：金屬球有沒有帶電？靠近棒的那一端和遠端各帶什麼電？
- ② 兩種移開順序：先移開接地、再移開帶電棒，最後帶什麼電？再改成「先移開帶電棒」比較。
- ③ 接觸起電：接觸後移開，金屬球最後帶什麼電？和任務②的感應起電差在哪？
