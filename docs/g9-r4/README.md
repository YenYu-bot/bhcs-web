## 內容
`circle1` 圓：扇形、切線與弦心距，依國三上二段講義 2-1，6 個單元（基礎／進階／挑戰）：
- sector 弧長與扇形面積：由半徑與圓心角求面積、周長；由弧長求面積；由圓面積求扇形／由周長反求圓心角與面積；由弧長求圓周長；同心圓兩弧與其間面積／兩扇形之間的周長與面積；由面積反求圓心角。
- segment 弓形、環形與部分面積：環形；正方形四角四分之一圓；正方形內切圓／弓形（60°、90°、120°）；長方形內扇形／由環形面積比求半徑比；正方形內兩個四分之一圓夾出的區域。
- position 點、線與圓的位置：點與圓、直線與圓的交點數、不可能的弦長／坐標點與圓（含 √）／兩相交圓的區域。
- tangent 切線與半徑：切線長（畢氏數、根式）、AC＝AO−r／∠P＝30°、圓外一點最近與最遠距離／∠P＝45°、內切圓半徑與過圓心的切線、坐標平面的切線長。
- tangentLen 切線長性質：∠APB 與 ∠AOB 互補、外切四邊形對邊和／三邊切點分段與 ∠POR、由三邊求 AD／內切圓的圓心角、含 x 的外切四邊形、內切圓對角互補。
- chord 弦心距：半徑、弦長、弦心距三量互求／兩弦的弦心距、平行弦的距離（兩解）、切小圓的弦與環形面積／直徑平分弦、過一點最短與最長的弦。

含 π 與根式的答案用精確式（如 18π、55−25π／4、8√5＋24），正項排前。數型：sector 整數＋分數，其餘整數。圖：扇形、同心圓、正方形內圓弧、切線、弦心距用內建的 SVG 圓弧（顏色只用 #16233A），已知條件寫在題幹文字裡。
