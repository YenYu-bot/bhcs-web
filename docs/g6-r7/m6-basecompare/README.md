## 改了什麼
新 topic `basecompare`，六個 unit：
- `identify` 基準量、比較量與比值（「是」前後、甲：乙、甲÷乙、「當作 1」、兩個數互求幾分之幾與幾倍、換基準量）
- `numline` 雙數線填空（SVG；上方是量、下方是倍數，刻度依倍數等比例；進階起含 0 與單位，挑戰不含 1 倍刻度）
- `arcline` 線段弧線圖（SVG；兩段或三段，求全部、求標 1 的段、求某一段）
- `findbase` 已知比較量求基準量（大小二數、牛奶、布還剩、男生女生、竹竿插水、某數加減、年齡）
- `sumdiff` 和倍差倍與應用（和／差／求差、牛羊相差、雞鴨、長方形周長、桃子與梨子價錢、各加減同數、用錢、給錢）
- `discount` 加成與折扣（加幾成、比原價少百分之幾；求售價、求原價、求多賺多少、由原價售價求成數）

數型勾選覆寫標籤：整數倍／分數倍／小數倍與百分率。`findbase` 只提供分數與小數（題意本身是部分量）；`discount` 只提供整數（成數）與小數（百分率、二成五）。

## 正確性（verify 走不同路徑）
雙數線：出題用「1 倍的量×倍數」，驗證用「已知格的量÷倍數」算出 1 倍再比對；線段圖：求全部用各段相加驗證、求部分用全部÷倍數和；文字題一律把答案代回原句（例：各減 15 後甲＝乙×1.5、剩餘錢兄＝弟×1.4、售價＝原價×（1＋成數））。

人工核對：雙數線 8／1、（①）／6、64／（②）→ 48、8；線段 30（1）＋4 倍 → 150；2、3、1 三段全部 540 → 90；60（1）＋20 % → 12；兄弟共 781、媽給兄 120 弟 60、兄是弟 2.1 倍 → 531、250；加二成五售 4125 → 3300；原價 1650 售 2475 → 加五成；男生占 0.8、56 人 → 全校 70、女生 14；某數減 5 剩 0.9 → 50；父親 40 歲是女兒 2½ 倍 → 6 年後 22 歲。全對。
