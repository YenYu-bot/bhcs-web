## 改了什麼
新 topic `speed`，六個 unit：`findv` 求速率、`findd` 求距離、`findt` 求時間、`convert` 單位換算、`average` 平均速率、`meet` 相遇與追趕。沒有圖，不涉及 SVG 顏色。所有題目從答案反推，題面數值乾淨；時間可用複名數（1 小時 20 分、3 分 39 秒）與時刻（上午／中午／下午）。

## 各單元三難度題型
| unit | 基礎 | 進階 | 挑戰 |
|---|---|---|---|
| findv | 時速、分速、秒速（單位一致） | 複名數時間、公里與分鐘求分速、公尺與秒求時速 | 兩車不同單位比快慢、複名數與公里求分速 |
| findd | 時速、分速、秒速 | 複名數時間、分速求公里、時速與分鐘 | 兩段路程、由出發到達時刻求距離、分秒複名數 |
| findt | 求小時、分鐘、秒 | 答案化成幾小時幾分、公里對分速、幾分幾秒 | 到達時刻、最晚出發時刻、耽擱後到達時刻 |
| convert | 時速↔分速、秒速→分速 | 時速↔秒速、分速→秒速 | 一次化成分速與秒速、兩者比快慢、三者排序 |
| average | 兩段距離與時間、來回給時間、多段總和 | 兩段速率與時間、中途休息 | 同一段路來回、上下坡、前後半路程（答案附「不是兩速率平均」的對照） |
| meet | 同時相向、同向追趕、反向相距 | 相遇地點、先出發後追、相遇前還相距多少 | 環形跑道同向追及、反向相遇、追上時離出發點多遠 |

平均速率的 `tip` 依規格點出「總距離÷總時間，不是兩個速率相加除以二；休息時間也要算」。

## 正確性（verify 走不同路徑）
求速率用「距離÷時間」出題、以「速率×時間＝距離」或換成分鐘再算驗證；換算用反向換算；平均速率以「平均×總時間＝各段距離和」驗證，同段來回另以公式 2ab÷(a+b) 比對；相遇追趕把時間代回兩人各自的距離；排序題改用分速重新比較。

人工核對：甲車 2 小時 48 公里、乙車 40 分 40000 公尺 → 乙快 36 公里/時；143 公里時速 52、上午 9:48 出發耽擱 15 分 → 中午 12:48；去 45、回 36 → 40（不是 40.5）；上坡 42、下坡 105 → 60；相距 561.05、時速 78 與 36.5 → 4.9 小時、甲走 382.2；乙先走 16 分（分速 40）、甲分速 100 → 32/3 分、3200/3 公尺；時速 27 → 秒速 15/2；分速 1100 → 時速 66；秒速 5、4 秒 → 時速 72（題：4 秒 80 公尺）；2 小時 50 分 170 公里 → 60。全對。
