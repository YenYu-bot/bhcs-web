# 波動、聲音與共振實驗室

從波速、頻率與波長出發，比較開管與閉管的共振條件；不把音高和音量混為一談。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 使用 v=fλ 解釋波長
- 比較開管與閉管的共振頻率
- 辨識位移的波節與波腹

## 模型

λ=v/f。兩端開管 fₙ=nv/(2L)；一端閉管 fₙ=(2n−1)v/(4L)。

## 簡化限制

理想一維空氣柱，不計管徑、端點修正及損耗。差距不超過最近模態頻率3%時標記「接近共振」，3%是介面教學容差，不是真實共振峰寬。曲線是空氣質點的縱向位移以橫向曲線表示，不是粒子沿曲線跑。開口是位移波腹，閉口是位移波節；壓力分布相反。

## 引導任務

- ① 頻率與波長：只把頻率加倍，比較波長；注意聲速維持不變。
- ② 開管基頻：固定長度1m，先預測170Hz的狀態，再比較250Hz。
- ③ 閉管與開管：比較85、170、255Hz，不要假設所有整數倍都能共振。
