# P3 題型多樣性 baseline（報表模式）

本階段只量測、不阻擋 CI。執行方式：

```bash
MATH_DIVERSITY_REPORT=docs/math-diversity/baseline-20260922.json node scripts/test_math_drills.mjs
```

## 量測定義

- 每個 unit、每個難度各以正式 `safeQuestion()` 產 200 題；本次共 483 units、289,800 題，全部成功取題，重試耗盡 0。
- 結構正規化：SVG 變成 `[圖]`；分數、上下標位置保留；每個數字 literal 換成 `#`，正負號、係數所在位置、比較符號與文字模板保留。
- 數字中位數：擷取 200 題題面中的所有非負數字 literal 後取中位數；挑戰／基礎比值以兩者中位數相除。
- JSON 每個難度保留結構總數與前 2 個可讀範例；挑戰相對基礎另記新增結構數與範例。
