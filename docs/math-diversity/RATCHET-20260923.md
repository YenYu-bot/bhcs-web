# P3 題型多樣性棘輪門檻（2026-09-23）

|---|---|---|
| `gcd` | `factor`、`gcd2`、`gcd3`、`lcm2`、`lcm3` | 純算法 |

`standarddev/zcompare`、`correlation/fromsums`、`matrixapps/stationary` 未核准，仍須在 P4 補反求或線性變換題型。

`singleForm` 只豁免每個難度「結構數至少 3」；挑戰級仍須相對基礎新增至少 1 種結構，或數字中位數至少 2 倍。

## CI 棘輪

每個 unit、每個難度固定產 200 題，使用固定 seed。baseline 保存結構數、門檻結果與完整輸出指紋；CI 執行下列規則：

1. 既有 unit 不得被移除，成功取題數與結構數不得低於 baseline。
2. baseline 已通過的結構門檻或挑戰差異門檻不得退回失敗。
3. 題面或答案輸出指紋變動的 unit，必須同時通過結構門檻與挑戰差異門檻。
4. 新 unit 必須直接通過完整門檻，且不得新增 `singleForm` 豁免。
5. 豁免集中在 `scripts/math-diversity-policy.mjs`；筆數固定為 21，須與 baseline 的核准清單逐筆相同。重複、替換、刪除或新增豁免都會使 CI 失敗。

棘輪本身另有合約回歸，覆蓋結構數下降、已修改 unit 未過完整門檻、新 unit 冒用豁免及 baseline unit 被移除。
