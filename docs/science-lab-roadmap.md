# 自然互動教材執行路線

## 排序原則

優先製作「學生很難只靠課本文字建立畫面、又能用可靠模型呈現」的單元；同時兼顧國中課程覆蓋、現有教材缺口、手機操作與可重複使用的元件。

| 階段 | 教材 | 核心學習問題 | 可重用能力 |
|---|---|---|---|
| 1 | 電路虛擬實驗室 | 開路、串聯、並聯的電流與電壓如何改變？ | 儀表讀值、實驗紀錄、預測流程 |
| 2 | 力與運動實驗室 | 合力、質量與加速度之間有什麼關係？ | 時間動畫、向量、位置／速度圖 |
| 3 | 粒子與化學反應 | 巨觀現象背後的粒子如何重排？ | 粒子引擎、守恆檢查、方程式 |
| 4 | 虛擬顯微鏡 | 倍率、視野、焦距與切片方向如何互相影響？ | 分層影像、拖曳視野、標本辨識 |
| 5 | 板塊與地震 | 板塊邊界如何造成地震、火山與地形？ | 地圖剖面、事件時間軸、資料疊圖 |
| 6 | 熱與物態 | 加熱時溫度為何有時不再上升？ | 曲線圖、能量流、粒子模型 |
| 7 | 浮力與密度 | 浮沉由重量、體積與排開液體如何共同決定？ | 力圖、液面、密度計算 |
| 8 | 酸鹼與指示劑 | 濃度、酸鹼值與中和如何連動？ | 混合模型、刻度、顏色對照 |
| 9 | 光合作用因素 | 光、二氧化碳與溫度如何影響反應速率？ | 多變因實驗、速率圖、控制變因 |
| 10 | 遺傳模擬 | 基因型如何形成配子與子代表現型？ | 機率抽樣、龐氏方格、分布比較 |

每完成一項都必須通過共用規格的科學、互動、內容、技術及教學五類驗收，才進入下一項。

目前進度：第 1 至第 6 階段「電路虛擬實驗室」、「力與運動實驗室」、「粒子與化學反應實驗室」、「虛擬顯微鏡」、「板塊與地震實驗室」及「熱與物態實驗室」已完成並接入官網；下一項為「浮力與密度」。

## 共用製作 Prompt

以下規格不是請模型自由發想，而是每次實作時的固定工作單；使用時把中括號內容換成該單元的資料。

> 你是臺灣國中自然科教材設計師、前端工程師與科學模型審查者。請在現有百宏文教網站中製作一個不依賴外部框架的互動教材「[教材名稱]」，適用於[年級／單元]。請遵守 `docs/science-lab-standard.md`，並以正體中文呈現。
>
> 學習目標：[列出 3–5 個可觀察的學習成果]。
>
> 必須讓學生完成「預測 → 操作 → 觀察 → 記錄 → 解釋 → 檢核」。核心變因為[自變因]，觀察量為[依變因]，控制變因為[控制變因]。科學模型採用[公式／規則]；簡化條件為[模型限制]，必須在頁面上明說。危險或不適合真實重做的操作只能用模擬警示呈現。
>
> 介面須包含基礎與進階模式、即時圖像、含單位的數值、至少一份可加入多筆資料的紀錄表、三題具診斷回饋的檢核，以及教師提示。若使用拖曳，必須提供非拖曳的替代操作。390px 手機寬度不得產生整頁橫向捲動，鍵盤可完成核心任務，並支援 `prefers-reduced-motion`。
>
> 交付前先列出模型驗收案例，至少涵蓋典型值、邊界值、開路／零值或其他無效狀態；再檢查 JavaScript 語法、重複 id、標籤對應、內部連結、canonical、Sitemap 與資源頁入口。不得以好看的動畫取代正確數值，也不得捏造超出模型能回答的結果。

## 每階段交付門檻

1. 規格：學習目標、模型、限制、驗收值已寫入 `docs/`。
2. 原型：核心流程可從頭完成，不需閱讀開發說明。
3. 驗證：公式測試、語法檢查、連結檢查與手機版檢查通過。
4. 接入：資源頁數量、說明、canonical 與 Sitemap 同步更新。
5. 上線：提交 GitHub 後檢查公開網址，再開始下一個教材。
