# 遺傳模擬實驗室規格

## 第一版學習範圍

- 區分基因型與表現型，以及純合顯性、異合、純合隱性。
- 由親代基因型列出可能形成的配子，理解每個配子只帶一個等位基因。
- 使用 `2 × 2` 龐氏方格列出四個等可能的配子組合。
- 計算子代基因型與表現型的理論比例。
- 以 `4、20、100、1000` 個子代進行隨機抽樣，比較觀察比例與理論機率。
- 理解 `3 : 1` 只出現在特定的異合單性狀雜交中，不是所有遺傳題的固定答案。

## 單性狀完全顯性模型

提供三個孟德爾豌豆例子：

| 性狀 | 顯性等位基因與表現型 | 隱性等位基因與表現型 |
|---|---|---|
| 莖高 | `T`，高莖 | `t`，矮莖 |
| 種子顏色 | `Y`，黃色 | `y`，綠色 |
| 種子外形 | `R`，圓粒 | `r`，皺粒 |

每個親代可選純合顯性、異合或純合隱性。內部以顯性等位基因數 `2、1、0` 表示三種基因型。

### 配子規則

- 純合顯性：只產生顯性配子，機率 100%。
- 異合：顯性、隱性配子各 50%。
- 純合隱性：只產生隱性配子，機率 100%。

為維持 `2 × 2` 龐氏方格，純合親代的相同配子會重複列出兩次；四格仍代表四個等可能組合。

### 子代規則

兩個配子各提供一個等位基因：

- 兩個顯性等位基因：純合顯性，顯性表現型。
- 一顯性、一隱性：異合，完全顯性模型中為顯性表現型。
- 兩個隱性等位基因：純合隱性，隱性表現型。

理論機率為四格中各類型格數除以 4。

### 隨機抽樣

每個模擬子代以均等機率從四個龐氏方格抽取一格。每個子代視為獨立抽樣；抽樣次數增加時，觀察比例通常更接近理論值，但不保證完全相等。

## 模型限制

- 只處理單一基因座、兩個等位基因、完全顯性、配子機率相等且各配子受精機會相同的情況。
- 不處理不完全顯性、共顯性、複等位基因、性聯遺傳、致死基因、基因連鎖與互換、多基因遺傳、粒線體遺傳或環境造成的表現差異。
- 不模擬減數分裂的染色體行為、突變、配子存活率、胚胎死亡或族群選汰。
- 豌豆性狀用於呈現孟德爾模型，不代表所有可觀察性狀都遵循相同規則。

## 驗收案例

1. 異合 × 異合：四格為純合顯性 1、異合 2、純合隱性 1；基因型 `1 : 2 : 1`，顯性／隱性表現型 `3 : 1`。
2. 異合 × 純合隱性：純合顯性 0、異合 2、純合隱性 2；表現型 `1 : 1`。
3. 純合顯性 × 純合隱性：四格全部異合，顯性表現型 100%。
4. 純合隱性 × 純合隱性：四格全部純合隱性，隱性表現型 100%。
5. 純合顯性 × 純合顯性：四格全部純合顯性，顯性表現型 100%。
6. 異合親代配子為兩種且各占 50%；純合親代只有一種配子且占 100%。
7. 任意抽樣結果的三種基因型次數總和必須等於設定的子代數。
8. 相同親代重複抽樣可以出現不同觀察次數，但理論比例保持不變。
