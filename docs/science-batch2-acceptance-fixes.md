# 第二批驗收修正（2026-09-18）

基準：49f54ff51716d0dcce04c8aa4b7a28adc88bcbe8。

## 本輪修正

1. 列印原本隱藏讀值，改為黑白也可讀的數值框，同時列出本輪有效條件、預測與尚未存入紀錄的解釋；支援網頁列印按鈕與瀏覽器列印。
2. 紙本紀錄由五欄表格改為逐筆段落，長解釋可跨頁；保留模型限制與安全提醒，省略選單、操作按鈕、檢核及重複導覽。
3. 設定與預測在DOM閱讀順序中移到結果之前；900px以下改為先設定、再觀察，加入結果與解釋的跳轉連結。
4. 560px以下圖解可在自身區域橫向捲動，避免文字整張縮小；控制標籤與數值可換行，讀值改為單欄。圖解區可用鍵盤聚焦。
5. 電磁模型外加磁場為0時不再畫出磁場箭頭；角度改以固定向右基準軸定義，明確說明負磁場與轉矩方向。發電說明改用磁通量／變化率的絕對值，避免負磁場時誤稱「最大」。
6. 新增紀錄與目前條件只列出當前模式有效參數，不混入未使用的氣體體積、轉速等。歷史紀錄原樣保留。
7. 檢核題未作答時不先透露解析；改選答案後清除該題舊回饋，避免仍顯示「答對」。統一部分繁體用字。
8. 修正浮點誤差造成的「-0 V／-0 N·m」顯示；四捨五入後為零的讀值統一顯示0，避免與零輸出判斷矛盾。
9. 螢幕紀錄表固定合理欄寬，避免條件文字將「預測」擠成逐字直排；列印按鈕先準備本輪快照，瀏覽器列印事件另行更新。
