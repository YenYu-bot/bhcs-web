# P4-4　g10 `quadratic`（二次函數與對稱性） 題型補強（2026-09-23，Claude）

累積包：`tools/math/g10-drills.html` 含 absolute、inequalities、linecircle、quadratic 四個 topic 的改動。本 topic 只改 `quadraticFunctionsConfig()`，unit id、名稱、modes 不變，基礎級保留原題型。

## 每個 unit 新增了什麼

| unit | 基礎（原有） | 進階新增 | 挑戰新增 |
|---|---|---|---|
| 配方與頂點 | 配方求頂點 | 頂點式展開與 y 截距；由對稱性說明 f(h−t)＝f(h＋t) | 已知極值反求 c |
| 平移 | 由 y＝ax² 平移 | 由頂點式平移 | 反推平移方式；平移使頂點到原點 |
| 反求函數 | 兩零點＋首項係數 | 兩零點＋y 截距；頂點＋一點 | 通過三點（x＝0、1、−1） |
| 區間極值 | 頂點在區間內 | 頂點在區間外（極值都在端點） | 由區間極值反求 k |
| 判別式 | 與 x 軸交點個數 | 與 x 軸相切的 k（兩解） | 與直線的交點個數（相減後看 Δ）；兩交點的 k 範圍 |
| 對稱性 | 由對稱求函數值 | 由 f(p)＝f(q) 求對稱軸 | 由 f(p)＝f(q) 求 b；不算函數值比較大小 |
| 最佳化 | 周長固定求面積；兩數和求積最大／平方和最小 | 靠牆圍籬；拋體最高點 | 營收模型（漲價減銷量） |

## 正確性
所有反求題的 `verify()` 都把宣稱的函數代回題目給的每一個條件（零點、截距、通過的點、極值）逐一核對；區間極值另在區間內取 21 個等分點確認沒有值超出宣稱的最大最小；營收與圍籬用鄰近整數值確認是極值。

## 每種新結構的樣本

### advanced／配方法與頂點

- f（x）＝2x2＋18x＋852，不配方，只用對稱性說明 f（−193）與 f（−83）的關係，並求對稱軸。　→　f（−193）＝f（−83）；對稱軸 x＝−92
- 將 f（x）＝2（x−4）2 ＋ 52 展開成 ax²＋bx＋c 的形式，並寫出 y 截距。　→　f（x）＝2x2−16x＋692；y 截距 692
- 將 f（x）＝2x2＋20x＋48 配方，並求頂點、對稱軸與極值。　→　f（x）＝2（x＋5）2 − 2；頂點（−5，−2）；對稱軸 x＝−5；最小值 −2
- 將 f（x）＝−3x2−6x−10 配方，並求頂點、對稱軸與極值。　→　f（x）＝−3（x＋1）2 − 7；頂點（−1，−7）；對稱軸 x＝−1；最大值 −7
- 將 f（x）＝−x2＋4x−1 配方，並求頂點、對稱軸與極值。　→　f（x）＝−（x−2）2 ＋ 3；頂點（2，3）；對稱軸 x＝2；最大值 3

### advanced／圖形平移
