# 互動教材視覺與自學體驗更新

範圍：兩批 20 頁共用版面與自學指引；顯微鏡、遺傳、力與運動、月相四頁的重點互動與圖像。

## 已實作

- 全部 20 頁：三步自學起點，包含本單元的第一個操作、觀察重點與比較任務；取消遮擋內容的浮動段落導覽，補足容器收縮與錨點留白。
- 遺傳：修正通用表格 `min-width:920px` 誤套到龐氏方格的根因；方格可點擊或鍵盤操作，逐格解釋親代配子、子代基因型與表現型。加入豌豆性狀插畫。
- 力與運動：小車外觀改用插畫；運動區與受力比較區分開。各水平力分列，垂直力獨立顯示，修正 SVG 箭頭依線寬放大造成遮擋的問題。
- 顯微鏡：試片操作台支援滑鼠、觸控 Pointer Events、方向按鈕與鍵盤方向鍵／Home。方向與既有光學反像模型一致；有範圍限制、拖曳取消處理、每幀一次繪製，以及依狀態變動的下一步提示。
- 月相：地面月相與太空位置分成兩張視圖；月面紋理使用插畫，亮暗邊界由模型計算。新增四個角度捷徑，進階軌道條件收合；完成預測後可自由拖動滑桿即時觀察。自由觀察不沿用舊預測，也不能保存過期的觀察結果。

## 程式驗收

- 既有 20 教材互動、第二批 21 組模型回歸通過。
- 新增拖曳前置條件、反向位移、邊界、取消、鍵盤、換標本引導重設測試。
- 新增遺傳格子選取、切換性狀、月相捷徑、即時觀察與紀錄失效測試。
- 73 個月相角度的繪圖亮面面積，與解析式 `(1−cosα)/2` 誤差小於 0.001。
- JSDOM 不代表真實排版驗收；仍需正式站目視檢查。實體觸控手機、投影與列印需另行實測，不以 Pointer Events 單元測試替代。

## 維護

共用體驗來源：`scripts/science/experience.css`、`experience.mjs`，由 `build_science.mjs` 內嵌至各頁。顯微鏡繪圖另執行 `build_microscope.mjs`。圖片在 `assets/science/`，提示詞見 `science-art-prompts.md`。

核心模型與操作不依賴外部框架；離線使用若要保留插畫，請連同 `assets/science/` 一起下載並保留相對路徑。
