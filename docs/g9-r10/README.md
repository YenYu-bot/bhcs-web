## 內容（A 類）
依舊工具 `tools/math/g9b-2-2-probability.html` 的四個單元重做。只做一次試驗的機率（兩次以上的試驗在 r11 treediagram）。每個單元五種問法，基礎取第 1～3 種、進階第 2～4 種、挑戰第 3～5 種：
- `bag` 袋中取球：兩色球、三色球與「不是」、放入球後的機率、由機率反求球數、要再放入幾顆球才使機率為指定值。
- `numbers` 整數籤筒與倍數：兩個倍數、既是又是與都不是、質數與完全平方數（或二位數）、任意範圍的倍數（是／不是）、「或」的倍數與個位數字。
- `dice` 投擲一顆骰子：等於／大於／小於某點數、兩個倍數與大於等於、奇偶質合數與因數、六面寫特殊數字的骰子、正四／八／十二／二十面體骰子。
- `poker` 撲克牌：花色、紅黑、A、人頭牌、數字牌、「不是」某種牌、取走四張同點數後的機率、「或」事件（排容）。
答案一律最簡分數（數型只有一種，標示為「最簡分數作答」）。舊工具的球袋、籤筒、骰子、撲克牌示意圖只是裝飾，引擎沒有移植；條件都在題幹。舊工具的線上作答、計時、匯出不在引擎範圍。
