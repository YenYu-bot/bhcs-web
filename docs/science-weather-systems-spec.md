# 天氣系統實驗室

切換北半球與南半球的高氣壓、低氣壓與颱風，看近地面風怎麼轉、中心空氣往上還是往下；再比較冷鋒、暖鋒與滯留鋒過境前後的天氣。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 說出北、南半球高低氣壓近地面的風向
- 連結中心的上升或下沉氣流與晴雨
- 比較冷鋒、暖鋒、滯留鋒的雲、降雨與過境後氣溫變化

## 模型

北半球：高氣壓順時針向外吹出、中心下沉；低氣壓逆時針向中心吹入、中心上升。南半球旋轉方向相反，往內往外不變。颱風是強烈的熱帶低氣壓。冷鋒：冷氣團推向暖氣團，積雨雲、雨勢急而短，過境後降溫；暖鋒：暖氣團爬上冷氣團，層狀雲、雨勢緩而久，過境後升溫；滯留鋒：冷暖氣團勢力相當，長時間降雨（臺灣梅雨）。

## 簡化限制

定性模型：只呈現風向、氣流與天氣的典型型態，不計算風速、氣壓數值與移動速度。近地面風向與等壓線的夾角固定畫約 30°，真實夾角隨地面摩擦而變。鋒面剖面的坡度只是示意；實際天氣會受地形與季節影響。

## 引導任務

- ① 北半球低氣壓：近地面的風怎麼轉？往中心吹進去還是往外吹出來？中心的空氣往上還是往下？
- ② 只改成南半球：只改半球，旋轉方向和往內往外各有沒有變？
- ③ 比較冷鋒與暖鋒：記下冷鋒過境後的氣溫變化，再只把鋒面改成暖鋒，變化方向為什麼相反？
