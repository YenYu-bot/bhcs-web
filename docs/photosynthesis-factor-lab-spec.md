# 光合作用因素實驗室規格

## 第一版學習範圍

- 以水草產氧情境比較光照強度、二氧化碳濃度與溫度對光合作用速率的影響。
- 練習一次只改一個自變因，固定其他控制變因，再用多筆紀錄判斷因果。
- 看懂光照與二氧化碳反應曲線的上升、逐漸飽和與平臺。
- 理解溫度有適合範圍，並非愈高愈好。
- 由三項條件中最低的因子找出目前限制因子，解釋為何提高非限制因子可能沒有作用。

## 限制因子模型

第一版使用無量綱因子 `0–1` 與相對速率，不宣稱是真實植物的固定數據。

### 光照因子

以飽和曲線表示低光時增加明顯、高光時逐漸趨緩：

`f光 = (1 − e^(−I/35)) / (1 − e^(−100/35))`

其中 `I` 為光照百分比 `0–100%`，並把結果限制在 `0–1`。

### 二氧化碳因子

以飽和曲線表示原料濃度增加後效益逐漸降低：

`fCO₂ = [C / (C + 300)] / [1200 / (1200 + 300)]`

其中 `C` 為 `0–1200 ppm`；`C = 0` 時因子為 0，結果限制在 `0–1`。

### 溫度因子

採便於國中生判讀的分段線性概念模型，最適溫度固定為 `25°C`：

- `T ≤ 5°C` 或 `T ≥ 45°C`：`f溫 = 0`。
- `5°C < T ≤ 25°C`：`f溫 = (T − 5) / 20`。
- `25°C < T < 45°C`：`f溫 = (45 − T) / 20`。

### 相對速率與限制因子

`相對光合作用速率 = 20 × min(f光, fCO₂, f溫)`

三項中最低者標示為限制因子；若兩項以上與最低值相差不超過 `0.025`，標示為「兩項以上接近」。30 秒模擬產氧量固定為 `速率 × 0.5` 相對單位，只用來對應動畫與比較快慢。

## 模型限制

- 這是為了呈現控制變因與限制因子的概念模型，不是從特定植物實驗迴歸出的預測公式。
- 最低值模型會產生較明確的限制因子與平臺；真實生物反應通常是多因子連續交互作用，不會完全由單一最小值切換。
- 未納入水分、葉面積、葉齡、植物種類、光質、養分、氣孔、呼吸作用、日夜節律及適應時間。
- 本頁呈現的是相對「總光合作用」速率；黑暗時取 0，沒有繪製呼吸造成的淨氣體交換負值。
- 氧氣泡動畫與相對產氧量不是實測體積，也不代表所有水草會以固定比例產生可見氣泡。
- 真實實驗若使用水草、燈具與碳酸氫鈉，仍需控制水量、植物長度、量測時間、燈具發熱及重複次數。

## 驗收案例

1. `光照 0%、CO₂ 1000 ppm、25°C`：光照因子與相對速率皆為 0，限制因子為光照。
2. `光照 100%、CO₂ 0 ppm、25°C`：CO₂ 因子與相對速率皆為 0，限制因子為 CO₂。
3. `光照 100%、CO₂ 1200 ppm、25°C`：三因子皆為 1，相對速率為 20，標示兩項以上接近。
4. `光照 100%、CO₂ 1200 ppm、5°C` 與 `45°C`：溫度因子與速率皆為 0，限制因子為溫度。
5. `光照 15%、CO₂ 1000 ppm、25°C`：限制因子為光照。
6. `光照 90%、CO₂ 150 ppm、25°C`：限制因子為 CO₂。
7. `光照 90%、CO₂ 1000 ppm、10°C`：限制因子為溫度。
8. 溫度因子在 `25°C` 為 1，在 `40°C` 為 0.25；可見超過最適溫度後速率下降。
9. 光照因子 `80% > 40%`、CO₂ 因子 `800 ppm > 400 ppm`，但整體速率永不超過 20。
