# 潮汐實驗室

改變月齡與一天中的時刻，看月球的引力怎麼讓海水隆起、一天為什麼有兩次滿潮，以及大潮、小潮與月相的關係。

年段：國中（依各校版本調整）。建議10–15分鐘。

## 學習目標

- 說明一天約有兩次滿潮、兩次乾潮
- 說明新月與滿月時是大潮、上弦與下弦時是小潮
- 知道每天的滿潮時間大約往後延 50 分鐘

## 模型

簡化的半日潮：潮高＝潮差因子×cos（2π×(時刻－延遲)÷12.42）。滿潮間隔約 12 小時 25 分；每過一天延遲約 50 分鐘。潮差因子＝0.6＋0.4×|cos(2π×月齡÷29.5)|：新月、滿月（太陽、月球、地球大致成一直線）時最大，上弦、下弦時最小。

## 簡化限制

簡化模型：只考慮月球與太陽的引潮力方向，不計海岸地形、海底深度與季節；各地實際的潮汐型態（半日潮、全日潮、混合潮）與時間都不同。潮高以相對值表示，不是實際公尺數；本頁不能當作潮汐預報。

## 引導任務

- ① 一天兩次滿潮：把時刻從 0 調到 24：這一天有幾次滿潮？間隔大約多久？
- ② 大潮與小潮：記下新月的潮差，再把月齡改成 7.5（上弦）：潮差變大還是變小？為什麼？
- ③ 滿潮每天往後延：比較月齡 0 與月齡 1 的下一次滿潮時間，差了多少？
