## 內容
`ratio` 比例，由舊的 `tools/math/g7-ratio.html` 移植：有理數、一次式、比與比值、繁分數、比例式、連比工具與十一個單元（比與比值含單位換算、繁分數化簡、比例式求 x、比例式求比值、方程式求比值、比例式與方程式求值、連比、連比例式求 x、y、連比活用、連比與求值、綜合練習）照舊，只換成引擎的難度／數型介面；對齊表、分隔符、帶分數改用內嵌樣式。
差異：為了讓每個單元有不同的題型結構，「比例式求比值」有三種問法（比值、除以…的值、設…求比值）、「繁分數化簡」有三種寫法（繁分數、求…的值、挑戰級的 a÷b）、「連比例式」挑戰級一半的題加問 x＋y。數型：整數、分數、小數。作答列不印前綴。與 g9 的 `ratio3` 是不同年段的獨立主題，兩者都保留。
