# 生態系、食物網與族群實驗室

先讀懂食物網箭頭，再比較營養階層能量與單一族群的承載量模型。

年段：國中（依各校版本調整）。建議20–25分鐘。

## 學習目標

- 辨認食物網箭頭代表能量由食物到取食者
- 比較階層能量傳遞
- 區分單族群邏輯斯成長與完整食物網動態

## 模型

每階層能量Eₙ=E₀ηⁿ；N(t)=K/[1+(K/N₀−1)e^(−rt)]。r=0或t=0時N=N₀。

## 簡化限制

食物網為關係圖，不是與族群曲線耦合的多物種模型。能量圖是簡化鏈，不把同一能量重複分給各分支；傳遞效率由學生指定，10%不是定律。族群模型假設K、r固定，無遷移、年齡結構、季節、掠食與隨機災害；數值是連續期望量。

## 引導任務

- ① 能量不是循環：記錄每階層能量，再把傳遞比例調到20%；不要改成100%定律。
- ② 接近承載量：記錄時間10和30，觀察族群曲線是否一直同速增加。
- ③ 超出承載量：觀察N₀>K的結果。這是否能預測整個食物網的真實變化？
