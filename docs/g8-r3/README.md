## 正確性
- 等比：每題以遞推逐項乘公比，與公式 a₁·rⁿ⁻¹ 互驗；中項驗 b²＝ac；相隔偶數項兩組解都代回檢查。
- 平行：八個角由截線角算出，驗同位角相等、同側內角互補；折線圖依真實角度求轉折點，圖上角度即題目數值。
- 四邊形：第四頂點驗兩對角線中點重合；菱形與等腰梯形驗 a²＋b²＝c²；梯形四等分平行線和驗等於 3×(上底＋下底)÷2。
人工核對：a₁＝1、r＝−3 → a₆＝−243；a₃＝−12、a₅＝−48 → r＝2、a₁＝−3；−3 與 −12 的等比中項 ±6；∠4＝(5x＋16)°、∠6＝(2x＋80)° 同側內角 → x＝12；折線 64°＋62°＝126°；菱形周長 68、對角線 16 → 另一條 30、面積 240；等腰梯形 8、14、腰 5 → 高 4、面積 44；A(−3,−1)、B(−4,4)、C(2,0) → D 為 (3,−5)、(−9,3)、(1,5)。
