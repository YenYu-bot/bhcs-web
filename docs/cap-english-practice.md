# 百宏國中會考英文專練

## 兩個新入口

- `tools/english-cap-grammar.html`：原創情境文法，36 題單題、5 篇短文共 16 個空格。學用不提示考點，教用逐題附繁體中文解析；過去完成、過去觀點未來和其他延伸預設不混入。
- `tools/english-cap-reading.html`：國中教育會考 103–115 年正式主考閱讀第二部分。保留整組文章、圖片、題號與選項順序，依年度抽取；112 組可以直接練習，含 145 張切頁圖。試辦、參考、補考、大陸考場、聽力及第一部分單題不混入。
- 兩頁免登入，不把作答送到後端。切換學用／教用保留同一份卷與題序，舊分項練習和混合卷不改。兩頁以固定題目 ID 還原卷號，已公開的 ID 與答案不可就地換成另一題；修正實質題意時新增 ID，或保留舊版讀取而提升卷號版本。

## 閱讀原題來源

年度來源及正式題本在 `assets/english-cap-reading/bank.json`。原題影像由官方 PDF 裁切，不拆散文章或改選項，不收第三方解析。103–106 年的 45 張題圖改用各年度在[國中教育會考歷屆試題](https://cap.rcpet.edu.tw/examination.html)另行提供的「無浮水印題本」內英語閱讀 PDF 重新裁切，沒有後製消去浮水印；題組 ID、原題號、答案、來源連結均未變。影像檔名沿用原始資料的頁碼識別：這四年無浮水印本實際頁碼相對於檔名，103 年為 −5，104–106 年為 +1。依教育評量辦法第 15 條，國中教育會考為法定考試；參考智慧財產局 [1151111b](https://www.tipo.gov.tw/tw/copyright/692-102728.html) 就試題與隨題附圖、答案選項代號的說明。可辨識另有第三方素材的 105 年第 25–27 題與 108 年第 16–17 題暫不抽取，僅保留年度官方原卷連結。全資料含這兩組的題號及答案以方便範圍核對；不上架無法確認的獨立作品。

新增年度時先核對正式發布的原題與答案，核對閱讀解答欄而非聽力。每組記原題起迄、PDF 實際頁數與對應答案字母；同頁跨組時裁到確切題組範圍，最後一頁須包含最後一個選項和與題目相關的圖表，保留圖上的題目文字。上傳 WebP 以 `年-起題號-PDF頁碼.webp` 命名。可離開網站開官方題本核對。

## 驗收

`node scripts/test_english_cap_practice.cjs` 連同原有 `npm test --prefix scripts`。驗收涵蓋資源入口、題組圖、編號、選項代號、錯誤與未作答狀態、同卷版切換和列印遮蔽規則。真實瀏覽器須另驗 390 px 和桌機、整頁原圖／跨頁題組，以及 A4 學用無答案、教用保留相同題號與答案。
