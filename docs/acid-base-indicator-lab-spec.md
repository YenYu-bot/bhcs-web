# 酸鹼與指示劑實驗室規格

## 第一版學習範圍

- 由強酸、強鹼的濃度與體積計算 `H⁺`、`OH⁻` 莫耳數，判斷中和後何者過量。
- 將過量離子濃度換算為 pH，分辨酸性、中性與鹼性。
- 比較加水稀釋與酸鹼中和：稀釋不改變溶質莫耳數，中和會消耗 `H⁺` 與 `OH⁻`。
- 比較紅藍石蕊、酚酞、廣用指示劑與紫甘藍汁在不同 pH 下的顏色。
- 從生活樣品的參考 pH 選擇合適指示劑，理解指示劑顏色只提供範圍而非精密 pH。

## 強酸強鹼混合模型

第一版固定溫度 `25°C`，酸採一元強酸 HCl，鹼採一元強鹼 NaOH，假設完全解離、體積可直接相加。

- 酸提供的莫耳數：`n(H⁺) = Ca × Va`。
- 鹼提供的莫耳數：`n(OH⁻) = Cb × Vb`。
- 中和反應：`H⁺ + OH⁻ → H₂O`，以 `1 : 1` 消耗。
- 若酸過量：`[H⁺] = (nH − nOH) / V總`，`pH = −log₁₀[H⁺]`。
- 若鹼過量：`[OH⁻] = (nOH − nH) / V總`，`pOH = −log₁₀[OH⁻]`，`pH = 14 − pOH`。
- 若兩者恰好等莫耳，或只有純水：本模型取 `pH = 7.00`。
- 額外加入的水只增加總體積，不改變中和前酸、鹼的莫耳數。

濃度選項為 `0.01 M`、`0.10 M`、`1.00 M`；體積以 mL 輸入，計算時除以 1000 轉為 L。畫面 pH 限於 `0.00–14.00`。

## 指示劑顏色規則

| 指示劑 | 教學顏色規則 |
|---|---|
| 藍色石蕊 | 酸性變紅；中性與鹼性維持藍色 |
| 紅色石蕊 | 鹼性變藍；中性與酸性維持紅色 |
| 酚酞 | `pH < 8.2` 無色；`8.2–10` 淺粉紅；`>10` 粉紅至桃紅 |
| 廣用指示劑 | 依 pH 由紅、橙、黃、綠、藍至紫的分段近似 |
| 紫甘藍汁 | 強酸紅、弱酸桃紅／紫紅、中性紫、弱鹼藍綠、強鹼綠黃 |

顏色為教學近似，實際顏色會受指示劑濃度、樣品顏色、照明與觀察者影響。

## 生活樣品參考值

檸檬汁 `pH 2.3`、食醋 `pH 2.8`、純水 `pH 7.0`、小蘇打水 `pH 8.3`、肥皂水 `pH 10.5`。這些是示意參考值，不代表所有品牌、配方或濃度都相同。

## 模型限制與安全

- 不適用於弱酸、弱鹼、多元酸鹼、緩衝液、沉澱、酸式鹽或會與水反應的複雜系統。
- 忽略活度、混合體積變化、反應熱與溫度改變；恰好中和取 pH 7 只適用本模型的強酸強鹼、25°C 條件。
- 粒子圖只表示相對種類與過量離子，不按真實數量、大小或水合狀態繪製。
- HCl、NaOH 具有腐蝕性；本頁只提供模擬，不提供自行配製或混合強酸強鹼的步驟。

## 驗收案例

1. `50 mL、0.10 M HCl`，未加鹼與水：`nH = 0.005 mol`、`[H⁺] = 0.10 M`、`pH = 1.00`。
2. 上述酸加入 `50 mL、0.10 M NaOH`：等莫耳中和，總體積 `100 mL`、`pH = 7.00`。
3. `50 mL、0.10 M HCl + 40 mL、0.10 M NaOH`：酸過量 `0.001 mol`、`[H⁺] = 0.011111… M`、`pH ≈ 1.954`。
4. `40 mL、0.10 M HCl + 50 mL、0.10 M NaOH`：鹼過量 `0.001 mol`、`[OH⁻] = 0.011111… M`、`pH ≈ 12.046`。
5. `50 mL、0.10 M HCl` 加水 `450 mL`：總體積 `500 mL`、`[H⁺] = 0.010 M`、`pH = 2.00`；相較未稀釋只向中性移動 1 個 pH 單位。
6. 酸、鹼體積皆為 `0 mL`，另有水時：顯示純水 `pH = 7.00`；三者皆為 0 時必須顯示尚無溶液，不進行除以零。
7. 酚酞在 `pH 7.0` 顯示無色、`pH 9.0` 顯示淺粉紅；廣用指示劑在 `pH 7.0` 顯示綠色。
