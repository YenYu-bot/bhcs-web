# 血液循環實驗室

沿著血液走一圈：先到肺還是先到全身？選一條血管看裡面是充氧血還是缺氧血；再調高運動強度，比較心跳與心輸出量增加多少。

年段：國中（依各校版本調整）。建議15–20分鐘。

## 學習目標

- 依序說出體循環與肺循環的路徑
- 判斷四條主要血管屬於哪個循環、流的是充氧血或缺氧血
- 說明動脈與靜脈是依血流方向命名，不是依含氧多寡

## 模型

每分鐘心輸出量（L／分）＝心跳（次／分）×每搏輸出量（mL）÷1000。本頁教學模型：心跳＝70＋1.1×強度，每搏輸出量＝70＋0.4×強度。

## 簡化限制

心跳與每搏輸出量的公式是教學用虛構數值，只用來比較「增加幾倍」，不是任何人的實際數值。循環圖是簡化示意，只畫四條主要血管與心臟四個腔室，不畫瓣膜與冠狀循環。藍色只是繪圖慣例，缺氧血實際是暗紅色。

## 引導任務

- ① 走一圈：從大靜脈出發，沿著箭頭走：血液先回到心臟的哪一側？接著先到肺還是先到全身？
- ② 只看肺動脈：它叫「動脈」，裡面流的是充氧血嗎？再切到肺靜脈比較。
- ③ 用力運動：強度從 0% 調到 100%：心跳變成幾倍？每分鐘心輸出量變成幾倍？哪一個增加得多？
