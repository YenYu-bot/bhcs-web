# g9-drills.html design review

## Summary
- Overall: g9-drills is broad, textbook-faithful and almost entirely correct (several dozen answers spot-checked by hand; one wrong answer found). The weakest dimension is the **difficulty ladder**: in roughly half the units the challenge level reuses the advanced (or even basic) template with bigger numbers — e.g. semicircle, centroidArea, twoStep, pyramid, cone, order, sumdiff, dice, numbers, poker, meanmed.
- **Correctness bug (P1)**: circle2/parallelChords — `DE 和 BC 都是直徑 … 求 ∠ABC、∠ACB…` answers `∠ACB＝90°`; the right angle is ∠BAC (∠ACB＝90°−弧AC/2). Hard-coded at g9-drills.html line 972.
- **Impossible / implausible data (P1)**: centers medians `AD＝6、BE＝6、CF＝21` (line 1075, no triangle check); circumcenter basic silently obtuse (line 1025) against its own tip; parallelogram with collinear A、B、C (midpoint); ages with grandfather younger than father (ratio3 apply); heights 270 cm (ratio3 share); 1.96-m flagpole, 52-m rope on a 20-m pole, 4-cm 水桶, 210-cm-circumference 罐子, 54 °C, 20-cm 跳高; similar ratioP uses one hard-coded ratio for every sheet; circle1 弦長 multiple-choice answer is always (C).
- **Missing standard item types**: quadfunc has no 應用題 (圍籬面積、利潤、拋物線) and no 圖形判讀 (由圖判斷 a、b、c); circle1 lacks 兩圓位置關係 and 拱橋; centers lacks 三心位置判斷; boxplot never asks to draw/read a box plot; treediagram never uses a tree and lacks 遊戲公平性; probability lacks 機率概念判斷題; solid lacks 展開圖 and composite solids; similar lacks 影子落在牆上.
- **Mode issues**: fraction mode is a no-op in several units (ratio3 value basic, twoStep O-type, area basic); decimal mode in quartile/raw is mostly the data-free 「第幾筆」 item.
- Curriculum: content fits 108 九上/九下 (sin/cos/tan is in 九上 1-4 per S-9-4); boxplot transf (ax＋b on 五數綜合) is mainly 高一 material — keep it light.

## Topic: ratio3 — 連比與比例分配
- Levels promised: 基礎「由連比例式求比值、代入已知等式求值、按比例分配、由兩個比求連比、倒數比」；進階「含係數的連比例式、最小公倍數條件、內角與周長的分配、含分數小數的比、共有錢數與得票數、年齡問題」；挑戰「xy＝yz＝zx 型…合資與濃度混合、錢數移轉、四個量的連鎖比、高的倒數比、速率與月薪比」。
- Overall: Solid core coverage and challenge is genuinely harder (xy＝yz＝zx, 錢數移轉, 合資). Main problems: implausible ages/heights (P1), basic vs advanced barely differ in value/combine/share, fraction mode is mostly a no-op, challenge solve is 5/8 the same coin template.

### Unit value 連比例式求比值
- Variety: basic/advanced = 2 kinds (x：y：z＝a：b：c 求兩線性式比；x／a＝y／b＝z／c 求 (x＋y＋z)：y). Advanced adds 4x：4y：3z＝… (係數化). Challenge 3 kinds (5xy＝3yz＝2zx；3x＝y＝2z 求三個和的連比；係數化). Missing: 「求 (x²＋y²)：xz」型 (二次齊次式), 「已知 x：y：z 求 (x＋y)：(y＋z)：(z＋x)」at basic, 判斷「x：y＝2：3 是否可推 x＝2」type.
- Difficulty: basic ≈ advanced (same template, same coefficient range 1–3). The "含係數的連比例式" promised for advanced appears only ~1/8.
- Plausibility/tip/mode: `x／4＝y／1＝z／4` — 分母 1 is unnatural (avoid b=1 in that form). Fraction mode basic is identical to integer (no fractions appear at all in 8 samples); fraction only appears via the coefficient kind at advanced.
- Proposed changes:
  1. [P2] Make basic = only the plain x：y：z＝a：b：c template with coefficients 1–2; advanced = 係數化 (4x：4y：3z) + 二次齊次式, e.g. 進階「設 x：y：z＝2：3：4，求（x²＋y²）：（yz）的比值。」 so the ladder is real.
  2. [P2] Fraction mode: actually use fractional ratios in basic, e.g.「設 x：y：z＝(1)/(2)：(1)/(3)：(1)/(4)，求（x＋y）：z 的比值。」; otherwise drop "fraction" for this unit.
  3. [P3] In the x／a＝y／b＝z／c form exclude denominator 1 (write「x＝y／4＝…」 if needed) and write the condition as「x／4＝y／7＝z／8≠0」 once instead of repeating「x、y、z 都不為 0，且」.

### Unit solve 連比求值
- Variety: basic 1 kind (+係數化 variant), advanced adds LCM condition and coin problem, challenge = coin(5/8), LCM, GCD+LCM. Missing: 「x：y：z＝2：3：4 且 x＋y＋z＝36 求 xyz／x²」type, 二次條件「xy＋yz＋zx＝104」(challenge), 「三數和與差」(x−y＋z＝…).
- Difficulty: basic already uses 係數化 ratios (`設 4a：2b：4c＝5：2：7，且 2a＋3b＋c＝58，求 a。`) — that is advanced material per the page's own levels text. Challenge coin problem is a one-step linear equation, not harder than advanced.
- Plausibility/tip/mode: answers fine. Coin totals plausible.
- Proposed changes:
  1. [P1] Remove the 係數化 kind from basic (keep x：y：z＝a：b：c only); move it to advanced.
  2. [P2] Cap the coin template at ≤2/8 in challenge and add a quadratic-condition kind:「設 x：y：z＝2：3：4，且 xy＋yz＋zx＝104，x、y、z 皆為正數，求 x＋y＋z。」(答 18).
  3. [P3] Move the coin template to advanced (it is an application, not a stretch).

### Unit share 比例分配
- Variety: basic 3 kinds (height, triangle angles, 按比分成三份); advanced adds 三邊連比, 各用 n 元後餘款; challenge 合資, 餘款, 食鹽水. OK.
- Difficulty: basic and advanced share the height template almost exactly (5/8 vs 3/8 of samples).
- Plausibility: heights generated from free ratios give impossible people: `甲、乙、丙三人身高的比是 9：5：8。若乙身高 150 公分 … 甲 270 公分`; `身高 7：4：4，丙 80 公分 → 甲 140`. Teachers will notice.
- Proposed changes:
  1. [P1] Constrain the height template so every height ∈ [120,190] cm (ratios with terms within ±25% of each other, e.g. 30：32：35), or replace heights with a context that tolerates wide ratios (「三個班級捐書」「三種飲料的杯數」).
  2. [P2] Advanced: replace the height clone with「按比例分配後再調整」, e.g.「獎金按 3：4：5 分給甲乙丙，丙比甲多分 600 元，求獎金總額。」(差量反求 — a standard 參考書 type missing everywhere).
  3. [P3] 食鹽水 kind appears only in challenge; fine.

### Unit combine 求連比
- Variety: basic 2 kinds (共同項 x 或 z 的兩比合併); advanced adds x＝6y、y＝8z; challenge adds 四量 a：d and 「甲的 5 倍等於乙的 3 倍」. Good spread.
- Difficulty: basic ≈ advanced for integer mode (advanced sample `x：z＝5：3，y：z＝8：3` is trivial — common term already equal). Basic fraction mode is harder than advanced integer (`x：y＝(3)/(5)：2，y：z＝(1)/(10)：(9)/(5)` → 3：10：180).
- Proposed changes:
  1. [P2] Advanced integer: require the common term to need an LCM ≥ 6 (exclude equal common terms); basic may keep easy ones.
  2. [P2] Basic fraction: limit to one side fractional and denominators ≤ 4 (e.g.「x：y＝(1)/(2)：(1)/(3)，y：z＝2：5」), keep big fractions for advanced/challenge.
  3. [P3] Use consistent notation: 「甲的 5 倍等於乙的 3 倍」 kind is good — add it to advanced too (currently challenge only).

### Unit apply 連比的應用
- Variety: basic 2 kinds (錢數, 得票); advanced adds 三角形周長, 年齡; challenge 錢數移轉, 年齡, 周長. Note: basic preset count for apply is 0, so basic apply only appears if manually ticked.
- Difficulty: challenge triangle-perimeter kind (`若 2a：2b＝7：8，b：c＝8：9`) is identical to advanced — not a challenge item.
- Plausibility: 年齡 kind produces impossible families: `小英年齡的 2 倍剛好是父親的年齡，父親年齡的 2 倍是祖父年齡的 5 倍 … 5：10：4；小英 15 歲` (grandfather 12 歲, younger than father); challenge `小英 5 歲、父親 15、祖父 9`. Also advanced `…最低的得票數 2 票` (8：1 and 1：6 → 16：2：96) is odd.
- Proposed changes:
  1. [P1] Fix the 年齡 generator: father = k×小英 with k∈{2,3,4}, grandfather > father (e.g. 祖父年齡的 2 倍等於父親年齡的 3 倍), and check 小英 ≥ 8, 父−小英 ≥ 20, 祖−父 ≥ 20.
  2. [P2] Remove the perimeter kind from challenge (keep in advanced); add a challenge「增減後的新比」, e.g.「甲乙丙三人的錢數比為 3：4：5，甲再存入 30 元、丙用掉 20 元後，比變為 4：4：3，求原來三人共有多少元。」
  3. [P3] 得票: require each candidate ≥ 10 票.

### Unit inverse 倒數比（反比）的應用
- Variety: basic 3 kinds, advanced adds triangle altitudes, challenge 高的倒數比, 月薪, 摺紙星星 (速率). Good.
- Difficulty: ladder ok.
- Plausibility/tip: tip good. Challenge `hₐ：h_b＝9：5、h_b：h_c＝1：1` — 1：1 is degenerate; prefer distinct ratios.
- Proposed changes:
  1. [P3] In challenge altitude kind, exclude ratio 1：1 so the 連比 step is exercised.
  2. [P3] Add a standard「工作效率」kind to advanced:「甲、乙、丙完成同一件工作分別需 4、6、8 天，求三人的工作效率比。」

## Topic: parallelratio — 平行線截比例線段
- Levels promised: 基礎「一組比求面積比、DE∥BC 求一段長、兩段式平行、三條平行線…中點坐標」；進階「兩層面積比與平行四邊形、含 x 的線段、兩條平行線、四條平行線、使 DE∥BC 的長度、兩次取中點、由中點反求端點、平行四邊形對角線交點」；挑戰「兩組比的面積比、周長與梯形內平行線、二次式的線段、判斷哪一條平行、中點三角形的面積、分點坐標與原點倍數」。
- Overall: Good breadth and figures. Recurrent weakness: challenge reuses the advanced template (parallelSeg, twoStep, threeLines, midsegment) and the midpoint challenge is easier than advanced. One degenerate figure bug (collinear "parallelogram").

### Unit areaRatio 等高三角形的面積比
- Variety: basic 3 kinds (單一比, 兩層 D on BC/E on AD, △BDE／△ABC); advanced = the same 3 kinds (no new kind; "平行四邊形" promised for advanced appears only in challenge samples); challenge 3 kinds (P on AB/Q on PC, AD：DB＝CE：EB, 平行四邊形對角線).
- Difficulty: basic ≈ advanced (identical forms, same ratio range). Challenge ok.
- Proposed changes:
  1. [P2] Give advanced its own kinds: 平行四邊形 (move from challenge) and 反求「△ABD 面積 12、△ADC 面積 8，BC＝15，求 BD」; and a "梯形對角線" kind「梯形 ABCD 中 AD∥BC，對角線交於 O，AD：BC＝2：3，△AOD＝8，求 △BOC 與 △AOB」(this one may belong to similar; if so, use the 反求 kind only).
  2. [P3] Basic: drop the △BDE／△ABC two-ratio kind to ≤2/8 (it is already a two-step product); keep single-ratio and reverse.

### Unit parallelSeg 三角形內平行線截比例線段
- Variety: basic 2 kinds (AD：DB＝AE：EC; DE：BC); advanced adds 含 x 線性 and DE∥PQ∥BC; challenge adds 周長 (AE＝BC＝4x).
- Difficulty: basic integer has many midpoint cases (`AD＝6、DB＝6 … 求 EC` 3/8) — trivial. Challenge integer is 5/8 the advanced `AD＝x−a、BD＝x−b，AE：EC＝p：q` template → not a stretch. Promised「二次式的線段」not seen here (only in threeLines).
- Proposed changes:
  1. [P2] Basic: exclude AD＝DB (that is the midsegment unit).
  2. [P1] Challenge: remove the linear x template; add 二次式「DE∥BC，AD＝x、DB＝x＋2、AE＝3、EC＝x＋… 」e.g.「△ABC 中 DE∥BC，AD＝x、DB＝6、AE＝4、EC＝x＋2，求 x。」(x(x＋2)＝24 → x＝4) and「DE∥BC，△ADE 與梯形 DBCE 周長／面積」mixed kind.
  3. [P3] Fraction mode: keep denominators ≤ 13 (avoid `DE＝(160)/(17)`).

### Unit twoStep 兩段式平行（找相同的邊）
- Variety: 3 kinds total (AD∥BE、BD∥CE 在角內; DE∥AB、EF∥AC; DE∥BF、DF∥BC) used at every level.
- Difficulty: flat — basic, advanced, challenge draw the same 3 templates with the same number range (challenge `AD∥BE、BD∥CE，OB＝8、OC＝16，求 OA` = basic). Page promises nothing distinct for challenge beyond 周長 in parallelSeg.
- Proposed changes:
  1. [P1] Level-gate: basic = OA:OB:OC 型 only with integer answers; advanced = add the other two templates; challenge = 含 x 或 求比值, e.g.「如圖，AD∥BE、BD∥CE，OA＝x、OB＝6、OC＝x＋5，求 x。」(x(x＋5)＝36 → x＝4) and「DE∥AB、EF∥AC，AD：DC＝2：3，求 BF：FC 及 四邊形 ADEF 周長／△ABC 周長」.
  2. [P3] Fraction mode basic yields only integers for the O-type (`OB＝24、OC＝32 → 18`); either allow fractional answers or note that fraction mode affects only the DE∥AB kind.

### Unit threeLines 平行線截比例線段
- Variety: basic 3 kinds; advanced adds 含 x 線性 and 四條平行線 (梯形); challenge adds 二次式 (AB＝x−3、AC＝x＋17). Good set.
- Difficulty: basic `AB：BC＝1：1，DE＝9，求 DF` trivial; challenge still half linear-x identical to advanced (`AB＝5、BC＝3、DE＝4x＋1、EF＝4x−9`).
- Proposed changes:
  1. [P2] Challenge: ≥5/8 二次式 or 四條平行線; drop the plain linear-x kind there.
  2. [P3] Basic: exclude 1：1.

### Unit judge 由比例判斷平行
- Variety: basic 2 forms (比 vs 長度), advanced adds 哪一條平行 and 使 DE∥BC 求 AE, challenge adds「AD：AB＝DE：BC 不能判斷」. Good; this is exactly the textbook trap.
- Difficulty: ladder ok.
- Good; no change except [P3] answer for 平行 cases could cite the converse theorem name:「平行（AD：DB＝AE：EC，由平行線截比例線段性質的逆敘述）」.

### Unit midsegment 三角形兩邊中點連線
- Variety: basic 2 kinds, advanced 3 (兩次中點 PQ＋DE, 中點三角形的中點三角形, 周長), challenge 3 (面積 1/4, PQ＋DE, 反求面積).
- Difficulty: challenge integer is 6/8 the PQ＋DE template from advanced; area ¼ is a basic fact, not challenge. Missing standard types: 「四邊形各邊中點連線成平行四邊形，周長＝兩對角線和」「梯形兩腰中點連線＝(上底＋下底)／2」「中點連線＋等腰／直角求長」.
- Proposed changes:
  1. [P1] Challenge: replace most PQ＋DE with「四邊形 ABCD 中，E、F、G、H 為各邊中點，AC＝12、BD＝16，求四邊形 EFGH 的周長。」(答 28) and「梯形 ABCD 中 AD∥BC，E、F 為兩腰中點，AD＝6、BC＝14，求 EF；EF 與對角線 BD 交於 G，求 EG。」.
  2. [P2] Move the 面積 ¼ kind to basic/advanced.

### Unit midpoint 中點坐標與分點坐標
- Variety: basic 3 (中點, 反求端點, 圓心), advanced adds 平行四邊形 D 與 P, 分點 (fraction only); challenge integer = OB＝kOA (6/8) + 平行四邊形.
- Difficulty: inverted at challenge: `坐標平面上 A（6，3），B 在射線 OA 上且 OB＝3OA，求 B` is a one-step multiplication, easier than advanced.
- Plausibility: degenerate figure — advanced `四邊形 ABCD 為平行四邊形，A（1，1）、B（1，−6）、C（1，−1）` (three collinear points; also C between A and B). Generator must reject collinear A、B、C.
- Proposed changes:
  1. [P1] Reject collinear A、B、C in the parallelogram kind (check (B−A)×(C−A)≠0).
  2. [P1] Challenge integer: replace OB＝kOA with 分點 that gives integer answers (choose A、B so the division is exact), e.g.「A（−4，1）、B（8，10），C 在 AB 上且 AC：CB＝1：2，求 C。」(答（0，4）) and「△ABC 三頂點 A（…）B（…）C（…），求三中點所成三角形的頂點」or 反求「AB 的三等分點為 P（1，2）、Q（3，5），求 A、B」.
  3. [P3] Keep OB＝kOA as one advanced item at most.

## Topic: similar — 相似形
- Levels promised: 基礎「縮放後的邊角周長、影印與比例尺、對應邊求長、對應角、AA 與 SSS 判別、對頂角與公共角的相似、面積比、影長與河寬」；進階「兩次縮放與倍率還原、含 x 的對應邊、係數化的角比、五邊形角、找出不相似的紙板、角平分線與平行四邊形的相似、平行線截高、梯形對角線、旗桿與鏡子」；挑戰「中心點縮放與光源投影、四邊比與周長、SAS 判別、EF：BC 反求分段比、面積等分的距離（根式）、燈影與兩根標竿」。
- Overall: Rich unit set with good real-world measurement items. Problems: several challenge levels are filled with basic one-step items (sides, angles, aa), measurement answers given as improper fractions of 公尺 (e.g. (1269)/(100) 公尺), a flagpole of 1.96 m, a hard-coded ratio in sides challenge, and basic-integer measure has only one kind.

### Unit scale 縮放與比例尺
- Variety: basic 3 kinds (縮放邊/角, 比例尺→實際距離, 影印%), advanced 3 (求比例尺, 兩次縮放＋面積, 倍率還原), challenge 2 (OA/OA′ 求倍率與周長, 光源投影). Good.
- Difficulty: ok.
- Plausibility: `實際距離是 (7)/(4) 公里` — distances should be written as decimals (1.75 公里).
- Proposed changes:
  1. [P3] Render real distances as decimals or 公尺 (「實際距離是 1750 公尺」).
  2. [P3] Add 面積 with 比例尺 to advanced:「比例尺 1：5000 的地圖上，公園面積 6 平方公分，實際面積是多少平方公尺？」(答 15000 平方公尺) — a standard 參考書 trap.

### Unit sides 相似形的對應邊
- Variety: basic 2 kinds (△ 對應邊, 多邊形周長); advanced adds 含 x (actually quadratic) and 最短邊; challenge adds 周長比求邊 and 四邊比.
- Difficulty: challenge contains basic items: `已知四邊形 ABCD∼四邊形 EFGH，周長分別是 36 公分與 108 公分。若 EF＝12 公分，求 AB 的長。` (one step). The 含 x kind is identical in advanced and challenge.
- Plausibility: challenge 四邊比 kind uses a hard-coded ratio `AB：BC：CD：DA＝1：(1)/(2)：(2)/(3)：2` (source `kind==="ratioP"`: `rr=[R(1),R(1,2),R(2,3),R(2)]`) — every sheet gets the same ratio.
- Proposed changes:
  1. [P1] Randomize the ratioP ratio (pick 4 unit fractions/integers from a pool, e.g. 1、(1)/(2)、(1)/(3)、(3)/(4)、(2)/(3)、2、3) and also ask the longest side.
  2. [P2] Move 周長比求邊 to basic/advanced; challenge add「△ABC∼△DEF，AB：DE＝3：5，且兩三角形周長和為 64，求 △ABC 的周長。」 and 不對應順序的相似「△ABC∼△ADE（D 在 AC 上、E 在 AB 上），AB＝12、AC＝9、AD＝6，求 AE。」
  3. [P3] Note in the advanced 含 x kind that x must make lengths positive (it already has a unique positive root) — fine.

### Unit angles 相似形的對應角
- Variety: basic 2 kinds (四邊形角比, △ 對應角), advanced adds 係數化角比 and 五邊形; challenge = 五邊形, 四邊形求 ∠D′, △係數化.
- Difficulty: challenge `四邊形 ABCD∼四邊形 A′B′C′D′ … ∠A＝122°、∠B＝60°、∠C＝44°，求 ∠D′` is a one-step basic item.
- Plausibility: 係數化 with equal coefficients is pointless and odd: `2∠A：2∠B＝5：6，3∠B：3∠C＝6：19` (same as ∠A：∠B).
- Proposed changes:
  1. [P2] In 係數化 kind require different coefficients on the two sides (keep `3∠A：2∠B＝20：21`, ban `2∠A：2∠B`).
  2. [P2] Move「四邊形求 ∠D′」to basic; add a challenge item mixing correspondence and order:「△ABC∼△DEF，∠A＝(2x＋10)°、∠D＝(3x−20)°、∠E＝(x＋40)°，求 ∠C。」

### Unit judge 相似三角形的判別
- Variety: basic 3 (SSS, AA by angles, 長方形); advanced SSS, 紙板, 求 x y (this is "sides", not judge); challenge SAS, 紙板, 求 x y.
- Difficulty: 紙板 kind identical in advanced/challenge; 「兩個相似三角形…求 x、y」 is a sides item mislabeled in judge.
- Missing standard types: SAS trap (角不是夾角), 給圖判別 with 公共角, 「正方形／正三角形一定相似；長方形、菱形不一定」判斷題.
- Proposed changes:
  1. [P2] Remove the 求 x、y kind from judge (sides covers it). Add challenge SAS trap:「△ABC 中 ∠B＝50°、AB＝6、AC＝8；△DEF 中 ∠E＝50°、DE＝9、DF＝12。能否判斷相似？」(答：不能，50° 不是夾角).

### Unit measure 簡易測量

### Unit altitude 直角三角形母子相似
- Variety: 3 kinds (BD,CD→AD,AB,AC; AD,BD→CD,BC; AB,BD→CD,AC) at basic/advanced; challenge adds AB,AC→BC,AD,BD.
- Difficulty: basic uses big triples: `BD＝64、CD＝225，求 AD、AB、AC` (→ 120、136、255); advanced draws from the same pool (`BD＝16、CD＝9` appears in advanced). No ladder in number size. Basic fraction `AD＝(360)/(17)、BD＝(675)/(17)` is very heavy for basic.
- Proposed changes:
  1. [P1] Basic integer: restrict to small triples (3-4-5, 6-8-10, 5-12-13 scaled ≤ 3; e.g. BD＝9、CD＝16); keep 8-15-17/20-21-29 scales for advanced.
  2. [P2] Basic fraction: use only givens that are integers with fractional answers (「AB＝6、BC＝10，求 BD」→ (18)/(5)), not fractional givens with denominator 17/25.
  3. [P2] Advanced: add 面積法「∠A＝90°，AB＝6、AC＝8，求斜邊上的高 AD」(AD＝AB·AC／BC) — the most common textbook item, currently only in challenge.
  4. [P3] Challenge: add「AD＝6，BD：CD＝1：4，求 BC」(設 BD＝k).

### Unit pythagoras 畢氏定理的應用

- Proposed changes:
  1. [P2] Replace (c−a)／(c＋a) with a varying follow-up (「求此三角形的面積與斜邊上的高」).
  2. [P2] Add basic 判斷題「下列哪一組可以是直角三角形的三邊長：(A) 5、6、7 (B) 9、12、15 (C) 2、3、√13 (D) 1、2、3」 and advanced 「等腰三角形腰 13、底 10，求面積」(promised「等腰三角形面積」 is missing from samples).
  3. [P3] Basic `AB＝160、BC＝36，求 AC` — scale down to ≤ 2-digit legs for basic.

### Unit special 特殊直角三角形
- Variety: basic 3 (30-60-90, 45-45-90, 37-53); advanced 3 (150° 等腰面積, 15°/30° 測塔, 30-60-90); challenge 3 (45°＋30° 合併, 30°/60° 測樓, 150° 面積).

### Unit trig 三角比（sin、cos、tan）
- Variety: basic fraction 3 (給 sin 求其餘, 給 tan 求其餘, 三邊求六個比); basic decimal 1 (塔高 8/8); advanced 4 (特別角求值, 給比求其餘, 面積公式, 兩次仰角); challenge 5 (四邊形, (1＋cos A)／cos A, BC＝k·AB, 吹折的樹, 兩次仰角).

- Plausibility: basic decimal answers `309.87 公尺` towers are fine but 8/8 one kind. Challenge `cos 54°＝0.6，tan 54°＝1.4` are inconsistent with each other (0.6² ＋ 0.84² ≠ 1) and far from the true values (0.5878, 1.3764); a student checking will be confused. ### Unit shortest 立體表面的最短路徑
