Source: `/home/claude/yenyu-bot/bhcs-web/tools/math/g11-drills.html` (branch `fix/math-answer-errors`). Samples: chunk `11-g11.txt`.

## Summary
Overall: answers are correct and clean, but the page mostly drills one template per unit. Inside a unit, the level usually changes only the number size, so the basic/advanced/challenge ladder comes almost entirely from presets. Highest-impact findings:

1. **spaceconcept needs a rewrite (P1).** 7 of 10 units are tautologies: the question restates a definition and the answer is the defined word (「不平行也不相交 → 歪斜」, 「公垂線段 CD＝9，求距離 → 9」, 「二面角 45°，求餘弦 → √2/2」). `decideplane` answers 「恰有 1 個」 100% of the time. `nestedlength` never uses 三垂線. There are no figures. Proposed: rebuild around a labeled cube/四面體/三角錐.
2. **Hard-coded pattern leaks (P1):** `doublehalf.point` uses only the 3-4-5 triple (`triples.slice(0,2)`), so every answer is ±24/25, ±7/25. `spaceinner.angle` uses 5 fixed vector pairs. `spaceinner.pointdistance` and `spacecross.height` use only axis/diagonal directions. `plane3d` distance/foot/reflection draw from a 6-normal pool.
3. **expfunctions never produces a base 0＜a＜1 (P1):** `UNIT_POLICIES.expfunctions` forces integer mode, so there is no decreasing exponential, the `compare` tip about 反序 is never exercised, `model` never decays, and the advanced promise 「分數／小數底數」 is unmet. `compare` is trivial (same base, integer exponents).
4. **Inverted or flat ladders (P1):** `expequations.quadratic` basic has 244/9 coefficients while advanced has the textbook 2^(2x)−6·2^x＋8＝0. `loggraphs.inequality` basic uses base 1/3 with 53/9 bounds while challenge uses base 2 one-liners. The trigtransform "challenge" units `intersections` (includes sin x＝1/2) and `model` (one 摩天輪 template) are among the easiest on the page.
5. **Units whose skill is never actually required (P1):** `commonlog.laws` uses only powers of the base, so no law is needed. `commonlog.scientific` asks the 首數 of a number already in scientific notation. `trigblend.condition` prints the folded form in the question. `vectorcauchy.angle` (「長度、夾角與內積」) never asks for a length or an angle. `expequations` never requires rewriting 4^x＝(2^x)².
6. **Missing core textbook types (P1/P2):** 疊合 on a restricted interval and a sin²＋b sin cos＋c cos² → 疊合; 由圖形求 a、b、c、d (trigtransform); the sinθ＋cosθ sign-decision type; half-angle with θ/2 in quadrants III/IV; real 對數模型 contexts (pH, 規模, 分貝, 複利); |a→＋b→| and 求夾角; reverse distance in plane3d; geometric (non-coordinate) vector items in planevector and spacevector.
7. **Format issues (P1):** special half-angles are left as √(2＋√3)/2 instead of (√6＋√2)/4. Phases print as 「(1)/(2)π」. Coefficient 1 prints as 「y＝1 sin 4x」, and 「log_2（x ＋ 0）」 also appears. There are mixed-number log answers 「122(3)/(5)（即 (613)/(5)）」 and base notation 「log_2^2（2^2）」. Fraction mode is meaningless where it only scales an integer equation (doublehalf.equation) or yields unreadable data (vectorcauchy.perpendicular).
8. **Good, little change needed:** planevector, determinant, trigblend.interval/period, loggraphs.combined, spacecross.tetrahedron, plane3d core (pointnormal/threepoints/parallel/bisector/planeangle).
9. Curriculum: commonlog's 首數／位數／log2 content is 高一 (第一冊) material under 108課綱, so on this page it serves as review. Some 108 textbooks no longer use the term 首數.

## Topic: doublehalf — 倍角與半角 (config line 789, generators ~735–788)
- Levels promised: basic「小整數比、直接套用二倍角公式與基本化簡」; advanced「加入分數／小數、象限判號、終邊點與降冪」; challenge「根式半角、倍角化方程及幾何綜合應用」.
- Overall: Each unit is a single template; level changes only number range (`ratio()` denominators 3–13 vs 4–18, `k` up to 4 vs 6). The ladder is therefore carried entirely by presets. Two P1 defects: `point` only ever uses the 3-4-5 triple, and half-angle special values are left in nested-radical form instead of the textbook (√6±√2)/4. Integer mode encodes fractions as 「2tanθ＝1」, which no textbook writes.

### Unit fromsin 由 sinθ 求二倍角
- Variety: 1 kind (given sinθ + quadrant, find all three). Missing: given cosθ; 「求 sin2θ 之值」 only (single blank, lighter for basic); θ given by range like 「π＜θ＜3π/2」 instead of quadrant name; reverse 「已知 cos2θ＝7/25 且θ為銳角，求 sinθ」.
- Difficulty: flat across levels. Basic samples include sinθ＝1/2 in Q1 (trivial: θ＝30°) and denominators up to 10/12 with answers like tan2θ＝−7√51 — too heavy for basic, and challenge is the same form.
- Plausibility/tip/mode: tip fine. Values like sinθ＝7/12 → √95 are legal but ugly.
- Proposed changes:
  1. [P2] Basic: restrict to sinθ whose cosθ is rational (from Pythagorean triples 3/5, 5/13, 8/17, 7/25) so the student practises the formula, not radicals; exclude sinθ＝±1/2 (special angle). Advanced: allow radical cosθ (1/3, 2/3, 1/4). Challenge: add given cosθ with θ range in radians and reverse kind 「已知 cos2θ＝−7/25，且 90°＜θ＜180°，求 sinθ、cosθ」.
  2. [P2] Add kind 「已知 cosθ＝−5/13，π＜θ＜3π/2，求 sin2θ、cos2θ」 (advanced).

### Unit fromtan 由 tanθ 求二倍角
- Variety: 1 kind. Good number choice (rational answers). Missing: reverse 「已知 tan2θ＝24/7，θ為銳角，求 tanθ」 (quadratic in tanθ, standard 參考書 type).
- Difficulty: flat. tanθ＝−2 appears in basic/advanced/challenge equally.
- Plausibility/mode: In integer mode `given()` prints 「2tanθ＝1」-style (seen in geometry). Fine in fraction mode.
- Proposed changes:
  1. [P2] Challenge kind: 「已知 tan2θ＝(24)/(7)，且 0°＜θ＜45°，求 tanθ」 (answer 3/4); also 「已知 tan(θ/2)＝1/3，求 sinθ、cosθ」 (萬能公式 t-substitution; advanced).
  2. [P3] Basic: limit to tanθ∈{±1/2, ±2, ±3/4, ±4/3, ±1/3, ±3} so answers have denominators 5/10/25.

### Unit sumdiff 由 sinθ±cosθ 求值
- Variety: 1 kind, always asks only sin2θ. Trivial cases 「sinθ−cosθ＝1」「sinθ＋cosθ＝1」 (answer 0) appear in 3 of 24 samples, twice in one challenge block. Missing standard follow-ups: sinθcosθ, sin³θ＋cos³θ, sin⁴θ＋cos⁴θ, tanθ＋cotθ, and 「已知 sinθ＋cosθ＝1/5，0＜θ＜π，求 sinθ−cosθ、cos2θ」 (sign decision — the core 參考書 type).
- Difficulty: flat (only the denominator changes).
- Proposed changes:
  1. [P1] Exclude |u|＝1 (answer 0) and u＝0.
  2. [P2] Advanced kinds: 「已知 sinθ＋cosθ＝(1)/(3)，求 sin³θ＋cos³θ」, 「求 tanθ＋(1)/(tanθ)」.
  3. [P2] Challenge kind: 「已知 sinθ＋cosθ＝(1)/(5)，且 0＜θ＜π，求 sinθ−cosθ 與 cos2θ」 (answers 7/5, −7/25; needs sign reasoning). Use only u giving a rational second value (1/5, 7/13, 7/17, 17/25…).

### Unit point 終邊點與二倍角
- Variety: P1 bug — `pick(triples.slice(0,2))` means every question is a multiple of (3,4) or (4,3); all 24 sample answers are ±24/25, ±7/25, ±24/7. Students learn the answer pattern, not the method.
- Difficulty: flat (only the scale factor grows).
- Proposed changes:
  1. [P1] Use the full `triples` list (5-12-13, 8-15-17, 7-24-25, 20-21-29) at basic/advanced; at challenge also allow non-Pythagorean points with radical r, e.g. 「終邊通過 P（−1，2）」 (sin2θ＝−4/5) and 「終邊在直線 y＝−2x（x＞0）上」.
  2. [P2] Basic: only one or two of the three values (e.g. 「求 sin2θ、cos2θ」) to keep it short.

### Unit identity 倍角公式化簡
- Variety: 5 surface forms but all are 「k·(textbook pattern)＋c」, i.e. pure pattern recognition; the outer coefficient and constant add nothing. No question needs a manipulation. Missing standard types: sinx cosx (no 2) → (1/2)sin2x; cos⁴x−sin⁴x; (sinx＋cosx)²; (1−cos2x)/sin2x＝tanx; 2cos²15°−1 numeric evaluation; sin15°cos15°, cos²(π/8)−sin²(π/8); 證明／化簡 (1＋cos2x)/(sin2x).
- Difficulty: flat apart from k.
- Proposed changes:
  1. [P2] Replace the ×A＋B wrapper with a kind list per level — basic: 「求 2sin15°cos15° 之值」「求 cos²(π/8)−sin²(π/8)」「化簡 sinx cosx」; advanced: 「化簡 cos⁴x−sin⁴x」「化簡 (sinx＋cosx)²−1」; challenge: 「化簡 (1−cos2x)/(sin2x)」「化簡 (sin2x)/(1＋cos2x)」「求 sin(π/12)cos(π/12)cos(π/6)」.
  2. [P3] Keep the tan form only at advanced+.

### Unit half 半角與象限判號
- Variety: 2 kinds (given cosθ in a 0–360° quadrant; special angle). Because θ is always in 0°–360°, θ/2 is always in quadrant I or II, so cos(θ/2) sign is the only decision and sin(θ/2) is always positive. Missing: θ in 360°–720° or −180°–0° (θ/2 in III/IV), given sinθ or tanθ, tan(θ/2)＝sinθ/(1＋cosθ) form.
- Difficulty: basic and challenge identical form; challenge 「根式半角」 promise is only the 22% special-angle branch.
- Plausibility: P1 — special values are shown as 「sin105°＝√（2＋√3）／2」. Textbook answer for 15°/75°/105°/165° is (√6＋√2)/4; teachers will mark the key as unfinished. 22.5° family (√（2−√2）/2) is correct as is.
- Proposed changes:
  1. [P1] Denest for r＝3 angles: sin15°＝(√6−√2)/4, cos15°＝(√6＋√2)/4 etc.
  2. [P2] Advanced/challenge: use ranges 「360°＜θ＜450°」「540°＜θ＜630°」 or 「−π＜θ＜−π/2」 so θ/2 lands in III/IV; this is what the page instruction 「務必先判斷 θ／2 所在象限」 calls for.
  3. [P2] Challenge kind: 「已知 sinθ＝−(4)/(5)，π＜θ＜(3π)/(2)，求 tan(θ/2)」 (needs cosθ first).
  4. [P3] Basic: drop tan(θ/2) or ask one value to shorten.

### Unit reduce 降冪與值域
- Variety: 1 kind (a sin²u＋b cos²u＋c). Missing: sin⁴x＋cos⁴x, sin²x cos²x, sin²x＋sinx cosx (needs 疊合 — challenge link to trigblend), 「求週期」.
- Difficulty: flat. Range answer is trivial once reduced.
- Plausibility: fine; ordering 「−5−4cos4x」 OK.
- Proposed changes:
  1. [P2] Advanced kind 「f(x)＝sin⁴x＋cos⁴x，降冪並求最大值與最小值」 (3/4＋(1/4)cos4x). Challenge kind 「f(x)＝sin²x＋2sinx cosx＋3cos²x 的最大值、最小值」 (2＋√2…).
  2. [P3] Ask also the period at basic (「並求週期」) to give the cos2kx form a purpose.

### Unit equation 倍角化三角方程
- Variety: 1 kind (cos2x＋sinx quadratic), 5 root sets. Missing: cos2x with cosx（2cos²x−1 form）; sin2x＝sinx / sin2x＝cosx (factoring); cos2x＝cosx; answers in degrees for basic.
- Plausibility/mode: P1 — fraction mode just multiplies an integer equation by a random fraction: 「(10)/(7)cos2x＋(50)/(7)sinx−(40)/(7)＝0」. No textbook writes this; students just multiply through. Fraction mode is meaningless here.
- Difficulty: flat.
- Proposed changes:
  1. [P1] Always use small integer coefficients (cos2x＋5sinx−3＝0 style); drop fraction/decimal mode for this unit.
  2. [P2] Add kinds: basic 「解 sin2x＝sinx，0≤x＜2π」; advanced 「解 cos2x＋3cosx＋2＝0」; challenge 「解 cos2x＝sinx−cosx 型」 or 「求 cos2x＋2sinx＝k 有解的 k 範圍」.

### Unit geometry 直角三角形面積
- Variety: 1 kind; the tip gives the final formula so the task is plug-in. Integer-mode wording 「銳角θ滿足3tanθ＝8」 is unnatural; answers like 432/73 are ugly.
- Difficulty: flat; challenge only larger h.
- Proposed changes:
  1. [P1] Wording: 「tanθ＝(8)/(3)」 always; and choose tanθ from triples so the area is tidy.
  2. [P2] Replace with standard 倍角 geometry kinds: 「等腰三角形腰長 10、頂角 2θ，cosθ＝3/5，求面積與底邊」; 「矩形 ABCD 中 AB＝2BC，∠ADB＝θ，求 tan2θ」; 「旗桿高 h，仰角 θ，走近 d 後仰角變 2θ，求 h」 (challenge); 「斜邊 h 的直角三角形面積最大值」 (challenge, sin2θ≤1).
  3. [P3] Move the formula out of the tip; tip: 「面積＝(1/2)·h cosθ·h sinθ，再用 2sinθcosθ＝sin2θ」.

## Topic: trigblend — 正餘弦疊合 (config line 2264)
- Levels promised: basic「小整數、同號係數，直接練習疊合、振幅與最值」; advanced「負係數、分數／小數、頻率、指定區間與平移」; challenge「多週期根數、反求係數及和差角展開後再疊合」.
- Overall: Mechanically solid and answers are clean. Weaknesses: (a) the two most-tested 疊合 question types are absent — **range on a restricted interval** (e.g. 0≤x≤π/2) and **a sin²x＋b sinx cosx＋c cos²x → 降冪後疊合**; (b) `sineform`/`cosineform`/`range` basic use only Pythagorean-triple coefficients, never the textbook entry case sinx＋√3cosx＝2sin(x＋π/3); (c) `condition` hands the folded form to the student; (d) `reverse` is one contrived template.

### Unit sineform 疊合為正弦式
- Variety: 1 kind; α left as 「cosα＝…，sinα＝…」. Basic only all-positive Pythagorean multiples (10,24 → 26). Missing: special-angle folding with explicit α (√3, 1 / 1, 1), basic entry type.
- Difficulty: ladder works on sign and k (basic positive k＝1, advanced signs, challenge k up to 3 and ×4 scale). OK.
- Proposed changes:
  1. [P2] Basic: 50% special-angle items 「將 y＝sinx＋√3cosx 疊合成 r sin(x＋α)，其中 r＞0，0≤α＜2π」 (answer 2sin(x＋π/3)); keep triples for the rest. Advanced: special angles with negative coefficients, α in (π, 2π).
  2. [P3] State the α range in the question (「r＞0，−π＜α≤π」) so the answer is unique.

### Unit cosineform 疊合為餘弦式
- Variety: 1 kind; duplicates in one block (advanced: −36sin3x−15cos3x appears 3× with only the constant changed, because sig includes d).
- Proposed changes:
  1. [P2] Dedupe on (a,b,k) ignoring d.
  2. [P2] Same special-angle addition as sineform; plus 「寫成 r cos(x＋β)」 variant (sign convention change) at advanced.

### Unit range 振幅與值域
- Variety: 1 kind (whole real line). Missing the core type 「0≤x≤π/2 時，f(x)＝√3sinx＋cosx 的最大值、最小值」, and 「f(x)＝(sinx＋√3cosx)²」 / 「f＝a(疊合)²＋b(疊合)」 type.
- Difficulty: challenge just bigger triples (120,35→125).
- Proposed changes:
  1. [P1] Add restricted-interval kind at advanced/challenge using special-angle coefficients: 「求 f(x)＝sinx＋√3cosx 在 0≤x≤(π)/(2) 的最大值與最小值」 (2 and 1). This is the 學測 staple; the unit currently cannot produce it.
  2. [P2] Challenge kind: 「求 f(x)＝sin²x＋2√3 sinx cosx−cos²x 的最大值與最小值」 (降冪→√3sin2x−cos2x→2sin(2x−π/6); max 2, min −2) and with a constant offset.

### Unit condition 最值與成立條件
- Variety: 1 kind. The question prints the folded form 「＝52 sin（x＋α）＋3」, so the student only adds/subtracts; the 「成立條件」 answer 「x＋α＝π/2＋2nπ」 is a non-answer since α is unknown.
- Proposed changes:
  1. [P1] Do not print the folded form. Ask the textbook version: 「f(x)＝3sinx＋4cosx 有最大值時，求 sinx、cosx 之值」 (sinx＝3/5, cosx＝4/5); for special coefficients ask x directly: 「0≤x＜2π，f(x)＝sinx−√3cosx 何時有最大值？」 (x＝5π/6). The second form overlaps `interval`; keep the sinx、cosx version here.

### Unit interval 指定區間的最值位置
- Good; ladder ok (k＝1 → 2 → 3,4 with multiple x). P3: challenge could also use a restricted domain like 0≤x≤π (fewer solutions, needs filtering).

### Unit period 週期與平移
- Good; answers clear. P3: wording 「平移量」 → 「並說明由 y＝R sin kx 的圖形如何平移得到」 to match textbooks.

### Unit roots 方程式的實根數
- Variety: target is exactly d (2k roots), d±A (k roots) or d＋2A (0). Never a generic interior value, never a parameter question. Basic samples are 4/5 「1 個」 — endpoint cases are 50% of output, which over-teaches the edge case.
- Proposed changes:
  1. [P2] Replace `middle` target ＝ d with any value strictly inside (d−A, d＋A), e.g. d＋A/2, and weight: interior 50%, endpoint 25%, outside 25%.
  2. [P2] Challenge kind: 「方程式 sinx＋√3cosx＝k 在 0≤x≤π 恰有兩相異實根，求 k 的範圍」 (√3≤k＜2) — standard 學測 type, combines with restricted interval.

### Unit reverse 由最值反求係數
- Variety: 1 contrived template (「最大值 200，且 a＋b＝248」); numbers to 300 at advanced are absurd and the ladder is only scale.
- Proposed changes:
  1. [P2] Replace with standard reverse kinds: basic 「f(x)＝a sinx＋4cosx 的最大值為 5，a＞0，求 a」; advanced 「f(x)＝a sinx＋b cosx＋c 的最大值 7、最小值 −3，且 f(0)＝5，b＞0，求 a、b、c」; challenge 「f(x)＝a sinx＋b cosx 在 x＝(π)/(3) 時有最大值 2，求 a、b」 (a＝√3, b＝1).
  2. [P3] Cap numbers at R≤25.

### Unit identity 和差角展開再疊合
- Variety: 3 templates; two of them collapse to no 疊合 at all (sin(u＋π/3)＋sin(u−π/3)＝sin u). P1 formatting: 「y＝1［sin（4x＋π/3）…］」 → 「y＝1 sin 4x」.
- Difficulty: flat.
- Proposed changes:
  1. [P1] Never print coefficient 1 (both question and answer).
  2. [P2] Replace with genuine expand-then-fold items: 「y＝sinx＋sin(x＋(π)/(3))」 → √3 sin(x＋π/6); 「y＝cos(x−(π)/(3))−sinx」; 「y＝2sin(x＋(π)/(6))＋2cosx」; challenge 「y＝sinx·cos(x＋(π)/(6))」 needs 降冪 → (1/2)sin(2x＋π/6)−1/4. Each asks 「求最大值與最小值」.

## Topic: trigtransform — 三角函數的伸縮與平移 (config line 2306)
- Levels promised: basic「整數係數、單一步驟伸縮與基本週期」; advanced「分數／小數係數、相位與複合平移」; challenge「交點計數與週期現象建模」.
- Overall: Clean answers, but every unit is one template with level only changing number ranges, and the two "challenge" units (`intersections`, `model`) are among the easiest on the page. No graph-reading (圖形題) at all, although 「由圖形求 a、b、c、d」 is the single most common textbook item for this unit. Notation inconsistency: phase printed as 「(1)/(2)π」 here vs 「π/2」 on every other topic.

### Unit parameters 振幅、週期與極值
- Variety: 1 kind (a sin/cos(bx＋c)＋d → 振幅、週期、最大、最小). Missing: tan function period (y＝tan(2x)), y＝|sinx|、sin²x 週期, 「由圖形讀出振幅週期」, and the reverse 「振幅 3、週期 π、最大值 5，寫出 y＝a sin bx＋d」.
- Difficulty: integer challenge sample 「y＝−2 sin（3x）−1」 is easier than basic 「5 cos（3x＋(1)/(2)π）−4」; ladder absent. Fraction challenge just uglier fractions (−(57)/(11)).
- Proposed changes:
  1. [P1] Print phase as (π)/(2), (2π)/(3) — not 「(1)/(2)π」/「(2)/(3)π」 — consistent with `equation`, `shift`, trigblend.
  2. [P2] Advanced kind: 「求 y＝3tan(2x−(π)/(3)) 的週期」, 「求 y＝|2sinx| 的週期」. Challenge kind: [圖] graph of one period with labeled max/min/x-intercepts → 「求 y＝a sin(bx＋c)＋d 中的 a、b、c、d（a＞0，b＞0，0≤c＜2π）」.
  3. [P3] Fraction mode: keep |a|,|d| denominators ≤4.

### Unit equation 伸縮平移寫方程式
- Variety: 1 order only (horizontal compress → shift → vertical stretch → vertical shift), always 「壓縮」 never 「伸長為 2 倍」, no reflection. The key pedagogical trap — that 「先平移再伸縮」 and 「先伸縮再平移」 give different equations — is never tested.
- Plausibility: answers like 「y＝3 sin（2x−2π）−3」 and 「5 cos（4x−2π）−1」 are just 3sin2x−3 — a shift by a full period; teachers will flag it.
- Difficulty: challenge identical to basic.
- Proposed changes:
  1. [P1] Reject shifts that are multiples of the new period (h·b ∈ 2πℤ).
  2. [P2] Advanced: random order of the two horizontal steps (「先向右平移 (π)/(3)，再水平壓縮為原來的 (1)/(2) 倍」 → y＝sin(2x−π/3)); include 「水平伸長為原來的 2 倍」 and 「對 x 軸鏡射」.
  3. [P2] Challenge reverse: 「y＝2sin(3x−(π)/(2))＋1 的圖形可由 y＝sinx 經哪些步驟得到？依序寫出。」

### Unit shift 由方程式判讀平移
- Variety: 1 kind, always relative to y＝sin(kx)/cos(kx) (same k). Shifts that are a whole period appear: 「y＝sin（6x − 6π）−1 由 y＝sin（6x）… 向右平移 π」 — the graphs coincide horizontally.
- Proposed changes:
  1. [P1] Exclude shifts that are multiples of the period.
  2. [P2] Advanced: 「y＝cos(x−(π)/(2)) 的圖形與哪個基本函數的圖形相同？」 (sinx) — phase/cofunction recognition; challenge: from y＝sinx with stretch (multi-step, see above).

### Unit intersections 週期內的交點個數
- Variety: 3 forms (horizontal line misses; 「相切」 at extreme; sin(kx)＝c). Wording 「水平線…相切，共有幾個相異交點」 gives away the case. Challenge contains 「sin x＝(1)/(2) 有幾個相異實根」 (answer 2) — easier than basic.

## Topic: expfunctions — 指數函數與圖形 (config line 892; `UNIT_POLICIES.expfunctions` line ~2650)
- Levels promised: basic「小整數指數、直接代入與基本圖形性質」; advanced「含負指數、分數／小數底數、平移、比較與方程」; challenge「多步驟交點、反求參數及成長衰退綜合」.
- Overall: **P1 structural problem** — `UNIT_POLICIES.expfunctions` forces every unit to integer mode, and `baseFor("integer")` returns 2–15. - Variety: 1 kind. Bases 7, 10, 12 with shifts give 「f（6）＝2×7^3＋6＝692」, 「f（−3）＝−3×10^3−4＝−3004」 — arithmetic, not exponent understanding.

  2. [P2] Add rational exponents at challenge: 「f(x)＝8^x，求 f((2)/(3))、f(−(1)/(3))」 (note: rational exponents are 高一 指數律 review; fine as challenge).

### Unit table 數值表與描點
- Plausibility: P1 — 「f（x）＝14^(x＋4)−2 在 x＝−3、−2、−1」 → (−1, 2742): unplottable. A table for 描點 needs small values.
- Proposed changes:

- Good idea (figure + 單調／漸近線／值域), but every item is 遞增 unless c＜0. Basic samples 4/4 遞增.

### Unit transform 平移、伸縮與對稱
- Variety: missing the two symmetries a textbook teaches: y＝a^(−x)＝(1/a)^x (對稱於 y 軸) and y＝a^x vs y＝log_a x (對稱於 y＝x, belongs to loggraphs). The word 「再對稱於 x 軸」 appears even when it is the first step: 「y＝−3^x−1 → 再對稱於 x 軸，向下 1 單位」.
- Proposed changes:
  1. [P2] Advanced kind: 「y＝2^(−x) 與 y＝2^x 的圖形有何關係？」; 「y＝(1/3)^x 可由 y＝3^x 經何種對稱得到？」.
  2. [P3] Drop 「再」 when it is the first listed step; use 「鉛直伸縮」 (textbook term) instead of 「縱向伸縮」.

### Unit compare 指數值大小比較
- Variety: P1 — always same base, integer exponents: 「由大到小排列：3^6、3^4、3^3」 is trivial at every level. The standard 比較 items are: different bases rewritten to a common base (2^30, 3^20, 5^10 → 比較 8^10、9^10、5^10), rational exponents (√2、∛3、⁶√6 → 取六次方), and bases 0＜a＜1 (0.5^−2 vs 0.5^3).
- Proposed changes:
  1. [P1] Basic: same base but include a＜1 (「(1/2)^3、(1/2)^−1、(1/2)^0」). Advanced: common-base rewriting 「比較 2^(1/2)、4^(1/3)、8^(1/5)」 (rewrite as 2^(1/2), 2^(2/3), 2^(3/5)). Challenge: 「比較 2^30、3^20、5^10」 and 「比較 √2、∛3、⁶√6」.

### Unit equation 同底數指數方程
- Duplicate of `expequations.linear` (same-base linear exponent). Challenge 「6^(2x−4)＝6^(−4/3)」 with fractional RHS exponent is artificial.
- Proposed changes:
  1. [P2] Either remove from this topic or make it graphical: 「利用 y＝2^x 的圖形，求方程式 2^x＝3−x 的實根」 (x＝1) / 「2^x＝x＋2 有幾個實根」 (graph intersection — belongs here, not in expequations).

### Unit intersection 圖形與水平線交點
- Near-duplicate of `equation` (horizontal line ⇒ same-base equation); 「y＝11^(x−2)−1 與 y＝1330」 absurd size.
- Proposed changes:
  1. [P2] Change to two-curve intersections: 「求 y＝4^x 與 y＝2^(x＋1)＋8 的交點」 (substitution t＝2^x, x＝2), 「y＝2^x 與 y＝(1/2)^x＋(3)/(2)」; and number-of-intersections 「y＝2^x 與 y＝x² 有幾個交點」 (3) at challenge.

### Unit reverse 由圖上點反求參數
- Variety: 1 kind (one point, solve a^e). Challenge 「通過 P（6，3377）」 just bigger.
- Proposed changes:
  1. [P2] Challenge kind: two points → two unknowns: 「y＝k·a^x 通過 (1,6)、(3,54)，a＞0，求 k、a」 (a＝3, k＝2); 「y＝a^x＋b 通過 (0,3)、(2,11)」 (a＝3, b＝2).

### Unit model 成長與衰退模型
- Variety: 1 kind, always growth (because base is integer), always 「某量」 with no context, always forward computation. Numbers like 18×7³＝6174.
- Proposed changes:
  1. [P1] Add decay and contexts: 半衰期 (「某放射性物質半衰期 5 年，100 克經 15 年剩幾克？」), 藥物濃度 (每小時剩 80%), 細菌分裂, 複利.

## Topic: expequations — 指數方程與應用 (config line 821, generators ~795–820)
- Levels promised: basic「同底整數指數與直接比較指數」; advanced「分數／小數係數、底數互換與換元」; challenge「二次型指數、不等式與成長衰退」.
- Overall: Units are single templates. `quadratic` is inverted (basic has 244/9 coefficients, advanced has the textbook 2^(2x)−6·2^x＋8＝0). The key skill of the unit — **rewriting** 4^x＝(2^x)², 2^(x＋1)＝2·2^x, 9^x vs 27^(x−1), 1/8＝2^(−3), √2＝2^(1/2) — is almost never required: every equation is already handed over in same-base or a^(2x) form. Fraction bases in inequalities print without parentheses.

### Unit linear 同底指數方程式
- Variety: 1 kind: 「3^(−5x＋24)＝3^x」. Both sides already same base. Ladder flat.
- Proposed changes:
  1. [P2] Basic: 「2^(x＋1)＝(1)/(8)」, 「3^(2x−1)＝27」 (RHS a number to rewrite). Advanced: 「4^(x＋1)＝8^(x−1)」, 「9^x＝(1)/(√3)」, 「(1/2)^(x−1)＝4^x」. Challenge: 「2^x·4^(x＋1)＝(1)/(32)」, 「5^(x²−3x)＝(1)/(25)」 (quadratic exponent, x＝1, 2).

### Unit convert 底數互換與指數律
- Variety: 1 template 「27^x×3^2＝3^8」; ladder flat (625^x at advanced is the only difference).
- Proposed changes:
  1. [P2] Merge useful parts into `linear` (above) and turn `convert` into 指數律 evaluation/simplification, which the topic subtitle 「指數律」 promises but nothing practises: 「化簡 (8^(2/3)×4^(−1/2))／2^(−1)」, 「若 2^a＝3，求 4^a＋8^(−a)」 (9＋1/27), 「若 a^(1/2)＋a^(−1/2)＝3，求 a＋a^(−1)」 (7) at challenge.

### Unit quadratic 換元法解二次型指數
- Difficulty: P1 inverted. Basic 「3^(2x)−(244)/(9)×3^x＋3＝0」 (roots t＝1/9, 27) is harder than advanced 「2^(2x)−6×2^x＋8＝0」. Basic shows fraction coefficients although the unit is integer-mode.
- Variety: always already in a^(2x), a^x form; never 4^x−2^(x＋1)−8＝0, never a^x＋a^(−x), never a case with an extraneous root (t＜0) to reject — the tip says 「t＞0」 but no item tests it except double roots.
- Proposed changes:
  1. [P1] Basic: only roots x ∈ {0,1,2,3} (t integers): 「2^(2x)−6×2^x＋8＝0」. Advanced: needs rewriting: 「4^x−2^(x＋1)−8＝0」 (t²−2t−8＝0 → t＝4, reject −2 → x＝2), 「9^x−4·3^(x＋1)＋27＝0」. Challenge: 「2^x＋2^(2−x)＝5」 (x＝0, 2), 「3^(x＋1)＋3^(1−x)＝10」.
  2. [P2] At least 1/3 of items should have one negative t to reject; answer should say 「（t＝−2 不合）」 only in the key.

### Unit inequality 指數不等式
- Plausibility: P2 — fraction base printed as 「(1)/(3)^x＋1」 (fraction then superscript) — ambiguous on paper; wrap in parentheses like expfunctions' `baseHTML` 「（1/3）^(x＋1)」.
- Variety: 1 kind (same base both sides, linear exponent). Challenge promise 「二次型…不等式」 not met.
- Proposed changes:
  1. [P2] Advanced: rewriting 「(1/4)^x＞8」, 「3^(2x−1)≤(1)/(27)」. Challenge: 「4^x−3·2^(x＋1)＋8＜0」 (2＜2^x＜4 → 1＜x＜2), 「(1/2)^(x²−2x)＞(1)/(8)」 (−1＜x＜3).

### Unit application 指數成長、衰退與複利
- Variety: 3–4 templates (bacteria backwards/forwards, half-life, 「某數量」), 複利 never appears though named in the title. Ladder: challenge adds 「需幾小時」 — good.
- Plausibility: decimal mode gives 「某菌群…2 小時後數量為 33.3，求起初的數量」 — fractional bacteria; use mass/concentration contexts for decimals.

  1. [P1] Decimal mode: switch context to 公克／毫克／萬元 (「某藥物在血液中每小時剩下原來的一半，注射 6.4 毫克…」).

## Topic: commonlog — 常用對數與對數律 (config line 456)

### Unit definition 對數定義與求值
- Variety: 3 kinds (log_a a^n; log_{a^p}(a^q); log_a(linear)＝c; plus 「log_5x＝4 求 log_5(5²x³)」). Trivial items: 「log_3 3」, 「log_2^2（2^2）＝1」, 「log_7 1」.

- Proposed changes:

  3. [P2] Add 「求 x 的範圍使 log_{x−1}(5−x) 有意義」 (1＜x＜5, x≠2) at advanced, and 「求 3^{log₃7}」, 「求 10^{2＋log 3}」 (300) at challenge.

  1.
