# g10-drills.html design review (高一, 15 topics)

Source reviewed: `/home/claude/yenyu-bot/bhcs-web/tools/math/g10-drills.html` (branch `fix/math-answer-errors`), samples from `chunks/09-g10.txt`.

## Summary

1. **Ladder is mostly carried by `presets` (which units appear), not by the generators.** In roughly 60 of ~100 units the generator ignores `ctx.level`, so basic/advanced/challenge print the same question with different random numbers (乘法公式 all 8 units, 分式 square/cube/symmetric/addsub, 算幾 all 9 units, 分點 all 7 units, 多項式 all 6, 指數 integerpowers/laws/algebra, 對數 laws/equation, 直線與圓 standard). When a teacher picks a unit directly (not the preset), the level buttons do nothing. Fix pattern: give each such unit 2–3 `kind`s gated by level (as radicals/integerpart, cubic/roots, line/slope already do).
2. **Four inverted or broken ladders (P1):** 指數/fractional (challenge `16^(1/2)` vs basic `5832^(2/3)` — root range is 2–18 at every level), 不等式/higher (basic asks to factor an expanded cubic with no hints; advanced gives factored form), 直線與圓/chord (`s = rand(1, L===0?100:10)` — basic radii 416, 578), 分式/muldiv & 絕對值/error (basic numbers harder/uglier than advanced).
3. **Three answer/format bugs (P1):** radicals/simplify `frac` kind prints `(4√38)/(2)` unreduced; 餘式/two prints mixed-number coefficients `1(2)/(3)x＋3(2)/(3)` (should be `(5/3)x＋(11/3)` or integer by construction); fraction mode everywhere prints polynomial coefficients as mixed numbers (`3(x−1(1)/(3))²`, `1(1)/(2)x³`), which no Taiwanese textbook does — coefficients must be improper fractions.
4. **Several units are trivial for 高一 and read as 國中複習:** 乘法公式 squareplus/squareminus/conjugate (國中 8 年級), 指數 integerpowers/laws/algebra/scientific (國中), 對數 laws basic (`log₂8−log₂32`, each term evaluable), 指數 equation basic (`3^x＝3^6`), 根式 equality (`p＋q√13＝15√13`, read off), 分式 symmetric (`k(x²＋1)/x` = k·given), 算幾 means/fixedproduct/fixedsum (one-step). These need a real 高一 form or should be demoted to a warm-up unit.
5. **Promised-but-absent content:** 分式 subtitle says 繁分式 but there is no unit; 對數 growth unit never uses a logarithm (duplicate of 指數 application; 108課綱 expects 幾年後超過/翻倍 with log 2≈0.3010, pH/分貝/地震規模); 直線與圓 tangent has no 「過圓外一點求切線方程式」; 分點公式 is 1-D only (108 數II also needs 平面分點).
6. Strongest topics as-is: 絕對值與區間, 二次函數, 三次函數, 直線方程式, 對數/digits — mostly polish.
7. Ugly numbers to clean (P2): 算幾/squarebound (`93312`, `6x＝±2y` not reduced), 直線與圓/minmax basic (半徑 69, P(17,64)), tangent (`20x＋21y＋862＝0`), 直線/intersect advanced (`(−228/43, 204/43)`), distance challenge (`(105√157)/157`), 根式 nested (`√(88−2√1927)`), 餘式 remainder basic (`P(5)` of a quartic = 1754).

## Topic: multiplication — 乘法公式
- Levels promised: basic「小係數，熟練和的平方、差的平方與平方差」/ advanced「分數／小數係數、三項平方與立方」/ challenge「立方因式分解、公式連鎖與條件求值」.
- Overall: every unit except chain/powervalue ignores level; the page is run with integer mode only, so the promised 分數係數 never appears. 和/差的平方、平方差 are 國中 g8; for 高一 the drill value is in 立方公式、三項平方、連鎖、條件求值、(x±1/x) forms.

### Unit squareplus 和的平方公式
- Variety: 1 kind `(ax＋by)²`, all levels identical. Contexts none.
- Difficulty: flat.
- Plausibility/tip: fine; 國中 level.
- Proposed changes:
  1. [P2] Gate by level: basic `(2x＋3y)²`; advanced one term with a constant or higher power `(3x²＋2)²`, `(x＋2y＋…)`; challenge numeric use of the formula `計算 1002²`（＝(1000＋2)²）and `已知 (a＋b)²＝49，ab＝10，求 a²＋b²`.
  2. [P3] Merge squareplus/squareminus into one unit `square` with random sign (two units of one line each is padding).

### Unit squareminus 差的平方公式
- Same as squareplus. Merge (see above). Add challenge `999²`, `(3x−1/3)²`-free forms like `(2x−3y)²−(2x＋3y)²`.

### Unit conjugate 平方差公式
- Variety: 1 kind `(ax＋by)(ax−by)`; flat.
- Proposed changes:
  1. [P2] basic as now; advanced `(3x＋2y)(3x−2y)−(x＋y)²`-type combination or `(x＋y＋2)(x＋y−2)`; challenge numeric `1003×997`, `(2＋1)(2²＋1)(2⁴＋1)` (ties to chain).

### Unit trinomial 三項平方公式
- Variety: 1 kind `(ax＋by＋c)²`; flat. Sample `（6x ＋ 8y ＋ 4）²` basic → `36x²＋96xy＋64y²＋48x＋64y＋16`, heavy arithmetic for basic.
- Proposed changes:
  1. [P2] basic coefficients ≤3 (`(x＋2y＋1)²`); advanced mixed signs `(2x−y＋3)²`; challenge `已知 a＋b＋c＝6，ab＋bc＋ca＝11，求 a²＋b²＋c²` (standard 108 example).
  2. [P3] Tip: write the formula out `(A＋B＋C)²＝A²＋B²＋C²＋2AB＋2BC＋2CA`.

### Unit cube 和差立方公式
- Variety: 1 kind; flat; basic sample `（8x − 7y）³＝512x³−1344x²y＋1176xy²−343y³` is too heavy for basic.
- Proposed changes:
  1. [P1] basic coefficients 1–3 only (`(x＋2y)³`, `(2x−y)³`); advanced ≤5; challenge numeric `11³` via `(10＋1)³`, `已知 a−b＝3，ab＝2，求 a³−b³`.

### Unit cubefactor 立方和差因式分解
- Variety: only 6 variants (`bankSize=6`, `!! null` on every level) — 8-question sheets cannot fill. Flat.
- Proposed changes:
  1. [P1] Enlarge: allow coefficients 1,2,3 for a and b (27x³±y³, 8x³±27y³), and `x³±1`, `x⁶−y⁶`→ no; add constants `x³＋8`, `27a³−1`, `a³b³−8`; challenge `x³＋y³＋x＋y`-type with 提公因式 `2x³−16` (=2(x−2)(x²＋2x＋4)).

### Unit chain 乘法公式連鎖
- Variety: 1 kind (`(a−b)(a＋b)(a²＋b²)`), challenge adds the x⁸ version 60%; a,b ∈ 1–3 so bank is 9–10 — near-identical questions.
- Proposed changes:
  1. [P2] Add numeric kind `(2＋1)(2²＋1)(2⁴＋1)(2⁸＋1)＝？` (answer `2¹⁶−1`) and `(x−1)(x＋1)(x²＋1)(x⁴＋1)＋1` at challenge; add `(x＋y)²(x−y)²` and `(x²＋xy＋y²)(x²−xy＋y²)` at advanced.

### Unit powervalue 已知和積求冪和
- Variety: 2 kinds (a²＋b², a³＋b³); basic only squares. Good ladder (negative products at advanced+).
- Proposed changes:
  1. [P2] Add `a−b` kind (`已知 a＋b＝7，ab＝10，求 (a−b)²` / `|a−b|`), `a⁴＋b⁴` at challenge, and the 1/x form here if 分式 drops it: `已知 x＋1/x＝3，求 x²＋1/x²、x³＋1/x³`.
  2. [P3] Tip: write `a³＋b³＝(a＋b)³−3ab(a＋b)`.

## Topic: polynomial — 多項式四則運算
- Levels promised: basic「低次整數多項式的加減與乘法」/ advanced「分數／小數係數與一次除式」/ challenge「較高次除法、ax−b 除式與除法原理」.
- Overall: all generators ignore level (degree ranges fixed), so e.g. basic addsub prints degree-4 pairs while challenge prints `(5x²−8x＋2)＋(4x²−7x−5)`. No 分離係數法、除以二次式、次數判斷、係數比較（恆等式）、升冪/降冪 — all standard for 108 高一 多項式.

### Unit addsub 多項式加減
- Variety: 1 kind; degree 1–4 random at all levels.
- Proposed changes:
  1. [P2] Gate degree: basic ≤2, advanced ≤3 with a subtraction of a longer poly, challenge `2P(x)−3Q(x)` with given P,Q, and 「求 P＋Q 的次數與首項係數」.
  2. [P3] Add 「已知 P(x)＋Q(x)＝…，P(x)＝…，求 Q(x)」 reverse kind.

### Unit multiply 多項式乘法
- Variety: 1 kind; degrees 1–2 each. Flat.
- Proposed changes:
  1. [P2] basic (一次)(一次)/(一次)(二次); advanced (二次)(二次); challenge 「求 (2x²−3x＋1)(x³＋2x−5) 展開後 x³ 的係數」 (係數比較, no full expansion) and `(x＋1)³(x−2)` 的常數項.

### Unit divide 多項式除法
- Variety: 1 kind (÷ x−a). Flat; challenge sample `（2x²＋10x＋11）÷（x＋4）` is easier than basic `x⁴…÷(x−2)`.
- Proposed changes:
  1. [P1] Gate: basic quadratic ÷ linear; advanced cubic/quartic ÷ linear (include missing-term polynomials like `x³−8`); challenge ÷ quadratic divisor `(x³＋2x²−x＋3)÷(x²＋1)` — the one thing this topic never asks and 高一 long division exists for.
  2. [P3] Wording: 「求 … 的商式與餘式」 fine; add 「用長除法」 to distinguish from the 餘式 topic's 綜合除法.

### Unit axb 除以ax−b
- Variety: 1 kind; coefficients -2..2 so many leading negatives (`−6x⁴＋12x−8`); flat.
- Difficulty: basic shows quartic `（−6x⁴＋12x−8）÷（3x−3）`; too hard for basic.
- Proposed changes:
  1. [P2] basic degree ≤2 positive leading; advanced cubic; challenge quartic with missing terms, plus the standard trap kind 「用綜合除法除以 x−1 後，商要除以 3」 phrased as 「P(x)÷(3x−3) 的商式與餘式，若 P(x)÷(x−1) 的商為 Q(x)、餘式 r」.
  2. [P3] Tip: `P＝(ax−b)Q＋R ⇒ P＝(x−b/a)(aQ)＋R`，so 商＝(綜合除法商)/a，餘式不變.

### Unit reconstruct 商式與餘式關係
- Duplicates remainder/reconstruct (same form, only divisor differs: ax±b here vs x−a there). Flat.
- Proposed changes:
  1. [P2] Keep one here with ax±b divisors at advanced and quadratic divisors at challenge (`P 除以 x²＋x＋1 商 x−2 餘 3x＋1`); drop or re-point the duplicate in the 餘式 topic (see below).

### Unit value 代入與餘式性質
- Variety: 1 kind P(a); flat; advanced `3x⁵＋…` at `P(4)＝4779` is pointless arithmetic.
- Proposed changes:
  1. [P2] basic a ∈ {−2..3}, degree ≤3; advanced ask `P(2)−P(−2)` or `P(1)＝係數和` tricks (`求 P(x)＝(2x−1)⁵ 的係數總和`); challenge 「P(1)、P(−1) 求奇次項係數和」, which is the actual 高一 use of 代入.

## Topic: remainder — 餘式定理與因式定理
- Levels promised: basic「整數係數、直接代入與一次因式判定」/ advanced「分數／小數係數、反求係數與綜合除法」/ challenge「雙餘式、較高次多項式與函數還原」.
- Overall: solid core but each unit has one kind; fraction mode is the only "advanced" ingredient and its mixed-number rendering (`1(1)/(2)x³−2(1)/(2)x`) is unreadable. Missing: 餘式定理 with ax−b 除式, 因式定理 on cubics, 兩未知係數 (a,b) 反求, 二次除式 `(x−1)²`, 用因式定理分解三次式.

### Unit remainder 餘式定理代入求值
- Variety: 1 kind; basic sample `P(x)＝4x⁴−7x³＋5x²＋x−1 除以 (x−5)` → 1754, heavy for basic.
- Difficulty: flat in integer mode; fraction mode harder than integer challenge.
- Proposed changes:
  1. [P1] Fraction mode: render coefficients as improper fractions `(3/2)x³−(5/2)x＋(5/2)` and prefer `2x³−3x＋1` ÷ `(2x−1)` (integer coefficients, divisor 2x−1 → P(1/2)) which is the textbook form; same for 多項式/axb.
  2. [P2] basic: |a|≤3, degree ≤3; advanced: divisor `2x＋1`、`3x−2`; challenge: 「P(x) 除以 x−2 餘 3，求 (x²＋1)P(x) 除以 x−2 的餘式」 and 「x¹⁰⁰ 除以 x−1」 style.

### Unit factor 因式定理與反求係數
- Variety: 1 kind `x²＋kx＋c 有因式 x−a 求 k` at all three levels (samples identical across levels).
- Proposed changes:
  1. [P1] Gate: basic as now; advanced cubic `x³＋kx²−5x＋6 有因式 x−2`; challenge two unknowns 「x³＋ax²＋bx−6 有因式 (x−1)(x＋2)，求 a、b」 and 「用因式定理分解 x³−2x²−5x＋6」.

### Unit two 雙餘式求二次除式餘式
- Variety: 1 kind; remainders random so the answer is fractional 6 of 8 times (`−1(4)/(9)x＋5(1)/(9)`).
- Proposed changes:
  1. [P1] Construct from the answer: pick m,n integers and divisors, then remainders u＝ma＋n, v＝mb＋n → integer line. Keep fractional m only at challenge and print `(5/3)x`, never mixed.
  2. [P2] Advanced: give P(x) explicitly with (x−1)(x−2) 除式 (`求 x⁵ 除以 x²−3x＋2 的餘式`); challenge: 除以 `(x−1)²` 型 (`P(x) 除以 (x−1)² 餘 2x＋1，P(x) 除以 x−2 餘 5…`).

### Unit synthetic 綜合除法求商與餘式
- Variety: 1 kind; flat (challenge sample `（x²−12x＋34）÷（x−4）`).
- Proposed changes:
  1. [P2] basic quadratic/cubic ÷ (x−a); advanced quartic with missing terms (`x⁴−3x＋2`); challenge ÷ (2x−1) (商 must be halved) and 「連續綜合除法：將 x³＋2x²−x＋3 展成 (x−1) 的冪次」 (108 高一 standard).

### Unit reconstruct 除法原理與函數還原
- Duplicate of 多項式/reconstruct with divisor x−a. Flat.
- Proposed changes:
  1. [P2] Replace with 「已知 P(x)÷(x−1) 商 Q(x) 餘 2，Q(x)÷(x＋1) 商 x＋3 餘 −1，求 P(x)」 (two-stage) at advanced, and 「P(x) 除以 (x−1)(x−2) 的商為 x＋1、餘式 3x−2，求 P(1)、P(2)」 at challenge; keep plain restore for basic.

## Topic: rationalexp — 分式的運算
- Levels promised: basic「單一倒數對稱式與一次因式約分」/ advanced「分數／小數參數、乘除與通分」/ challenge「立方對稱式、繁分式與裂項相消」.
- Overall: 繁分式 promised, not present. square/cube/symmetric multiply the target by a random k (`求 10(x²＋1/x²)`) which no textbook does; symmetric is a tautology. muldiv hands the student already-factored expressions so 「先分解」 in the tip is never exercised.

### Unit square 倒數對稱式平方
- Variety: 1 kind; flat; `x＋1/x＝±2`-adjacent values ok (|s|≥2 enforced).
- Proposed changes:
  1. [P1] Drop the k multiplier. basic 「已知 x＋1/x＝3，求 x²＋1/x²」; advanced 「已知 x−1/x＝2，求 x²＋1/x²」 and 「x＋1/x＝3，求 x⁴＋1/x⁴」; challenge 「x²−3x＋1＝0，求 x²＋1/x²」(derive x＋1/x first) and 「求 x−1/x」(±√5).

### Unit cube 倒數對稱式立方
- Variety: 1 kind; flat; drop k as above.
- Proposed changes:
  1. [P1] basic x＋1/x given → x³＋1/x³; advanced x−1/x given → x³−1/x³; challenge `x²＋x＋1＝0`-free, use 「x＋1/x＝3，求 x⁵＋1/x⁵」 (via (x²＋1/x²)(x³＋1/x³)).

### Unit symmetric 對稱式轉化
- Variety: 1 kind `k(x²＋1)/x` ＝ k·(x＋1/x): the answer is the given number times k. Trivial at every level (sample 「已知 x＋1/x＝−17，求 (x²＋1)/x」→ −17).
- Proposed changes:
  1. [P1] Replace with real conversions: 「已知 x/(x²＋x＋1)＝1/4，求 x²/(x⁴＋x²＋1)」 (textbook classic), 「已知 x＋1/x＝3，求 (x⁴＋x²＋1)/x²」, 「x²−5x＋1＝0，求 x³＋1/x³」. Gate: basic one step, advanced two steps, challenge the 1/4 classic.

### Unit muldiv 分式乘除與約分
- Variety: basic cancel only; advanced +×; challenge +÷ (good gating) — but numerators/denominators are given factored, so no factoring happens; 禁值 handled well.
- Proposed changes:
  1. [P1] Print expanded quadratics: 「化簡 (x²−8x＋15)/(x²−2x−15)」, 「(x²−1)/(x²＋3x＋2) × (x＋2)/(x−1)」; keep factored form only at basic.
  2. [P3] Answer form `((x−9))/((x−3))` has doubled parentheses — print `(x−9)/(x−3)`.

### Unit addsub 分式通分與加減
- Variety: 1 kind `p/(x−a) ± q/(x−b)`; flat; answers show expanded denominators (`(−3x)/(x²＋9x＋18)`) whereas textbooks keep `(x＋3)(x＋6)`.
- Proposed changes:
  1. [P2] Keep denominator factored in the answer; simplify common factors in numerator (`(−2x−60)/…` → `−2(x＋30)/…`).
  2. [P2] Gate: basic as now; advanced three terms or a quadratic denominator sharing a factor `1/(x−1)＋2/(x²−1)`; challenge 繁分式 `(1＋1/x)/(1−1/x²)` and 部分分式 「將 (3x＋1)/((x−1)(x＋2)) 化為 A/(x−1)＋B/(x＋2)」 — fulfils the promised 繁分式.

### Unit telescope 裂項相消求和
- Variety: good (split/plain/sigma/reverse/sigma2/bound), properly gated. Good; no change except:
  1. [P3] basic "split" kind `1/(30×31)` is a single line; fine. Tip is long; split into two sentences.

## Topic: radicals — 根式的運算
- Levels promised: basic「單一平方根化簡與基本共軛乘積」/ advanced「分母有理化、雙重根式與整數部分」/ challenge「共軛對稱式、無理數相等與裂項相消」.
- Overall: well-gated kinds in simplify/integerpart/telescope, but random radicands from a 30-element list produce unteachable numbers (√46−√3, √(88−2√1927)); equality is trivial; conjugate has 2 kinds only.

### Unit simplify 根式化簡
- Variety: 3 kinds per level, gated. Bug: `frac` kind answer unreduced (`√(608)/(4)` → `(4√38)/(2)`, should be `2√38`). Basic radicands too big (√3312, √2541 need factoring 23²·… ).
- Proposed changes:
  1. [P1] Reduce `s/d` by gcd in the frac kind (line 884).
  2. [P2] basic: s ∈ 2–6, r ∈ {2,3,5,6,7,10} (√50, √72, √108); challenge may keep larger. `√1664＋√1664` (same radicand) should be excluded.

### Unit rationalize 分母有理化
- Variety: 4 kinds gated (single/two/minus/both/twok). Numbers unnatural (`1/(√47＋√6)`, `(√26＋√23)/(√26−√23)` → `(49＋2√598)/3`).
- Proposed changes:
  1. [P2] Restrict radicands to {2,3,5,6,7,10} and allow integer terms: `1/(2＋√3)`, `1/(√5−2)`, `(√3＋1)/(√3−1)`, `√2/(√5−√3)`. Add challenge 「有理化後求 a＋b 若 (√3＋1)/(√3−1)＝a＋b√3」 (connects to equality).

### Unit nested 雙重根式
- Variety: 1 kind `√(M±2√N)`; flat; radicands from the big list (√(53＋2√646)).
- Proposed changes:
  1. [P2] Gate: basic a,b ≤ 7 with the 2 shown (`√(5＋2√6)`); advanced hidden 2 (`√(7＋√48)`, `√(8−√60)`); challenge needs halving `√(4＋√15)＝(√10＋√6)/2` and `√(3−√5)`.

### Unit integerpart 根式的整數與小數部分
- Variety: 5 kinds gated — good. Challenge `9−√4600` floor −59 is a valid but rarely-taught case.
- Proposed changes:
  1. [P3] Add 「設 √7 的小數部分為 b，求 b²＋6b」/「求 1/b 的整數部分」 at challenge (both standard); keep `c−√n` but limit to small n so the student can place it (`5−√96` ok, `1−√8732` not).

### Unit conjugate 共軛根式與對稱式
- Variety: 2 kinds (product, x²＋y²), not gated; x²＋y² of `√a±√b` is just 2(a＋b).
- Proposed changes:
  1. [P2] Gate: basic product; advanced `x＝(√5＋√3)/(√5−√3)`, `y＝1/x`，求 x＋y、xy; challenge 求 x²＋y²、x³＋y³、x/y＋y/x (use 乘法公式 topic's identities).

### Unit equality 無理數相等
- Variety: 1 kind, read-off (`p＋q√13＝15√13` → (0,15)). All levels identical. P1 too easy.
- Proposed changes:
  1. [P1] Make the right side need work: `p＋q√2＝(1＋√2)²`, `(p＋q√3)(2−√3)＝1`, `p＋q√5＝(3＋√5)/(3−√5)`, 「(x−2)＋(y＋1)√3＝0，x、y 有理數，求 x、y」. Gate by number of steps.

### Unit telescope 根式裂項相消
- Variety: 6 kinds gated; good. Basic mixes a 「分母有理化」 single-term kind that duplicates rationalize — fine as lead-in.
  1. [P3] Challenge `Σ 1/(√(2k＋1)＋√(2k−1))` answers like `(√57−1)/2` fine. No change.

## Topic: exponent — 指數
- Levels promised: basic「指數定義、零次方與單一步驟運算」/ advanced「分數指數、連續根式及複合指數律」/ challenge「條件代換、異底數關係、科學記號座標與應用」.
- Overall: integerpowers/laws/algebra/scientific are 國中 content and overlap each other; fractional ladder is inverted; equation basic is trivial; substitution has 2–3 fixed templates.
