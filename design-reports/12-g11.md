# g11-drills.html design review — line3d / conditionalprob / bayes / matrixops / matrixapps

Source reviewed: `/home/claude/yenyu-bot/bhcs-web/tools/math/g11-drills.html` (branch `fix/math-answer-errors`), topic configs at lines 1497–1525 (line3d), 460–552 (conditionalprob), 193–316 (bayes), 1065–1149 (matrixops), 954–1061 (matrixapps). Samples from chunk `12-g11.txt`.

## Summary

1. **The difficulty ladder is mostly implemented by presets (which units appear at each level), not inside units.** In line3d 14/16 units ignore `ctx.level` (only `skewdistance`, `motion` read it); in conditionalprob 10/15 ignore it; in bayes 11/15; in matrixops the only lever is `lim` (bigger entries: 3/5/7); in matrixapps 9/19 ignore it. So when a teacher picks a unit at "challenge" they usually get the same questions as "basic". The presets make the printed basic/advanced/challenge sheets differ, so this is tolerable for sheets built from presets, but every unit chosen manually has a flat ladder. Proposals below add real within-unit kinds for the units that appear in 2–3 presets.
2. **Pattern leaks that teach the wrong thing (P1):** `linerelations` skew case is always `t(1,0,0)` vs `t(0,1,0)`; `pointprojection`/`pointdistance` only use the six axis/diagonal directions so the foot can be read off without the formula; `composition` is always shear-then-scale; `inverseproduct` always uses det=1 matrices of the shape `[[1,a],[b,1+ab]]`.
3. **Missing standard textbook question types (P1):** 直線與平面的夾角, 兩平面交線的參數式 (not just the direction), 比例式→參數式 (unit is titled 互換 but only goes one way), 由機率值判定獨立 (P(A∩B) vs P(A)P(B) given as fractions), 旋轉後的像點, 已知 T(u)、T(v) 為非基底向量反求矩陣, 反求伸縮/面積倍率參數, det 性質 (det(AB), det(kA), det(A⁻¹)).
4. **Near-duplicate units (P1/P2):** bayes `factoryorigin` ≡ `bayesthree` (same math, 機器 vs 廠); `totaltwo` ≡ the 35 % legacy branch of `bayestwo` minus the last step; line3d `pointdistance` ≡ `pointprojection` plus a length. Five bayes units share one 甲乙丙廠不良品 context.
5. **One formatting bug (P1):** `lineimage` prints `L′：＋y＋4＝0` when the x-coefficient is 0 (`lineText` adds a sign to the first non-zero term when it is not the x term).
6. **Wording/mode polish (P2/P3):** `rotation` says 「連續施作 1 次」; `scaling` basic (integer mode) yields `P′（−30，2/3）`; medical units say 「教學模型／教學用檢驗資料」; 「不小於 7的」 lacks a space; `productsize` can ask about two 1×1 matrices; 行/欄 for "column" is inconsistent across tips.
7. Numbers and answers are otherwise correct and in textbook form; contexts in bayes/conditionalprob are plausible but monotonous (廠/機器/檢驗/袋子). Curriculum: 點到直線距離 and 歪斜線距離 are 數甲 (高三選修) material under 108課綱, not 數A 高二 core — keep them but flag them as 延伸 in the levels text.

## Topic: line3d — 空間直線方程
- Levels promised: 基礎「讀寫參數式、比例式、線上點與過兩點直線」／進階「線面／線線關係、交點、平行條件與夾角」／挑戰「投影、點線距離、歪斜線距離與運動整合」.
- Overall: Correct and complete on the basics; the preset split matches the levels text. Weak points: trivial read-off units with no variation (direction/parametric/symmetric), leaked patterns (linerelations skew, projection/distance directions), ugly plane coefficients, and no 線面夾角 / 交線參數式.

### Unit direction 由參數式讀方向向量
- Variety: 1 kind, identical at all levels (pure copy of the t-coefficients). Missing: 由比例式讀方向向量, 由兩點式, 化為最簡整數比, 判斷哪些向量與 L 平行.
- Difficulty: flat (basic = challenge).
- Plausibility/tip: fine, tip matches.
- Proposed changes:
  1. [P1] Add kind 比例式 (advanced+): 「直線 L：(x−1)/2＝(y＋3)/(−1)＝z/4，寫出一個方向向量。」A: （2，−1，4）. Challenge variant with un-normalised numerators: 「直線 L：(2x−1)/4＝(3−y)/2＝z，寫出一個方向向量。」A: （2，−2，1）（must divide out the 2 and flip the sign — the classic trap）.
  2. [P2] Add kind 最簡整數比 (basic): 「直線 L：(x，y，z)＝(1，2，0)＋t(4，−6，2)，寫出最簡整數方向向量。」A: （2，−3，1）.
  3. [P3] Add kind 判斷 (basic): 「下列何者與直線 L 平行？(A)(6，−2，4) (B)(3，1，2) …」 or simply「向量 (6，−3，9) 是否與 L：…＋t(2，−1，3) 平行？」A: 是.

- Difficulty: flat.

### Unit symmetric 參數式與比例式互換
- Variety: 1 kind (參數式→比例式 only). Title says 互換 but the reverse direction never appears. Missing: 比例式→參數式, zero-component case, un-normalised 比例式.
- Difficulty: flat.
- Plausibility/tip: tip mentions 「三分量皆非零時」 but no question ever exercises the zero case.
- Proposed changes:
  1. [P1] Add reverse kind (basic/advanced): 「將直線 (x−2)/3＝(y＋1)/(−2)＝z/5 化為參數式。」A: (x，y，z)＝(2，−1，0)＋t(3，−2，5).
  2. [P1] Add zero-component kind (advanced): 「將直線 (x，y，z)＝(1，4，−2)＋t(0，3，5) 化為比例式（若某分量為 0 請分開寫）。」A: x＝1，(y−4)/3＝(z＋2)/5.
  3. [P2] Challenge: 「將直線 (2x＋1)/4＝(1−y)/3＝z 化為參數式，並寫出一點與方向向量。」A: (x，y，z)＝(−1/2，1，0)＋t(2，−3，1).

### Unit lineplane 直線與平面關係
- Variety: 3 outcomes (相交／平行不相交／在平面上), good. Missing 反求 kind.
- Difficulty: flat; planes for the parallel cases are generated as n＝d×w and printed unreduced: 「42x−27y＋15z＋158＝0」, 「53x＋14y−45z＋430＝0」 — students would never see these in a textbook.
- Plausibility/tip: tip fine. Answer wording 「平行且不相交」 OK (textbooks: 平行／相交於一點／直線在平面上).
- Proposed changes:
  1. [P2] For parallel/contained cases build n from small vectors: pick n with entries in −4…4, then choose d ⟂ n by construction (e.g. d＝n×e), reduce by gcd, and choose the constant so the point value is small. Target plane like 「2x−y＋3z＋5＝0」.
  2. [P2] Add 反求 kind (advanced/challenge): 「直線 (x，y，z)＝(1，0，2)＋t(2，1，−1) 在平面 ax＋by＋z＝c 上，求 a、b、c。」A: from d·n＝0 and the point: a＝1，b＝−1，c＝3（pick values so a unique small solution exists: use d and a second point to force two equations).

### Unit linerelations 兩直線位置關係
- Variety: 3 outcomes, but the skew case is **always** u＝(1，0，0), v＝(0，1，0) (source: `u=V(1,0,0);v=V(0,1,0)` in the skew branch), and the parallel case always shows v＝k·u unreduced with k∈{2,3,4}. Students will classify by eye without doing the work. 重合 is never generated (textbooks list 4 cases).
- Difficulty: flat.
- Plausibility/tip: tip fine.
- Proposed changes:
  1. [P1] Skew: pick u, v random small non-parallel vectors, n＝u×v, B＝A＋w with w·n ≠ 0 (and verify by solving). Sample: 「判斷 L₁：(x，y，z)＝(1，0，2)＋t(1，2，−1) 與 L₂：(x，y，z)＝(0，3，1)＋s(2，−1，1) 的位置關係。」A: 歪斜.
  2. [P1] Parallel: half the time use v＝−u or a hidden multiple (e.g. u＝(2，−4，6), v＝(−3，6，−9)); add 重合 case (B on L₁, v ∥ u) with answer 「重合」.
  3. [P2] Use distinct parameters t and s for L₁ and L₂ (currently both use t, which is confusing when students set coordinates equal). Same fix in `lineintersection`.

### Unit equality 矩陣相等反求未知數
- Variety: 1 kind (x, y on the diagonal, 求 x＋y).
- Difficulty: bigger numbers only.
- Proposed changes:
  1. [P2] Challenge: coupled entries 「[[x＋y，3],[−1，x−y]]＝[[5，3],[−1，1]]，求 x、y」 A: x＝3，y＝2; advanced: 3 unknowns, ask xyz.
